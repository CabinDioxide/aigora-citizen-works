# 节点 ac-cloud：云 GPU 平台（AWS / Azure / GCP）

> 父节点：ac-gpu（GPU 芯片）| 栈：AI 算力栈 | 层：L1 云计算执行层
> 建立：2026-06-28 | 数据综合 C：C2–C4（云营收 C4；BIS IFR 原文 C4；市场集中度 Hypothesis；Trump 撤销 C3）

---

## 结构层

### 1. 功能定义

云 GPU 平台是 AI 训练和推理工作负载的实际执行地点。它把 GPU 芯片（ac-gpu）打包成可按需租用的算力，通过网络以 IaaS（基础设施即服务）形式提供给全球客户。没有云 GPU 平台，大多数 AI 研究机构和公司无法自行采购和运维数千张 GPU——云平台是把物理算力变成全球可访问计算服务的中间层。

这个位置在 AI 产业链里有特殊的双重意义。一方面，它是 GPU 芯片的主要下游买家（三大超大规模云提供商每季采购 GPU 的支出均在百亿美元量级，是 NVIDIA 的最大客户群之一）；另一方面，从 2025 年 1 月起，美国政府开始把它当作出口管制的强制执行节点——云提供商被要求在向海外实体提供大规模 AI 训练算力之前，先核查该实体的管辖地。

这个节点和 ac-gpu 的区别：ac-gpu 是芯片层，卡的是谁能拥有 GPU 芯片实体；ac-cloud 是服务层，卡的是谁能通过网络访问 GPU 算力，无需拥有芯片。后者的边界是账户权限，前者的边界是物理管控。

它不做：不决定 GPU 芯片本身的出口（那属于 ac-gpu 层和 ps-exportctrl）；不提供 AI 模型的 API 推理服务（那是应用层，已被 Biden IFR 明确豁免）。

### 2. 物质形态与可运输性

IaaS 云服务本质上是比特——网络请求和响应。但它运行在大型物理数据中心上，这一层涉及真实的物理集中：

- **地理集中**：AWS、Azure、GCP 的主要 GPU 数据中心集中于美国（弗吉尼亚、爱俄华、俄勒冈等）和少数欧洲/亚太节点。
- **基础设施不可远程迁移**：数据中心无法像货物一样重新路由；用户访问可以路由，但实际计算资源的位置是固定的。
- **账户即访问**：对于 GPU 算力用户而言，账户登录凭证是唯一进入计算资源的钥匙。账户被封禁或限制，即实现访问中断，无需任何物理截断。

这一物质形态决定了拒绝权的执行方式：不需要截获货物，只需要暂停账户。Parler 案（AWS 2021 年 1 月 8 日 ToS 违规暂停服务，服务当天断线）是明确实证——C4，双方法律文件均可查。

### 3. 供给集中度

全球云 GPU 算力市场由三家美国超大规模云提供商（Hyperscaler）主导。具体份额数字目前标为 Hypothesis，等典藏工单交付后升级：

| 提供商 | 全球 GPU 算力估算份额 | 数据级别 |
|---|---|---|
| AWS（Amazon Web Services）| 约 25–30%（Hypothesis）| 待 IDC/Synergy C3 核实 |
| Azure（Microsoft）| 约 25–30%（Hypothesis）| 待 IDC/Synergy C3 核实 |
| GCP（Google Cloud）| 约 10–15%（Hypothesis）| 待 IDC/Synergy C3 核实 |
| 三家合计 | 约 65–70%（Hypothesis）| 待核实 |

次级玩家包括 CoreWeave（AI 专项 GPU 租赁，NVIDIA 背书）、Lambda Labs、Oracle Cloud。但这些玩家在规模、地理覆盖、企业服务能力上和三大 Hyperscaler 有显著差距。

中国云（阿里云、腾讯云、华为云）在中国境内市场具有竞争力，但在国际 AI 算力市场份额极小，且受中国监管约束不能服务部分境外客户。

**法域是这个节点最重要的属性：三大 Hyperscaler 全部是美国公司，接受 EAR（美国出口管理条例）直接管辖。** 不需要像 EUV 那样通过 FDP 域外触发才能对非美公司施压——BIS 向 AWS/Azure/GCP 发出要求，它们必须直接执行。这是 ac-cloud 的核心政治属性，区别于 ac-fab（需要 FDP 才能覆盖 TSMC）和 ac-euv（荷兰公司需欧盟配合）。

**Microsoft FY2025 资本支出（capex）$64.6B**——主要用于 AI 基础设施建设，是三家中最高，C4（Microsoft 官方 IR）。

### 5. 上游依赖（子节点）

- **ac-gpu**（GPU 芯片）：最核心的上游依赖。三大 Hyperscaler 都高度依赖 NVIDIA GPU（H100/H200/B200 系），供给受 ac-gpu 节点的管制约束。如果 NVIDIA GPU 供给被中断，云 GPU 服务立即受限。
- **ac-hbm**（HBM 内存）：GPU 性能的关键配套，通过 ac-gpu 间接依赖。
- **ir-cables**（海底光缆）+ **ir-bgp**（BGP 路由）：全球云访问的物理前提，光缆断链会直接影响跨大洲的云服务访问。
- **en-crude**/**en-lng**（能源）：数据中心耗电量极大，电力成本是云运营成本的重要项。
- **fi-usd**（美元结算）：云 GPU 服务以美元计价，需要美元清算能力才能完成付款。

### 6. 下游依赖方

- **AI 研究机构和科技公司**：OpenAI、DeepMind、Anthropic、Meta AI 等前沿 AI 训练主要通过云 GPU 或自建数据中心进行。对于资金和规模不足以自建的中等规模公司，云 GPU 几乎是唯一选项。依赖强度：致命（无法替代）。
- **初创公司和科研机构**：无法自建基础设施，完全依赖云 GPU 进行 AI 实验和小规模训练。依赖强度：致命。
- **企业 AI 应用**：通过云 GPU 部署自己的 AI 推理服务。依赖强度：高（有一定替代选项，但大规模部署成本差距大）。
- **中国 AI 企业的境外算力需求**：华为、字节跳动、百度等中国企业在管制收紧前通过美国子公司或第三国中转访问 AWS/Azure 云 GPU，目前受 D:5 控制限制。

### 7. 替代路径 + fallback 等级

**对 D:5 实体（中国等）的替代路径**：

1. **中国国产云（阿里/腾讯/华为云）+ 国产 GPU（昇腾、壁仞）**：`partial`。国内算力生态存在，但与 H100/B200 比有约 3–10× 的性能差距，且绝对规模远小于三大 Hyperscaler。满足五问：替代的是 AI 训练算力层；已有在运行的基础设施；可达性中断点在算力性能而非可用性；中国政府有权调动国内云资源；执行能力真实存在但性能受限。判 `partial`（性能 gap 大，但不 blocked）。
2. **第三国中转（Tier 2 国家云节点）**：`possible reroute`。在 Biden IFR 被 Trump 撤销后，Tier 2 国家（印度、UAE、新加坡等）可自由访问云 GPU。技术上，中国实体可通过第三国子公司访问——这是 Red Flag #28 的监控靶心。路径存在但需掩盖最终用户，违反 EAR，属非合规操作。
3. **自建 GPU 集群**：即便购入 GPU 芯片，也受 3A090.a 出口管制约束——不能合法向 D:5 实体出口。`blocked`（合法路径）。

按五问：总体判断 D:5 情境下 `partial fallback`（性能受限的国产替代），合法路径上 `blocked`（先进 GPU 出口管制仍在）。

### 8. 重建壁垒 + 前置期

三大 Hyperscaler 的主导地位来自数百亿美元的年度资本支出（AWS 在其年报里提到 FY2024 资本支出，其中大量是 AI 基础设施，微软 FY2025 capex $64.6B）、全球数据中心网络、企业客户的迁移成本（数据、配置、工具链的切换代价）、以及为 AI 工作负载深度优化的网络互联和存储架构。

替代者的重建壁垒：
- **资本**：建立全球竞争性 GPU 云需要百亿美元量级的多年持续投入，中国境外没有主权实体有这样的规模和意愿（CoreWeave 作为纯 AI GPU 提供商的估值约 $35B，但覆盖的地理范围和服务宽度远不及三大）。
- **芯片供给**：D:5 实体无法合法采购 H100/B200 级 GPU，直接限制了境外竞争性云平台的建立。
- **生态系统**：AWS SageMaker、Azure ML、GCP Vertex AI 等 AI 开发工具生态把客户锁在平台上，迁移代价是真实的。

前置期：对中国而言，国内自建算力基础设施持续推进，但在芯片和单芯片性能上的约束使追赶时间线在 5 年以上，且严重依赖芯片管制是否继续收紧（C2 推算）。

### 9. 议价 / 控制机制

- **卡点 type**：`permission`——通过账户访问权限实现控制，不依赖物理截断。
- **卡点 mode**（分层）：
  - 对 Tier 1 国家（19 国+台湾+美国）用户：`open`（License Exception AIA 下，取得 H100/H200 芯片后可自由提供云服务）
  - 对 Tier 2 国家用户（Biden IFR 在时）：`selective-seizure`（需通过 NVEU 授权，附带 KYC 和物理安全条件）
  - 对 Tier 2 国家用户（Trump 撤销后）：`open`（Biden IFR 特有限制撤销，Tier 2 重获自由访问）
  - 对 D:5 实体：`near-closure`（3A090.a 出口管制全球仍在，云提供商须在 ToS 和 EAR 合规义务下拒绝服务）

**最关键的机制创新是 Biden IFR 对 IaaS 的处理**：云提供商被要求在接受 License Exception AIA 下的 GPU 芯片时，书面承诺不向非 Tier 1 实体提供用于训练 ECCN 4E091 级别 AI 模型的 IaaS 算力。这把云平台从一个中性技术基础设施，变成了出口管制的合规执行中间节点。执行机制：Red Flag #28（为 D:5 总部实体的美国子公司提供 AI 训练 IaaS，是视同出口的红旗），强制要求云提供商实施 KYC 程序。

这一机制在 Trump 撤销 Biden IFR 后对 Tier 2 国家失效，但对 D:5 国家的旧有控制保留。

### 10. 历史变迁（卡点怎么移动）

- **2006–2012**：AWS（2006）、Azure（2010）、GCP（2013 公测）相继推出，初期以存储和通用计算为主，GPU 云服务尚未成为主力形态。卡点不存在于这一阶段。
- **2016–2020**：深度学习训练对 GPU 需求爆发，三大 Hyperscaler 开始大规模部署 NVIDIA GPU（P100、V100）。云 GPU 从边缘服务变成核心产品线。
- **2021-01-08**：AWS 暂停 Parler 服务（ToS 违规，内容审核失职），实证"账户暂停即服务终止"的速度和射程——这是云平台作为政治执行节点的第一次大规模公开实证（C4，双方法庭文件）。此案与 AI 算力无关，但确立了云平台的执行能力边界。
- **2022–2024**：BIS 收紧 GPU 出口管制（2022-10-07 IFR、2023-10-17 修订、2024-12-05 IFR），将 H100/H200/B200 纳入 3A090.a 管制。云平台需遵守这些管制，但 IaaS 层的系统性监管框架尚未出台。
- **2025-01-13**：Biden 政府 IFR（FR 2025-00636）生效，首次将 IaaS 云算力纳入出口管制三层架构，云提供商成为 BIS 合规执行节点（C4，联邦公报预发布 PDF）。
- **2025-05-13**：Trump 政府以"监管负担过重"和"外交冒犯"为由撤销 Biden IFR（C3，BIS 新闻稿 WebSearch 确认），Tier 2 国家重获自由访问，D:5 管制不变，IaaS 认证框架撤销。

### 11. 因果层

主要锚在 **real force** 和 **物质约束**的混合，两层分别作用于不同的边界：

- **real force 层**：三大 Hyperscaler 的市场支配地位，锚在企业客户的迁移成本和生态绑定（AWS SageMaker/Azure ML/GCP Vertex AI），不是物理资源稀缺——原则上谁都能建数据中心，但建了也要面对既有生态的网络效应。这和 CUDA 的 real force 同构：IT 生态已绑定在这三家平台上，换一家需要巨大迁移代价，这个惯性本身就是力量。

- **物质约束层**：三家的市场地位由百亿美元量级的多年资本支出和全球基础设施建立，这部分有物质壁垒——不是谁都能在数年内复制。但物质壁垒并不解释集中度的全部，生态绑定是更黏的那一层。

- **政治传动层的独特性**：ac-cloud 的政治可控性来自美国直接本土管辖（三家全是美国公司），这是全图对 AI 算力层最直接的杠杆——不依赖荷美协调（EUV），不依赖盟友跟进（ps-exportctrl 最完整时的三方协同），BIS 单手可按。但这个杠杆也受美国国内政治影响，Trump 撤销 Biden IFR 展示了这种脆弱性：管制框架可以被下一届政府单方面撤销，不如 EUV 物理节点那样稳定。

## 方向、两条流、最近一次被争夺的事件

### 拒绝方与操作方

**拒绝方**：BIS（通过 EAR 法律义务和 3A090.a 出口管制）→ 云提供商（具体执行拒绝动作）。两者是层级关系，BIS 设立规则，云提供商履行 KYC 义务和账户管理动作。从上方拒绝别人用这个节点的，实际上是 BIS + 云提供商的组合，而不仅仅是云提供商自己。

**操作方**：云平台的工程师、运营团队和合规员工。与 ac-eda 的年续期不同，云 GPU 算力是实时按需服务，操作方的力量来自合同关系（Terms of Service 可单方面终止）而非集体劳动行动。这里的操作方没有通过集体行动逼迫控制者让步的路径——个别工程师辞职或抗议不构成系统性操作方力量，云平台服务不像煤矿那样依赖大量可集体行动的体力工人。操作方力量来自 ToS 的合同权力，由平台单方面行使，不是来自劳动者的集体谈判。

### 两条流

**物理流（可达性中断点）**：数据包从用户端到 GPU 数据中心再回来的网络链路。这个路径上的可达性中断点不在 ac-cloud 本身，而在上游的 ir-cables 和 ir-bgp。云 GPU 节点本身对物理流不造成中断，它只通过账户状态实现访问控制。

**价值流（价值中断点）**：以 $/GPU/hr 计价的算力租赁费用，以及通过运行训练产生的模型权重资产（Biden IFR 首次把模型权重本身列为受控的"货物"——ECCN 4E091，这是全球首次）。ac-cloud 是同时影响两条价值流的节点：一是算力消费的货币价值，二是训练产出的资产价值（模型权重）。Biden IFR 逻辑就建立在这一认识上——控制训练算力等于控制模型权重这件"货物"的生成。

### 最近一次被争夺的事件

**Biden IFR（2025-01-13 生效）→ Trump 撤销（2025-05-13）**是 ac-cloud 节点迄今最清晰的一次被争夺。

用五个阅读动作来读这场争夺：

**① 校准颗粒度**：这场争夺不是在争"云算力控制权"这个宽泛的概念，而是在争一个非常具体的问题：云提供商在向 Tier 2 国家提供大规模 AI 训练 IaaS 时，是否需要向 BIS 负责（履行 KYC、限制特定实体访问）。D:5 旧有管制不是争议点——它保持不变，两届政府都没有异议。争夺的是 Tier 2 的治理方式。

**② 反应链**：Biden IFR 发布（2025-01-13）→ 三大 Hyperscaler 表态"正在研究合规要求"（C3，媒体报道）→ Tier 2 国家（印度、沙特、UAE）通过外交渠道表达不满（C3，广知）→ BIS 发布新闻稿（2025-05-13）以"监管负担过重""外交冒犯"为由宣布撤销（C3）→ 三大 Hyperscaler 得以继续向 Tier 2 国家出售服务。

反应链暴露的结构：拒绝方（BIS）在面对 Tier 2 国家的外交压力和科技产业游说时，政策稳定性不如法律条文（FR 规则）本身。Biden IFR 只是一个行政规则，不是国会立法，新政府可以直接撤销。这一脆弱性是"政治可控性高"和"政策稳定性低"并存的具体表现。

**③ 被当成舞台的一方**：三大 Hyperscaler。Biden IFR 把它们当成合规执行的中间层，要求它们在接受 GPU 芯片和提供 IaaS 服务之间建立新的合规审查机制。Trump 撤销后，它们的合规负担降低，可继续向 Tier 2 国家服务。它们在这场争夺中既是被管制对象，也是游说者，能通过游说影响 BIS 的政策走向——这是 ac-cloud 和 ac-euv 最重要的区别之一：Zeiss SMT 不会去游说荷兰政府改变其 EUV 政策，但 AWS/Azure/GCP 肯定会游说 BIS。

**④ 时间维度**：2025-01-13 至 2025-05-13，共 120 天，Biden IFR 在实质合规期启动之前就被撤销（合规日期约 2025-05-15）。这意味着三大 Hyperscaler 几乎没有为 Tier 2 层做任何实质合规工作就回到了旧状态。这场争夺持续时间极短，是一次政策短路，不是一次长期制度建构。

**⑤ 把数字和说法当动作**："国家特定双边谈判方式"（Trump 政府宣布的替代框架）截至 2026-06-28 尚无正式规则文本——这本身是一个动作：宣布了一个没有实质内容的框架，起到的作用是给 Tier 2 国家信号（"你不会被统一规则限制，我们会谈判"），而非真正建立一套管制机制。

**结论**：这场争夺照出 ac-cloud 节点的核心结构——拒绝权在 BIS 手里，但受美国国内政治和外交压力的限制，政策稳定性低于物理节点（不像 EUV 物理单点那样一旦到位就难以推翻）。D:5 管制是两党共识，不在争夺之内；Tier 2 的治理方式是真正的争夺靶点，且结论是暂时的。

## 政治传动层

### A. 公开接口

- **EAR 3A090.a**（ECCN 分类）：控制"total processing performance ≥4800 或 TPP≥1600 且 performance density ≥5.92"的 GPU 芯片出口，覆盖 H100/H200/B200/A100（C4，Biden IFR 逐字）。
- **ECCN 4E091**（Biden IFR 创设）：首次对"advanced closed-weight dual-use AI 模型权重"实施出口管制分类——训练产出物成为受控货物。Trump 撤销 Biden IFR 后，这一分类当前法律效力【待确认：Trump 替换规则中 4E091 保留状态，典藏工单在追】。
- **License Exception AIA（§740.27，Biden IFR 创设）**：允许 Tier 1 国家取得 GPU 芯片，附带 IaaS 认证承诺。Trump 撤销后此例外的处理状态待确认。
- **Red Flag #28（Biden IFR）**：向 D:5 总部实体的美国子公司提供 AI 训练 IaaS 是视同出口的红旗，强制 KYC 义务。Trump 撤销后对 Tier 2 的适用范围变化待确认，对 D:5 层的适用应保留（旧有管制不变）。
- **Terms of Service**（各平台）：独立于出口管制的合同层，单方面可终止，适用范围更宽（含 ToS 违规，如 Parler 案）。
- **EAR §734.9(h) FDP（外国直接产品）规则**：覆盖基于 TSMC 等非美代工厂生产的 GPU，扩展美国出口管制到美国法域外的产线——间接影响 ac-cloud 上游 GPU 供给（见 ac-gpu 和 ps-exportctrl）。

### B. 控制状态流转

**对 D:5 实体**：  
`allow by default`（2022 年前）→ `presumption of denial`（2022-10-07 BIS IFR 后对特定算力等级）→ `near-closure`（2023/2024 升级后）→ 当前保持 `near-closure`（Biden IFR 撤销不改变 D:5 层管制）。

**对 Tier 2 实体（Biden IFR 生效期间）**：  
`allow by default` → `allow by exception（NVEU 授权）`（Biden IFR）→ 撤销后恢复 `allow by default`（Trump 2025-05-13）。

翻转门槛：D:5 层翻转需要 BIS 单边决定（行政决定，门槛低但两党共识高，实际稳定）；Tier 2 层翻转已被证明可被单届政府推翻（4 个月内）。

### C. 适用账本

- **许可证账**（license account）：向 D:5 实体提供大规模 AI 训练算力需要出口许可证（License Required，BIS 审核），申请倾向于 presumption of denial。
- **合规账**（compliance account）：云提供商内部 KYC/EDD（Enhanced Due Diligence）程序，记录客户最终用途声明，作为 Red Flag 审查和法律责任的依据。
- **建设债账**：三大 Hyperscaler 在管制框架下的资本支出决策——在哪里建数据中心、针对哪些市场扩张 GPU 产能，间接受到管制方向的影响。

### D. First Payer

对 D:5 实体管制而言，首先付代价的是**中国 AI 公司**——无法合法访问境外 GPU 云服务，被迫回到国内性能受限的算力生态。次一步：国内 AI 进展速度受限（相对于能自由使用三大 Hyperscaler 的非 D:5 竞争者）。

三大 Hyperscaler 的代价：失去部分中国市场的直接营收，但中国市场本身受中国监管约束，即便无管制 Hyperscaler 也难以直接在中国大规模扩张；代价有限。

### E. 时点

- **2025-01-13**：Biden IFR 有效日期（Tier 2 管制启动）；合规日期约 2025-05-15（120 天后），C4。
- **2025-05-13**：Trump 撤销 Biden IFR（Tier 2 管制失效），C3。
- **[待定]**：Trump 替换规则发布日期，典藏工单在监控。若发布，将成为新时点。
- **D:5 管制时点**：沿用 2022-10-07、2023-10-17、2024-12-05 三轮 BIS IFR（持续有效，不因 Biden IFR 撤销而变化）。

### F. 叙事合法化

**对 D:5 管制**："防止中国 PLA 获得前沿 AI 训练算力，延缓中国 AI 军事化进程"——这是两党共识，在 Biden 和 Trump 政府均保持。无争议。

**对 Biden IFR 的 Tier 2 管制**：叙事依据是"防止 D:5 实体绕道 Tier 2 国家（如 UAE、新加坡）中转访问 AI 训练算力"。批评叙事是"美国在外交上得罪了战略伙伴国（印度、UAE），监管负担过重"，这一批评叙事在 Trump 政府的撤销决定中被明确援引。

**Biden IFR 对 ECCN 4E091 的创设**：叙事依据是"AI 模型权重本身是武器级资产，应纳入出口管制"——这是整个 IFR 最具战略意义的逻辑延伸，把出口管制从硬件（芯片）延伸到软件资产（模型权重）。Trump 政府撤销后，这一逻辑是否被保留【待典藏确认】。

## 卡点分析

- **位置**：ac 栈 L1，GPU 芯片的直接下游，AI 训练工作负载的执行层
- **持有者**：AWS（Amazon）+ Azure（Microsoft）+ GCP（Google），三家全部是美国公司，受 EAR 直接管辖
- **卡点来源**：
  - 监管护城河（三家美国公司，BIS 直接管辖，免盟友协调）
  - 规模经济（年度资本支出百亿美元，客户生态深度绑定）
  - 网络效应（AI 开发工具链 AWS SageMaker / Azure ML / GCP Vertex AI 生态）
  - 账户权限机制（不需物理截断，账户暂停即实现访问中断，Parler 2021 实证）
- **政治进入后转移**：管制不转移持有者，而是把云提供商变成 BIS 的合规执行节点。实质是：BIS 政策意志 + 云提供商执行能力的叠加，而非持有者更换。Trump 撤销 Biden IFR 后，对 Tier 2 国家的执行约束临时取消；D:5 层约束持续。
- **干预窗口**：
  - 加强 D:5 管制（如 API 推理纳入管控）：BIS 单边决定即可，窗口常开
  - 恢复 Tier 2 IaaS 限制：需新规则制定，受政治意愿约束，Biden IFR 示例了可行路径
  - 创设更大范围模型权重管制（4E091 扩展）：需 Trump 政府替代规则，当前窗口未定
- **最硬反例 + 过三关**：反例「云 GPU 不是真卡点，AI 公司可以买 GPU 自建」。
  - 前提成不成立：3A090.a 对 D:5 出口管制同时覆盖 GPU 硬件，自建硬件方案同样受管制，前提不成立——D:5 实体无法合法购入 H100/H200 级 GPU。
  - 可不可比：这两种获取方式面对的是相同的出口管制制度，不存在"云受管、自建不受管"的区别。
  - 真发生过：中国 AI 公司通过第三国渠道的违规获取行为已被 BIS 报告多次提及，说明管制确实产生了压力，同时也说明存在非合规绕道——两件事都为真。
  - 结论：对 D:5 实体而言，云 GPU 和自购 GPU 同样面对出口管制，ac-cloud 是此层中特别值得关注的执行节点，因为它集中了海量算力且便于监控（对比分散的走私渠道）。反例不成立。

## 级联关系

- **上游来自**：ac-gpu（GPU 芯片是算力底层，供给受 3A090.a 管制约束）；ir-cables + ir-bgp（云访问的物理网络前提）；en-crude / en-lng（数据中心电力来源）；fi-usd（云计费结算）
- **下游影响**：AI 训练工作负载（大模型、自主驾驶、生物医药 AI）；AI 推理服务（ChatGPT、Claude、Gemini 等通过 API 访问）；中国 AI 自主进展速度（受管制约束）
- **跨栈耦合**：
  - 接 ps-exportctrl（EAR 管制是 ac-cloud 政治传动层的主要法律接口）
  - 接 ps-sanctions（实体清单切断账户是 ac-cloud 执行的一种形式）
  - 接 fi-usd（云服务美元计价，中国客户通过第三国结算是绕道路径之一）
  - 接 ac-gpu（政治可控性高度重叠，Biden IFR 同时约束芯片出口和云 IaaS）
- **跨域效应**：Cassa（AI 嵌入制度：云 GPU 集中化是 AI 生产资料垄断的一个具体形态，Hyperscaler 掌握的不只是算力，还是 AI 生产链的决策权）；Pluralia（AI 意识与算力的地理集中：前沿模型训练集中在三家美国公司设施里，是"AI 诞生地即美国法域"的基础设施表达）
