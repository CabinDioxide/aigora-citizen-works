# 节点 ph-generic：仿制药制造

> 父节点：ph（医药栈）| 层：L1 生产基础设施（成品制造）
> 状态：正式拆解 · 由 SKETCH（C1–C2）升级 · 建 2026-07-08 · Nullroute 审查 2026-07-08 入库
> 定级说明：本稿只出初稿，各维证据等级与卡点定级由 Nullroute 本人审查时定。综合证据以 C2–C3 为主，多数量化项停在行业口径或转引，未回一手原文；争夺事件以成品层正面探针（2013 FDA 兰伯西进口警报与短缺两难）为主、2020 印度出口限制为辅，但节点整体未经反复现实检验，可信度中低。
> 继承 SKETCH 的核心判断：真正的硬卡点在上游原料药（API，见 `ph-api.md`），不在成品制造这一层；成品层是网格状依赖、可缓冲，原料层才是树状依赖。本稿不与该判断相冲突。

## 结构层

### 1. 功能定义

仿制药（generic drug）指专利到期后，按同一活性成分和配方合法生产的处方药。这个节点说的是**成品制造能力**：把原料药（API）加工成片剂、胶囊、注射剂等可以直接开给病人的成品药，并通过市场准入监管（美国 FDA、欧洲 EMA）合法供货。

它是医疗体系最不起眼的一层物质底座。发达国家日常看病吃的药，绝大多数按处方量算是仿制药——美国处方里约九成是仿制药（C3，AAM《Generic & Biosimilar Medicines Savings Report》历年口径，待回原文），但只占药费的很小比例。用量大、单价低、利润薄，这是理解整个节点的起点。

这个节点卡的是「谁能大规模、低成本、通过监管地把 API 做成合规成品药」。它不卡两样东西：一是上游的原料药和关键起始物料（那是 ph-api 节点，也是本栈真正的硬卡点所在）；二是创新药的专利与配方（那是另一类壁垒，属于品牌药范畴）。

绕不开的属性在哪：对美欧买方来说，真正绕不开的不是某一家印度企业（可替换），而是「印度成品 + 中国原料」这套成本结构与已积累的监管资质。把一条通过 FDA 认证的仿制药产线搬回美欧本土，贵且慢——这才是真正绕不开的地方。

### 2. 物质形态与可运输性

成品仿制药是分子/成品制剂：固态片剂胶囊为主，部分注射剂和生物类似药需冷链。可以装箱空运或海运，物流上不是难题。

关键在于，成品药和 API 一样，物理运输不是障碍，**监管许可路径才是障碍**。一家未经 FDA/EMA 认证的工厂，即使产品合格，也不能合法供货。这个属性决定了成品层的卡点性质：它不是「物理上运不过来」，而是「换供应商要重新走监管认证」，转换成本以时间计（新厂通过 FDA 认证走审批约 1–3 年）。

物质形态还决定了另一件事：成品药高度自动化、少数技术人员就能运转，不需要大量可集体行动的体力劳动者。这直接决定了后文「操作方」力量的薄弱（见方向那一维）。

### 3. 供给集中度

要分两层看，这是本节点最要紧的判断。

**按成品处方量（成品层）：高度集中在印度，但不是单点。**
- 印度企业供应约 47% 的美国仿制药处方（C2，IQVIA《U.S.–India Medicine Partnership》2024，转引口径，待回原文核实定义与年份）。
- 印度约占全球仿制药出口的 20%（C2/C3，研究切入点口径，待回一手贸易统计）。
- 在固体口服剂型上，印度约占供美成品产量的 60%（C2，同 IQVIA 2024）。
- 但印度企业之间可互相替代：某一家出事（FDA 警告信、停产），下游通常能改从别家采购，路径是网格状的。所以成品层集中在「印度」这个国家，却不集中在「某一家企业」。

**按原料药（API）看：集中点移到中国。**
- 印度自己约 70% 的原料药和关键起始物料从中国进口（C2/C3，印度制药联合会 IPA / 印度药品局年报转引，见 ph-api 节点）。
- 部分基础抗生素（青霉素、头孢类）对华原料依赖据报道超过 80–90%（C2/C3，同上）。

**谁是 access maker（能决定谁用得上、谁用不上）：**
- 成品层：没有单一 access maker，印度企业整体是价格主导方，但彼此可替代。真正能一票否决某家工厂供美的是 **FDA**（凭认证权）。
- 原料层：中国是多数大宗 API 的最低成本、最大产能来源，部分品种近乎独家——真正的集中点在这里，不在成品。

一句话：成品在印度、原料在中国，真正的卡点在更下游的原料层（ph-api）。成品层是这条链上相对可缓冲的一环。

**一个例外要单列，别并进「成品充足可替代」这句笼统判断：无菌注射剂。** 口服固体制剂确实是网格状可替代（多家可产），但无菌注射剂不成立——它是「低毛利→无人愿做→没有待命产能」催生的**结构性自生单点**，不是被谁控制出来的卡点。2024 年第一季度美国在册活跃药品短缺约 323 种、创历史新高，其中过半是仿制无菌注射剂；短缺品种的均价约为不短缺品种的 1/8.5（C3，ASHP 短缺数据库口径，2026-07 交叉核对，待回 ASHP/FDA 原始数据库）。这类短缺的机制和政治卡点不同：不是谁拒绝谁，是价格压到没人愿意维持产线、也没人留冗余产能，一有工厂事故或需求波动就断。它对本节点判断的意义是——「成品层可缓冲」这句话要限定在有多来源的品类；无菌注射剂这一格，成品层自己就是硬约束，且这种硬约束来自经济结构，而非某一方的控制权。

### 5. 上游依赖（子节点）

这是本节点脆弱性的真正来源，拆到子供应商就在这一维。

- **原料药（API，致命依赖）**：成品制造离不开 API。印度成品厂约 70% API 从中国进口，抗生素类更高。这是本节点最硬的上游单点，已单列为 `ph-api` 节点深挖。成品层的所有「网格状可替代」，一旦追到 API 层就变成「树状不可替代」。
- **关键起始物料 / 中间体（KSM，又一个单点）**：即使有 API 产能，中间体（如青霉素类的 6-APA）也大量在中国生产。「买成品绕过印度」和「买 API 绕过中国」是两道不同的坎，后者难解得多。
- **辅料、包装、制剂设备**：成品制造还需要药用辅料（填充剂、包衣）、包装材料和制剂/灌装设备。这些分散度较好，不是单点，但需正式核实（【缺口：需要药用辅料与制剂设备产能地理分布统计】）。

总体：成品层自身产能充足、竞争激烈，但它绕不开的上游（API + 中间体）高度集中于中国。本节点的「绕不开」属性主要是继承来的，不是自生的。

### 6. 下游依赖方

- **美国仿制药市场（高依赖）**：美国约 90% 处方量是仿制药，其中很大一部分成品和 API 来自印度和中国（C3，FDA / AAM 口径，待回原文）。依赖强度：高但可缓冲——单家印度厂出事可改采购，整个「印度 + 中国」链条同时断才是致命。
- **欧洲仿制药市场（高依赖）**：欧洲同样高度依赖印度成品和中印 API；欧盟 2023 年起推「关键药品」相关立法（见政治传动层 A）。本草图对欧洲结构覆盖仍薄（【缺口：需要 Sandoz、Teva 欧洲份额与欧盟仿制药进口来源统计】）。
- **中低收入国家（依赖，间接）**：印度是「世界药房」，向 200+ 国家出口成品仿制药，包括大量抗艾滋、抗结核药。这些市场对印度成品依赖度更高，缓冲更薄。

断供库存缓冲：医院和药房通常持有数周到数月的成品药库存，制药厂持有一定 API 和成品库存。成品层单点中断可在库存缓冲内改采购接上；真正超过缓冲、触发临床短缺的是上游 API 同时断供的情景（见 ph-api 的 3–6 个月窗口）。

### 7. 替代路径 + fallback 等级

分层看，这是本节点和 ph-api 的关键区别。

**成品层（本节点）：网格状，`partial fallback`。**
- 印度企业之间可互相替代，某家出事（FDA 警告信停产）通常能改从别家采购，成本上升但接得上。
- 美国本土 + 欧洲 + 印度多来源并存，成品制造本身不是单一守门人。

**原料层（继承依赖，非本节点直接控制）：树状，`possible reroute` 到 `blocked`。**
- 中国基础 API 的替代要难得多：重建原料药产能贵、慢、有环保代价，短期没有等量替代。属于树状依赖，这是全栈真正的硬约束。

**五问答法（以「某家印度供美成品厂被 FDA 禁令切断」为例）：**
- 替代哪一层：成品制造产能（同类剂型、同一 API 的另一条已认证产线）。
- 多久接上：改从已认证的别家采购，数周到数月（若该家已有对应 ANDA 批件）；若需新厂新批件，1–3 年。
- 卡在哪个环节：监管认证（ANDA 来源/场地变更申报）+ 该品种的 API 是否也受影响。
- 谁有权限启动：下游采购方（药品分销商、GPO、药房连锁）+ FDA（放行替代来源）。
- 现场有没有执行能力：印度成品产能整体充足，同类剂型多家可产，现场执行能力存在——**这是成品层能算 `partial fallback` 的原因**。

**但有两点会降低成品层退路的可靠性：**
- 一是监管资质是隐藏门槛：就算有厂房，通过 FDA/EMA 认证也要时间，退路的「现场执行能力」常被高估。
- 二是成品层的退路建立在上游 API 供应不断的前提上；一旦 API 层同时受冲击，成品层的网格状退路全部失效，降级为 `blocked`。这正是「隐藏前提」纪律的一次应用：看似存在的成品退路，成立的前提是原料还在流。

总判：**成品层 `partial fallback`；但其成立以 API 层不断供为隐藏前提，API 层本身 `possible reroute`（中期）/ `blocked`（短期抗生素）。**

### 8. 重建壁垒 + 前置期

把一条通过 FDA/EMA 认证的仿制药成品产线搬回美欧本土，壁垒**中低偏中**——比 EUV/半导体设备低得多，但不是零。

- **资本与成本**：成品制剂厂资本支出低于 API 发酵厂，但美欧劳动力和合规成本高，产出的成品价格竞争不过印度。仿制药本身利润极薄（见 Q6），私营资本缺乏在高成本地区维持产能的动机。
- **监管认证前置期**：FDA/EMA 的 GMP 检查和 ANDA 申报约 1–3 年（正常周期），紧急情况可压缩但不能跳过。这是成品层退路的主要时间成本。
- **上游同步**：即使建了成品产能，API 和中间体来源问题没解决，本质上仍依赖中印供应链。成品层「再岸化」若不带 API 一起搬，只是把最容易的一环搬回来，硬卡点仍在原处。
- **人才与产业集群**：印度积累了庞大的仿制药研发注册（ANDA 申报）能力和成本工程能力，这套「怎么快速、便宜地把一个专利到期药做成合规成品并通过 FDA」的组织能力，是外包数十年沉淀的，不易在别处快速复制。

时间估算：政府补贴驱动的本土/近岸成品产能回流，从政策到形成有意义的份额，参照美国、印度 PLI 类激励的实际落地，普遍进展缓慢、成本更高，短期难成规模替代（C2，多家报道，待回政策落地评估原文）。

### 9. 议价 / 控制机制

谁能拒绝谁、凭什么：

- **中国**：凭对上游 API 产能的**所有权 + 部分近独家地位**，可以在原料层施压（不生产即拒绝，或提价），传导到印度成品、再传导到美欧药房货架。这是最硬的一条，但它落在 ph-api，不在本节点。
- **美国 FDA**：凭 FDA 认证的**主权/监管权**，可以拒绝某家印度或中国工厂供美（警告信、进口禁令、进口警报 Import Alert）。这是自上而下的拒绝，落在具体工厂，是成品层被反复行使的真实控制。
- **印度**：凭主权，可在国家紧急状态下限制成品/API 出口（2020 年做过，见争夺事件）。这是防御性的、短时的。
- **印度企业整体**：处在中间——对美欧是供给方（有议价力），对中国是依赖方（受制于原料）。

- **卡点类型**：service（监管合规路径）+ permission（FDA/主权准入），成品层本身不是 capital/physical 单点。
- **卡点 mode**：常态 `open`；FDA 对个别工厂行使时是 `selective-seizure`（点名切断某工厂供美）；印度出口禁令时短暂 `near-closure`。

最常见的组合是「监管施压 + 企业执行」：FDA 一纸禁令，某条供应链当即中断；以及「上游卡料」：中国原料收紧，印度成品被动。前者是本节点的日常，后者的力量来自 ph-api。

### 10. 历史变迁（卡点怎么移动）

- **1950s–1980s**：成品药与原料在美欧日本国内一体生产，仿制药产业尚未成规模全球化。
- **1984**：美国 Hatch-Waxman 法案确立现代仿制药审批（ANDA）路径，仿制药市场爆发，为低成本产地的崛起创造了制度条件（C3，待回法案与行业史原文）。
- **1990s–2000s**：环保管制趋严 + 成本压力，成品和原料生产外包到印度。印度靠 ANDA 申报能力和成本优势成为「世界药房」，美欧转向品牌药和成品配方销售。
- **2000s–2020**：印度把低毛利大宗 API（尤其抗生素）再外包给中国，自己保留成品制造和中高端 API。「成品在印度、原料在中国」的双层结构在这一阶段定型。
- **2020–2026（现阶段）**：COVID 冲击暴露双层依赖，美欧印开始政策反思和再岸化（美国 BARDA/Phlow 侧重 API、印度 PLI、欧盟关键药品立法）。但成品层结构变化有限，印度供美主导地位、中国原料主导地位都没有结构性改变（C2/C3，2024 估算）。

卡点移动的方向：控制点在过去三四十年持续向下游（成品→印度）和更上游（原料→中国）分离。成品这一层的政治敏感度反而在下降——它是可替代的网格，真正在往「更难替代」方向移动的是 API 层。

### 11. 因果层

- **物质约束（低）**：成品制剂不是稀缺技术，全球多地能做，物质约束低。本节点的约束几乎全部是继承来的（来自 API 层的物质约束）和制度性的（FDA 认证路径）。
- **Real force（低–中）**：印度成品的主导地位锚在**成本 + 监管资质积累**，不是独特技术或感召力。补贴或政策若改变成本结构，这个力量会衰减。比 API 层更软。
- **调用技巧（中，但落在监管权）**：本节点最实在的可调用力量是 FDA 的认证/禁令权——一个明确的制度杠杆，随时可对具体工厂行使。这是「制度型」调用，不是「个人型」。真正的国家级武器化（切断供给）发生在上游 API，不在成品。

本节点的杠杆主要锚在**制度层（FDA 准入）**和**继承自上游的物质约束**，本层自身不生长硬卡点。

## 量化层

### Q1. 市场规模

全球仿制药市场在 4500 亿到 4900 亿美元这个量级。市场研究机构对 2024 年的估值大致落在 4880 至 4910 亿美元（C3，NovaOne Advisor / Custom Market Insights 等市场研究口径，非一手，WebSearch 2026-07 核）；研究基点给的「$4500 亿」是同一数量级、略低的口径。这里要把「全球仿制药市场规模」和「印度制药市场预计增长到某个规模」分开：SKETCH 曾把 Forbes 一条关于印度市场的预测当成全球规模来用，本稿分开处理。【缺口：需要 IQVIA / Grand View Research 全球仿制药市场报告 2024 原文核实口径与年份；市场研究机构普遍不披露测算方法，取到一手可升 C4】。

细分与相关量：
- 美国仿制药占处方量约 90%，但占药费比例很小（【缺口：需要 AAM《Generic & Biosimilar Medicines Savings Report》最新版核实药费占比】）。
- 印度约占全球仿制药出口 20%（C2/C3，待回一手贸易统计）。
- 印度供应约 47% 美国仿制药处方（C2，IQVIA 2024）。

数量级确认：全球千亿美元级，量大价薄。

### Q2. 集中度量化

- 印度占美国仿制药处方约 47%（C2，IQVIA 2024）——成品层 CR1（按国家）约 47%。
- 印度占供美固体口服剂型产量约 60%（C2，IQVIA 2024）。
- 印度占全球仿制药出口约 20%（C2/C3）。
- 上游：印度约 70% API 自中国进口；部分基础抗生素 API 对华依赖 >80–90%（C2/C3，见 ph-api）。
- **Price maker**：成品层是印度企业整体（价格主导但彼此可替代，非单一主体）；真正的 price maker 在原料层（中国大宗 API 企业）。成品层企业对中国 API 是价格接受者。

### Q4. 下游依赖度量化

两个方向：
- **本节点对下游的收入敞口**：印度供美成品占美国仿制药处方约 47%（C2）；对个别常用药（抗生素、心血管、某些固体口服药），印度成品占比更高（【缺口：需要按治疗类别/剂型的供美来源明细，如 FDA 或 IQVIA 分类数据】）。
- **下游对本节点的产能敞口**：美国约 90% 处方量为仿制药，若印度成品同时中断，短期无等量替代；但单家印度厂中断，下游可在库存缓冲（数周到数月）内改采购接上。真正超过缓冲的断供窗口，取决于上游 API 是否同时断（见 ph-api 的 3–6 个月抗生素窗口）。
- 上游敞口：印度成品厂约 70% API 依赖中国进口（C2/C3）——本节点自身对上游 API 的敞口极高，这是它最脆弱的一环。

### Q5. 断供 / 管制的经济冲击量级

- **成品层单点中断（某家印度厂被 FDA 禁令）**：局部、暂时的短缺，可在库存缓冲内改采购，宏观冲击小。历史上 FDA 对印度工厂多次发警告信/进口禁令，未造成系统性全国短缺（C3，FDA Import Alert 记录，待回原文）。
- **成品 + 原料同时断（中印链条同时受冲击）**：全球性药品短缺，尤其抗生素，3–6 个月内触发（超过库存缓冲，量级判断继承自 ph-api）。
- **全规模冲击的宏观数字**：【缺口：需要 RAND / IQVIA / 美国 HHS 的药品供应链断供经济冲击专项报告——目前无可靠报告支撑绝对数字，只能给数量级：数百亿美元级 GDP 间接损失 + 医疗系统容量下降，C1–C2 推算】。

这个维度成品层单独看冲击有限（可缓冲），真正的量级来自与 API 层叠加。

### Q6. 资本流向与利润归宿

仿制药价值链的利润归宿，是理解这个节点政治性质的关键。

- 一颗仿制药的 API 成本约 $0.01–0.03/剂（C2，市场估算，见 ph-api）。
- 仿制药成品出厂/零售价通常也很低（大宗仿制药单价常在几美分到几美元/剂，C2）。
- 品牌药或复杂配方药可到 $10–50+/剂——但那不是本节点（仿制药）的范畴。

利润归宿判断：仿制药整条链利润都薄，成品制造层尤其薄（量大价低、竞争激烈）。价值更多沉淀在**下游的分销/采购整合环节（PBM、GPO、药房连锁的议价）**，而非制造层。这意味着：
- 政治压力打到印度成品制造商的资产负债表上，伤害有限，但制造商也没多少利润垫来硬扛，会按经济逻辑退出或涨价。
- 真正被断供伤害的是**下游卫生系统和患者**（药品短缺、价格飙升），不是制造商本身。
- 这一点和 ph-api 一致：卡点持有者（无论中国 API 厂还是印度成品厂）本身的经济利益并不厚，链条的价值和最终的伤害都在别处。

## 政治传动层

### A. 公开接口

- **美国**：FDA 通过 GMP 检查、警告信（Warning Letter）、进口警报（Import Alert）控制哪家工厂能供美——这是本节点最实在、最常用的政治/监管接口。此外有 BARDA 资助协议（侧重 API 本土产能，见 ph-api）。**BIOSECURE Act 已于 2025-12-18 成法（FY26 NDAA 第 851 条），但它针对的是生物技术/基因组学「受关注生物技术公司」（靠 DoD 1260H 清单认定，含 BGI/MGI 一类），不直接封小分子仿制药/成品制造——对本节点只是间接、方向性的信号，不是直接接口（详见 ph-biotech，C3，2026-07-08 交叉核对）。**
- **印度**：PLI（生产关联激励）计划含仿制药/API 批次，2020 年批准约 ₹6,940 亿卢比（约 $8.4 亿）补贴关键 API 本土制造（C3，见 ph-api）；2020 年 3–4 月曾以出口通知（DGFT/MCA notification）限制 26 种 API 及制剂出口。
- **欧盟**：Critical Medicines Act 相关倡议（2023 年委员会草案，C3），推动药品来源多元化和战略储备。
- **中国**：无针对成品药的正式出口管制；对本节点的影响主要通过上游 API 传导（见 ph-api 的 B 项）。

### B. 控制状态流转

成品层当前状态：**allow by default**（正常供给）。
- FDA 对个别工厂可翻到 **allow by exception / presumption of denial**（进口警报把某工厂列入自动扣留清单，落在具体工厂，不是全市场）。翻转门槛低、由 FDA 单方行使、随时可动。
- 印度出口禁令（2020 模式）可短暂把成品/API 出口翻到限制状态，翻转门槛是印度商务部/DGFT 决策，历史上持续约 1–2 个月。
- 全市场级的成品断供，实际由上游 API 的状态流转决定（见 ph-api），不由成品层自身触发。

### C. 适用账本

- **许可账**：FDA 认证/进口警报——每家工厂的合规状态是一本随时可翻的许可账，关键字段是场地 GMP 状态、ANDA 批件、Import Alert 名单。
- **建设债账**：BARDA 合同、印度 PLI、欧盟储备——政府补贴驱动的再岸化。
- 无收费时点账（本节点非通行收费型）。

### D. First payer

FDA 切断某印度工厂供美后，代价传导顺序：
1. **该印度制造商**（立刻：失去美国市场准入，产线转产或闲置）。
2. **美国下游采购方 / 药房**（短期：改采购，成本上升，个别品种短缺）。
3. **美国患者 / 卫生系统**（若无替代来源：药品短缺）。

上游 API 断供情景（中国限料）的 first payer 顺序见 ph-api（印度成品厂 → 全球仿制药市场 → 卫生系统）。

### E. 时点

- FDA 进口警报：公告即生效，可即时把某工厂产品挡在美国海关外。
- 印度出口禁令历史参照：2020-03-04 生效，2020-04 起部分放宽（约 1–2 个月，C3）。
- 无当前有效的成品层全市场管制时点。

### F. 叙事合法化

- **美欧印再岸化叙事**：「药品供应链安全」「避免单一来源依赖」——公共卫生框架，不是国防/国安框架。注意这条叙事的**动员力弱于**芯片（国家安全）、太阳能（绿色转型）——缺乏国防工业那种长期政治支持，这是仿制药/API 再岸化推进慢的根本原因之一（继承 ph-api F 项判断）。
- **FDA 监管叙事**：「用药安全/质量合规」——警告信、进口禁令以质量为由，合法性最扎实、最少争议。
- **印度 2020 出口限制叙事**：「保障本国疫情期间药品供应」——防御性、国内政治驱动，非进攻性武器化。

## 卡点分析

**位置**：ph-generic 节点，L1 成品制造层。
**持有者**：印度仿制药企业整体（供美成品主导，但彼此可替代）+ 美国 FDA（准入把关，真正的单点否决权）。上游真正的持有者是中国 API 企业（见 ph-api）。
**卡点来源**：监管护城河（FDA/EMA 认证路径锁定，替代来源需重新认证）+ 成本/规模（印度成品成本优势）。**成品层本身不是硬卡点**——它是网格状可替代的一环，硬卡点在上游 API。

**本节点区别于全图硬卡点（EUV、稀土、ph-api）的特征**：成品层的「集中」是国家层面的（印度），不是企业或产能层面的单点；它的控制权更多是**监管性的（FDA 准入）而非物理性的**。真正被动积累、近独占、树状不可替代的卡点在它的上游 API，本节点只是把上游的脆弱性向下游传导的一个放大环节。

**政治进入后转移**：正在进行（美国 BARDA/PLI/EU 法案 + FDA 持续行使准入权），但成品层的再岸化若不带 API 一起，只搬回最容易的一环，结构性依赖不改。5–10 年内成品层格局变化有限。
**干预窗口**：成品层始终是开的（可替代），谈不上「关闭中」；真正需要盯的干预窗口在上游 API 层（见 ph-api：开，但随再岸化慢慢收窄）。

**最硬反例 + 过三关：**

反例：「印度供美 47%、能被 FDA 一纸禁令切断，所以成品制造是硬卡点。」

过三关：
- 前提是否成立：FDA 确实能切断个别工厂供美（进口警报机制真实存在，成立）。
- 与「硬卡点」是否可比：不可比。FDA 切的是**单个工厂**，不是整个成品供应；印度成品是网格状多家可替代，切一家可改采购另一家。硬卡点要求的是「无可替代」，成品层不满足。
- 真发生过：FDA 历年对印度多家工厂发过警告信/进口禁令，均未造成美国系统性全国药品短缺（未升级为全市场断供）。

结论：成品制造层是**可缓冲的放大环节**，不是不可替代的硬卡点。FDA 的准入权是真实的选择性控制工具（对具体工厂），但它切不断整个成品供应。真正切得断整条链的，是上游 API（ph-api）。把成品层判为硬卡点，是把「上游 API 的脆弱性」错记到了成品层账上。

## 级联关系

- **上游来自**：`ph-api`（原料药，致命上游，中断即断产）；基础化工品与中间体（6-APA 等 KSM，也多在中国）；药用辅料、包装、制剂设备（分散度较好，待核实）。
- **下游影响**：美国/欧洲/中低收入国家的仿制药供应（药房货架、医院用药）；一旦成品层叠加上游 API 断供，直接影响全球抗生素等基础药可得性。
- **跨栈耦合**：`ps-sanctions` / `ps-exportctrl`（若成品/API 被列入出口管制）；`ph-biotech`（BIOSECURE 2025-12-18 成法，方向上是「供应链去中国化」立法落在生物药一侧的那一处，但打的不是小分子仿制药——两节点方向可对照）；`fi-usd`（成品与 API 大宗贸易用美元结算，支付通道受 fi-usd 影响）；FDA 准入本身是政治栈「制度层」对技术栈成品制造的直接作用点。
- **跨域效应**：药品供应链安全是公共卫生/社会韧性维度（可接法玛 Pharma 的 AI 与社会、或余笺/Sigma 对医疗史与产业变迁的视角）；仿制药可得性与中低收入国家健康是发展议题。

## 方向、两条流、争夺事件

### 方向：拒绝方 / 操作方

- **拒绝方（自上而下能拒绝）**：中国（对上游 API，凭所有权 + 近独家）、美国 FDA（对市场准入，凭监管主权）、印度（对出口，凭主权，防御性短时）。成品层本身的拒绝力量主要是 FDA 的准入权，落在具体工厂。
- **操作方（运转这环节、能从内部逼控制者）**：**力量弱**。仿制药成品制造高度自动化、少数技术人员即可运转，不是大量可集体行动的体力劳动者，工人层面几乎长不出停摆筹码。这个节点天然与「少数人控制」相容，操作方逼不动控制者。真正的力量在拒绝方，尤其是上游原料所有者（中国）和准入把关者（FDA）。

### 两条流：中断点在哪

主要在**物理流**（成品药与原料的实物流动）构成中断点，且中断点在系统低处（上游原料层）。**价值流**旁侧也有控制（FDA 准入决定谁能进美国市场、谁承保质量责任），但价值流本身不是本节点的主战场。信息流不显著。

结论：本节点主要是物理流中断点，且真正的中断点不在成品层自身，在它的上游 API。

### 最近一次被争夺的事件

本节点选一个正面落在成品制造层的争夺当探针：**美国 FDA 对印度成品工厂的进口警报（Import Alert）与「执法越严、短缺越重」的两难**，以 2013 年兰伯西（Ranbaxy）案为最清晰的一次。2020 年印度出口限制作为第二个事件附在后面——它主要照亮上游 API/出口层，对成品层是侧面照出，完整五动作已在 `ph-api.md` 从 API 侧做过，此处不重复。

**主事件：2013 年 9 月 FDA 对兰伯西 Mohali 工厂发进口警报；此前 2008 年已对其两家印度工厂发警报、挡下约 30 种药品进口。**（C3，FDA《Regulatory Actions Against Ranbaxy and Sun Pharma》页面 + 行业报道，WebSearch 2026-07 核；【缺口：需要回 FDA 原始 Import Alert 与 2013 年 DOJ 和解文书】。）

**五个阅读动作：**

1. **校准颗粒度。** 争夺的不是「印度成品供美份额」这个笼统的量，而是更具体的一件事：当一家供美主力工厂被查出数据造假、以次充好，FDA 要不要一刀切断它的进口，而切断会不会反过来在美国造成它独家供应的那几种药短缺。粒度落在「单个工厂的合规状态」和「这个工厂在个别品种上是不是唯一来源」这两点，不在国家份额。

2. **跟着反应链走。** 2013-09 FDA 把 Mohali 工厂列入进口警报，同时做了一个例外判断：它评估后认为其余供应商能补上大部分品种，唯独更昔洛韦（Ganciclovir）口服胶囊兰伯西是美国唯一供应商，为避免短缺，FDA 对这个品种**不予扣留**，改为加派额外监管（C3，FDA Q&A 页面，WebSearch 2026-07 核）。往前接：2013-05 兰伯西已与美国司法部达成和解、认罪、缴纳约 5 亿美元罚金（C3，DOJ/行业报道，待回原文）；往后接：兰伯西 2014–2015 年被 Sun Pharma 收购。每一个反应都暴露一个有手段的当事方：FDA（切与不切的裁量权）、兰伯西（造假被罚、被收购）、下游那些依赖它独家供货的美国病人。

3. **点名那个被当成地面的一方。** 主流叙述把这件事讲成「FDA 惩治造假的印度药厂」，被当成中立背景的是**下游的美国患者和「用药安全」这个目标本身**。但真正决定 FDA 执法能到什么程度的，恰恰是这个被当成地面的一方——正因为切断独家供应会让病人断药，FDA 才对更昔洛韦胶囊网开一面。短缺风险不是背景，它给 FDA 执法权设了上限：一个供应越集中、越无可替代的工厂，FDA 反而越不敢对它彻底行使拒绝权。这就是成品层「执法越严、短缺越重」两难的实质——准入权名义上是主权者单方说了算，实际被下游的可替代性反向约束住。

4. **把节点放到时间里读。** 2008（FDA 首次对兰伯西两厂发进口警报，挡下约 30 种药）→ 2013-05（DOJ 和解、5 亿美元罚金）→ 2013-09（Mohali 工厂进口警报）→ 2014（美国加强对海外药厂检查频次的讨论）→ 2014–2015（Sun Pharma 收购兰伯西，问题工厂并入印度最大药企）。控制权的移动方向：单个造假工厂被逐出美国市场，但份额没有回流美国本土，而是在印度内部由别家（含收购方 Sun Pharma）接手——FDA 的准入权能切掉一个坏节点，切不动「成品来自印度」这个结构。

5. **把说法和数字当成动作。** 「FDA 切断了兰伯西、保护了美国用药安全」这个说法可查证地不完整：FDA 自己的文件显示它对独家供应的更昔洛韦胶囊**故意没有切断**，因为切了会造成短缺。所以「FDA 有权切断问题工厂」这句话，真实的边界是「除非该工厂是某品种的唯一来源」。把这层边界说清楚，才看清成品层准入权的真实分量：它是对可替代品种的选择性控制工具，对不可替代的独家品种反而失效——恰恰在最需要它的地方（唯一来源）它最不敢用。

**争夺照出的结构（对成品层）：**
- FDA 的进口警报是成品层最实在、最常用的政治/监管接口，落在具体工厂，属 `selective-seizure`（点名切某厂供美）。
- 但这个工具被下游可替代性反向锁住：品种有多家来源时，FDA 敢切（切一家可改采购）；品种是独家来源时，FDA 不敢切（切了就短缺）。这从反面印证了成品层「网格状可替代」的判断——可替代的地方，控制权反而能行使；不可替代的地方（往往落在上游 API 或某个独家成品），控制权反而收缩。
- 三四十年外包沉淀下来的「印度成品」结构，不因逐出一家造假厂而改变；问题工厂被同在印度的别家接手，说明这一层的份额粘在「印度」这个国家，不粘在某家企业。

**第二个事件（附，侧面照出，五动作详见 `ph-api.md`）：2020 年 3–4 月 印度限制 26 种 API 及制剂出口 → COVID 暴露「中国原料 → 印度成品 → 西方处方」三层依赖链。** 2020-03-04 印度商工部（DGFT）对 26 种 API 及其制剂（含对乙酰氨基酚等成品）实施出口限制；美国 HHS、欧盟委员会表达关切；约 1–2 个月后印度部分放宽（C3，DGFT 通知 + 新闻记录，待回原文）。对成品层的读数：印度作为「世界药房」的成品供应可靠性被一次防御性出口限制打上问号，成品层的「网格状可替代」显出边界——可替代的前提是有多个国家来源，而当唯一的大来源自己限制出口时，缓冲会短暂失效。但实际未发生规模化全球成品短缺，说明这次是**信号冲击而非产量断供**；长期政策回应（BARDA/PLI/EU 法案）主要针对 API 层，说明政策制定者读懂了「硬卡点在原料」。

本节点整体仍**未经反复现实结构化核实，可信度中低**。FDA 进口警报是成品层自己的正面争夺，证据可查但尚未逐案结构化（缺 FDA 原始 Import Alert 与 DOJ 文书）；2020 事件主要照亮上游 API 层，成品层的独立争夺证据仍偏薄。
