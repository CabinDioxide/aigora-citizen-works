# 节点 ph-api：原料药（API）

> 父节点：ph（医药栈）| 层：L1 生产基础设施
> 建立：2026-06-26 | 数据综合 C：C2–C3（市场规模 C3 行业口径；中印份额 C3；抗生素专项份额 C3；中国对印度进口依赖 C3；关键企业营收 C3；断供冲击 C2 推算；欧美政策动向 C3）

## 结构层

### 1. 功能定义

API（Active Pharmaceutical Ingredient，原料药）是药品里真正起药效的化学或生物活性成分，是最终片剂/胶囊/注射剂的核心物料。没有 API，制药厂无法生产任何成品药。抗生素 API（如青霉素、头孢类、阿莫西林）是这个节点最硬的卡点区——它们用量极大、仿制药赛道依赖它、且生产高度集中。

这个节点和 ph-generic（仿制药）的关系：API 是上游，仿制药是下游。本节点说的是化学合成和发酵产出活性成分这一步，不包括把 API 制成成品药的配方环节（见 ph-generic）。

这个节点卡的不是药品的最终配方，而是**活性成分的合成产能**。谁控制这个产能，谁就能决定下游仿制药厂能不能开工。

### 2. 物质形态与可运输性

原料药是化学分子，固态粉末（大多数抗生素 API）或液态（部分原料）。可以装箱空运或海运，无特殊低温要求（部分生物 API 需冷链，但化学 API 为主的大宗抗生素不需要）。运输障碍不是物理难题，是监管壁垒——FDA 认证（ANDA 或 NDA 相关的 API 来源）和 WHO GMP（良好生产规范认证）。一家未经认证的新工厂即使产品质量合格，下游制药厂也无法合法用它供货（需重新申报来源变更，少则 1–2 年，多则 3–5 年走审批）。

所以，运输本身不是障碍；障碍是**监管许可路径的长度**。

### 3. 供给集中度

整体市场集中度低于 EUV 或 SWIFT，但在特定 API 品类里极端集中。

**全球整体 API 市场（约 $2200–2500 亿美元，2023，C3 行业估算）：**
- 中国：约 40% 产能（C3，IQVIA/EvaluatePharma 口径）
- 印度：约 20% 产能（C3）
- 欧洲：约 20%（高附加值专利药 API 为主，化学合成大宗 API 份额萎缩）
- 美国：约 11%（C3，FDA 2019 国会报告）
- 其他（东南亚、拉美）：约 9%

抗生素 API 是整个节点里政治最敏感的子类：用量大、仿制药赛道的核心、且中国近独占——不是因为技术壁垒高，而是因为中国靠廉价能源 + 规模 + 环保外部化逐步把西方生产者逼出市场（同多晶硅、镓的竞争逻辑）。

**Price maker：** 中国大型 API 企业（华北制药、石药集团、中国医药集团等国企为主）。大宗 API 长期处于成本竞争状态，中国产品价格常低于欧洲产能的现金成本，是欧洲最后几家抗生素 API 工厂（如荷兰 DSM Sinochem、西班牙 Ferrer）都难以维持的根本原因。

**法域结构关键点：** 中国 API 企业大多是国资控股或有国资参股，这意味着国家可以在危机时直接调度产能和出口决定，而不必经过市场机制。印度 API 企业以私营上市公司为主，但印度政府 2020 年 COVID 期间曾一度禁止特定 API 和成品药出口（2020 年 3–4 月，后撤销，C3），证明了国家干预这条线可以被印方也能拉动。

### 5. 上游依赖（子节点）

- **化学前体（关键依赖）**：大多数抗生素 API 通过发酵或化学合成两条路线生产。化学合成路线需要基础有机化学品（苯、甲苯、DMF 等）和关键中间体（6-APA 是青霉素 API 的前体，6-APA 本身几乎也在中国生产）。中国同时主导了多个 API 前体的供应，使得「买中国 API 绕过」比「买前体自己合成」同样难解。
- **发酵培养基和工业酶**：抗生素发酵工艺需要特定工业酶（Novozymes 等丹麦/荷兰公司仍有供给，分散度较好），不是单点。
- **化工能源**：大规模发酵合成是能耗密集型工业，中国能以较低电价生产 API 是成本优势的物质来源。如果中国电价上升或对 API 出口征收额外税，成本优势缩窄，但不会立刻消失。

总体：上游依赖没有 EUV 那种极端单点，但多个前体也由中国主导，买不到 API 时大概率同时买不到便宜的前体。

### 6. 下游依赖方

- **印度仿制药厂（依赖度极高）**：印度是「世界药房」——向 200+ 个国家出口成品仿制药，但印度仿制药厂约 60–70% 的 API 从中国进口（C3，印度制药联合会数据）。这是典型的双层脆弱性：中国掐印度 → 印度掐全球。
- **美国仿制药市场（高依赖，间接）**：美国仿制药约 90% 依赖海外（主要是印度）API 和成品药（C2；〔2026-07-11 修正〕FDA 2019《Drug Shortages: Root Causes》原文明确说 FDA 不掌握美国 API 依赖比例，该数字系行业/国会转述口径而非 FDA，降 C2）。美国卫生部门的关键担忧是：多数常用仿制药（包括抗生素、血压药、心脏药）的 API 最终来自中印，国内产能基本为零。
- **欧洲（高依赖，已有政策响应）**：欧盟 2023 年发布「关键药品法案」（Critical Medicines Act 倡议），试图通过战略储备和分散采购减少单一来源依赖（C3，委员会文件）。

断供库存缓冲：医院和制药厂通常持有约 2–6 个月的 API 库存（短则 2 个月，部分关键 API 企业战略备货更长，C2 推算）。真正的断供窗口要超过库存缓冲才会触发临床短缺，这给政治响应留了一定时间，但 2020 年 COVID 封锁期间短期物流中断已经造成局部短缺（C3）。

### 7. 替代路径 + fallback 等级

**针对中国单国断供（不含印度）：**
- 印度现有 API 产能可部分接替，特别是非抗生素品类（抗病毒、心血管、糖尿病）：`partial fallback`
- 抗生素 API：印度自产量不足以覆盖中国断供量（印度自产青霉素 API 能力有限，大量依赖中国进口 6-APA 前体），`possible reroute`（需要前体来源也一并解决）
- 欧洲残存产能（DSM Sinochem、Aurobindo 欧洲工厂）：产能微小，数年内无法规模化替代

**针对中国+印度双双断供：**
- 全球性抗生素短缺在 3–6 个月内发生（超过库存缓冲），目前没有任何单一替代来源能在这一时间窗口内接上，`blocked`（短期）

**五问答法（以青霉素 API 为例）：**
- 替代哪一层：合成产能，需新建或重启的发酵车间
- 多久接上：从立项到 FDA/EMA 认证约 3–5 年；短期临时豁免许可约 6–12 个月
- 卡在哪个环节：发酵设备（有 CDMO 专用，不是通用）+ 前体 6-APA 来源（也在中国）+ 监管重新认证（ANDA 来源变更申报）
- 谁有权限启动：私营 CDMO 企业（Pfizer CentreOne、Thermo Fisher、Lonza），需要政府采购合同支撑才经济可行
- 现场有没有执行能力：美国 Phlow/BARDA 合同已启动，但 2023 年仍处于中试规模，未达商业量产；〔2026-07-11 修正〕2024 年报道显示合同交付不足（TechTarget，C3），fallback 评估中不得把该项算作已建产能

青霉素 API 的真实 fallback 等级：`possible reroute`（中期，3–5 年重建路径存在但未完成）。

### 8. 重建壁垒 + 前置期

与 EUV 或半导体设备相比，API 制造的技术壁垒**属于中等**——工艺多数是成熟化学/发酵技术，没有 EUV 那种物理极限约束。真正的壁垒是：

- **规模经济和成本**：中国靠廉价能源、松散环保监管、成熟产业集群，把青霉素 API 价格压到约 $5–8/kg（C2 推算）。重建一座有竞争力的发酵工厂，前期资本支出约 $1–5 亿（C2），且没有规模经济护持的前几年将持续亏损——欧洲最后几家抗生素 API 工厂关闭，正是因为这个成本差距使私营资本拒绝维持。

- **监管认证前置期**：FDA/EMA 的 GMP 检查和 ANDA 来源变更审批约 1–3 年（正常周期），紧急情况可能压缩但流程不能完全跳过。

- **前体链同步**：即使建了合成产能，前体（6-APA、7-ACA 等）来源问题没解决，本质上仍依赖中国供应链的某个更上游层。

- **人才和工程能力**：欧美做大规模工业发酵的工程人才已大量流失，30–40 年外包期后国内已没有足够的 API 工程师存量（C2 推算）。

时间估算：政府补贴驱动的「再岸化」路径，从政策出台到形成 10–20% 的本土抗生素 API 产能，实证案例（如美国 BARDA/Phlow 合同）显示约 5–8 年。

### 9. 议价/控制机制

这个节点目前**没有明确的政治武器化出口管制**（截至 2026 年 6 月）——没有类似镓/锗 2023 年、稀土 2025 年的正式出口许可制度（C3，未见正式公告）。中国对 API 的卡点来自于**隐性的市场主导力量**，而非显性的政策工具。

- **卡点类型**：资本壁垒（cost moat）+ 服务依赖（监管合规路径）
- **卡点 mode**：当前 `open`（正常供给），潜在 `selective-seizure` 或 `near-closure`（在特定危机情景下，如中国政府以 API 供应为谈判筹码）

2020 年 COVID 初期，中国政府实际上**没有正式禁止 API 出口**，但官员的公开发言（「如果中国停止出口，美国将陷入药品短缺」，C3，新华社相关报道）被美国国会作为潜在威胁感知。至今这张牌是隐性的，而非已动用的。

印度政府 2020 年 3–4 月**确实临时禁止了**25 种成品药和 12 种 API 的出口，随后解除（C3）——这证明了印度也有主权意愿在危机时切断供给，尽管不是定向武器化。

### 10. 历史变迁（卡点怎么移动）

1950–1980s：美国、德国、英国、荷兰、日本是主要 API 生产国，抗生素 API 在西方工业化国家内部生产。

1980–2000s：环保管制趋严 + 劳动力成本上升 → 欧美 API 生产外包到印度。印度成为「世界药房」，欧美专注于成品药配方和品牌销售。

2000–2020：印度逐步把低毛利的大宗 API（尤其青霉素）再外包给中国，自己升级到中高端 API 和仿制药成品。中国靠成本优势逐步取得抗生素大宗 API 约 80–90% 份额。

2020–2026（现阶段）：COVID 冲击后，美欧印开始政策反思和再岸化投资。美国 BARDA 资助 Phlow 等；EU 关键药品法案；印度 PLI（生产关联激励）计划支持本土 API 制造。但实际产能变化仍然有限，中国在大宗抗生素 API 的主导地位没有结构性改变（C3，2024 年估算）。

### 11. 因果层

**物质约束（中等）**：API 化学本身不是稀缺资源，全球大多数地方都能化学合成，物质约束来自规模经济（只有在巨大产能下成本才具竞争力）和发酵工艺的特定设备依赖。不同于 EUV（物理上没有第二家）或稀土（资源和加工 know-how 双重集中）。

**Real force（中低）**：中国 API 的主导地位锚在**成本竞争的历史积累**，而非感召力或独特技术。一旦价格保护（补贴、廉价电价、环保外部化）减弱，或替代方获得足够补贴，这个力量会衰减。这与稀土 know-how 或 CUDA 生态那种更黏的 real force 不同：它更像多晶硅的成本护城河，而非技术壁垒。

**个人/调用层（低）**：API 市场由分散的私营企业组成（中国国企为主），没有单一决策人。真正的调用发生在国家层面，需要国务院/商务部级决策——历史上还没有对 API 出口做过正式政策性武器化，这是与镓/稀土的关键区别。

## 量化层

### Q1. 市场规模

全球 API 市场约 $2200–2500 亿美元（2023 年，C3，IQVIA/Grand View Research 行业估算）。

细分：
- 化学合成 API（主流）：约占约 70%，即约 $1500 亿
- 生物 API（单抗/蛋白质）：约 30%，这部分集中度更分散，主要在美欧
- 大宗仿制药 API（抗生素+维生素+心血管+镇痛）：约 $800–1000 亿，中国主导

具体细分口径因来源不同差异较大，但数量级确认：千亿美元级，且中国主导的大宗 API 约占总市场 30–40%。

### Q2. 集中度量化

- **整体 API 市场 CR2（中国+印度）**：约 60%（C3）
- **抗生素 API CR1（中国）**：约 80–90%（C3）
- **维生素 C CR1（中国）**：约 95%（C3）
- **Price maker**：中国国有 API 企业（在大宗品类），靠低价格影响全球市场；印度仿制药厂对中国是价格接受者

### Q4. 下游依赖度量化

- **印度进口依赖**：印度仿制药厂约 60–70% API 从中国进口（C3，印度制药联合会 IPA 2022 年数据）；抗生素 API 专项依赖更高，估约 80–90%（C2）
- **美国间接依赖**：约 72% 美国仿制药活性成分来自海外，其中大部分来自中印（C2；〔2026-07-11 修正〕原标 C3 挂 FDA 名下有误——FDA 2019《Drug Shortages: Root Causes》报告原文明确说不知道美国 API 依赖比例，72% 系国会/媒体转述口径，降 C2，待可靠原始来源）
- **断供库存缓冲**：API 制造商通常持有约 3–6 个月的前体和 API 成品库存；下游制药厂通常持有约 2–4 个月 API 库存（C2，行业估算）；超过 6 个月断供，常规库存全部耗尽

### Q5. 断供冲击量级

- **局部断供（单品类，如青霉素 API 断供）**：全球抗生素短缺，下游医院治疗感染症能力下降。欧洲已有 2022 年冬季阿莫西林短缺案例（EMA 预警 + 部分国家配给，C3）——但成因是需求激增 + 物流阻塞，非供给方断供。
- **重大事件中的冲击历史**：2008 年中国肝素 API 受 NDMA 杂质污染，造成美国约 81 人死亡（C4，FDA 事故报告）——这是迄今最直接的 API 单一来源风险实证。
- **全规模断供量级**：【缺口：需要 RAND/GE Healthcare/IQVIA 专项断供冲击报告，估约数百亿美元 GDP 间接损失 + 医疗系统容量下降，C2 推算，没有可靠报告引用数字】

### Q6. 资本流向与利润归宿

大宗 API（抗生素、维生素）的价值链利润**主要沉淀在下游成品药配方和品牌环节**，不在 API 原料层：

- 一颗阿莫西林 API 约 $0.01–0.03/剂（C2，市场估算）
- 最终成品药零售价约 $0.5–5/剂
- 品牌药或复杂配方药可到 $10–50+/剂

这意味着 API 层本身的利润极薄，供给方是利润率最低的节点，而非最高的节点。政治压力打到 API 供给方的资产负债表上，伤害实际上不大（中国国企甚至可以亏损维持产能）；真正的伤害传导给**下游仿制药厂**（原材料成本骤升）和**最终消费者/卫生系统**（药品短缺或价格飙升）。

这是这个节点区别于 cm-ree/ac-gpu 的重要特征：卡点持有者（中国 API 厂）本身的经济利益并不依赖这个卡点——他们断供自己也没有多少利润可失，这使得将 API 出口作为武器的「成本-收益」对中国而言比稀土出口管制更偏向有利（失去的利润更少，造成的对手伤害更大）。

## 政治传动层

### A. 公开接口

- **美国**：无正式 API 出口管制（截至 2026 年 6 月），但 BARDA 资助协议（如 BARDA-Phlow 2020 年约 $354M ≈ 3.54 亿美元 CARES Act 资金，C3）是政府拉动国内供给的工具。《关键药品法案（Critical Drug Shortage Prevention and Treatment Act，S.2092）》等立法提案尝试要求 FDA 认证来源多元化，但截至 2023 年尚未立法（C3）。
- **印度**：PLI（Production Linked Incentive）计划专项 API 批次，2020 年批准约 ₹6,940 亿（约 $8.4 亿，C3）补贴 53 种关键 API 本土制造，重点是抗生素 API。
- **欧盟**：Critical Medicines Act 倡议（2023 年委员会草案，C3），提出强制 API 来源多元化和战略储备。
- **中国**：无正式 API 出口管制条款，但「国家医保目录」和国有企业定价决策事实上控制了出口优先级。

### B. 控制状态流转

当前状态：**allow by default**（完全开放供给）。
翻转门槛：需要中国国务院/商务部决策（相当于正式出口管制），或印度商务部出口禁令（2020 年 3 月模式）。无正式的推定拒绝状态。和镓/稀土比，翻转门槛更高（政治成本更大——中国依赖这条出口赛道的外汇收入和医药全球化战略），但并非不可能。

### C. 适用账本

目前无许可账（无出口管制）。适用的是建设债账（BARDA 合同、PLI 补贴）。如果 API 被纳入出口管制，触发的就是许可账模式（类镓）。

### D. First payer

状态翻转后（如中国限制 API 出口）的代价传导顺序：
1. **印度仿制药厂**（立刻：原材料断供，产线停工）
2. **全球仿制药市场**（3–6 个月内：库存耗尽，药品短缺，尤其抗生素）
3. **卫生系统和终端患者**（6 个月后：治疗能力下降，医院配给）
4. **品牌药厂/医疗服务机构**（间接：供应链重组成本）

### E. 时点

无当前有效管制时点。如触发，历史参照：2020 年印度出口禁令 3 月 4 日生效，4 月 6 日解除，共约 33 天（C3）。若中国发布正式出口管制，参照镓 2023 年 8 月案例，可在公告后约 1 个月生效。

### F. 叙事合法化

- **中国潜在叙事**：「医疗主权」、「战时医疗储备优先」（若对台冲突）、「对等反制美制裁」
- **美欧印叙事**：「医疗供应链安全」（非国家安全，而是公共卫生框架）、「避免单一来源依赖」——注意这条叙事和「绿色转型」叙事（太阳能）、「国家安全」叙事（芯片）相比，**动员力更弱**，缺乏国防工业那种长期政治支持，是再岸化推进慢的根本原因之一。

## 卡点分析

**位置**：ph-api 节点，L1 生产基础设施层
**持有者**：中国国有/国资 API 企业（大宗抗生素品类近独占），印度私营仿制药企业（次级持有）
**卡点来源**：规模经济（成本竞争逐步淘汰对手）+ 监管合规路径锁定（替代来源需重新获 FDA/EMA 认证，提高转换时间成本）

**这个节点区别于全图其他所有物理节点的特征：** 卡点是**被动积累的**，不是主动建设的。中国没有设计出让世界依赖它的 API 战略——它只是在正常市场竞争中靠成本优势赢了，大部分西方企业自愿退出。这意味着这个卡点没有像 EUV 那样有单一的守门人，也没有像稀土那样有明确的政府战略，武器化成本更高（需要国家意志强行介入正常市场行为）。

**政治进入后转移**：正在进行（美国 BARDA/Phlow + 印度 PLI + EU 法案）。但进展慢，5–10 年内结构性变化有限。
**干预窗口**：开，但窗口在慢慢关闭——随着再岸化投资积累，3–5 年后某些品类可能形成 partial fallback。现在是干预（建立多元来源）最容易、成本最低的阶段，也是政治意愿最弱的阶段（无明显危机触发条件）。

**最硬反例 + 过三关：**

反例：「COVID 证明中国 API 供应没有被武器化=夸大威胁」

过三关：
- 前提是否成立：COVID 期间中国官员确实有威胁性表述（新华社 2020 年），但**没有正式出口管制**，正确。
- 与原命题可比：这是「火力展示（implicit threat）≠ 武器实际动用」，与「威胁存在」并不矛盾。
- 真发生过：中国在 COVID 期间实际上**没有限制 API 出口**（事实），但**印度限制了**（2020 年 3–4 月），这证明了供给方国家有政治意愿动用这张牌，即使中国这次没动。

结论：「COVID 没有断供」只能说明**这张牌在 COVID 期间没有被动用**，不能说明这张牌不存在或不会被动用。正确类比：2022 年前俄罗斯没有断天然气，不能说明断天然气不可能。断供本身是隐性威胁，隐性威胁也会产生实际政策效果（美欧 PLI/BARDA 投资就是因为威胁感知，而非实际断供触发）。

## 最近一次被争夺的事件

**2020 年 3 月印度 API 出口管制（MCA 通知）→ COVID-19 暴露中国→印度→西方三层依赖链**

这是 ph-api 节点近年来最清晰的被激活时刻，不是进攻性武器化，而是防守性管制暴露了双层依赖的存在。

**五个阅读动作：**

1. **校准颗粒度**：争夺的不是"API 全球市场份额"，而是"疫情需求激增时，印度自保本国药品供应的决定，能否被西方接受且不造成全球短缺"。粒度在**印度作为再出口供应商的可靠性假设**，而非中国作为原料药来源。

2. **跟反应链**：2020 年初 COVID 爆发→ 印度国内医药需求急剧上升→ 2020-03-04 印度商工部发布通知，对 26 种 API 及其制剂实施出口禁令（含扑热息痛/对乙酰氨基酚、维生素 B12、黄体酮等）→ 美国 HHS 和欧盟委员会公开表达关切→ 印度面临来自 WTO 和双边贸易伙伴的压力→ 2020-04 印度部分放宽（点名疫情重灾国可申请豁免）→ 2020-05 美国 BARDA 宣布与 Phlow 签署 $354M 合同，推动建立国内 API 制造产能（CARES Act 条款）→ 此后欧美日韩先后提出 API 供应链本土化政策。

3. **点名地面方**：被当成"可靠中间供应商"的印度，用一次出口禁令把自己的双重角色暴露出来：对西方，印度是"中国之后的替代供应来源"；对自己，印度是高度依赖中国 6-APA 等前体 API 的下游加工方。印度的决定性手段是：它有能力在国家紧急状态下单边限制出口，且这个能力与中国稀土/镓的"出口许可"工具性质相同，但动机不同（防御本国短缺，而非进攻性武器化）。

4. **放到时间里**：2008（肝素危机，首次暴露中国单源 API 风险）→ 2020-03（印度出口禁令，暴露"中国→印度→西方"双层脆弱性）→ 2020-05（BARDA-Phlow 合同，第一次以联邦资金推动 API 国内产能）→ 2022–2023（EU Critical Medicines Act 草案，欧盟版的 API 来源分散化立法）→ 2024（IRA / BIOSECURE Act 讨论）→ 2025-12-18（〔2026-07-11 修正〕BIOSECURE **已成法**，含 NDAA 1260H 式实体认定机制，美国以立法定向切断特定中国生物技术企业；原稿写作时状态是"讨论中"，成法确认见 07-08 审查轮）。时间轴照出：2008 年的警告没有推动政策变化；2020 年的危机触发了第一轮真实投资；2022 年以后地缘政治叠加，进入第二轮系统性政策推动。

5. **说法当动作**：印度 2020-03 的出口禁令，本身是国内政治驱动的防守动作（保本国库存），但它被西方读成"供应链单一来源的风险实证"——同一个动作，不同的阅读者产生了不同的因果推断。西方政策界把它当成"中国→印度→西方"链条脆弱性的证据；印度却是在应对"中国→印度 6-APA 前体供应"的上游脆弱性。这是一个多层误读的事件，政策回应（BARDA-Phlow/EU Critical Medicines）基于的是西方对事件的读法，不是事件本身的全貌。

**争夺照出的结构**：
- ph-api 节点的双层依赖是**可传播的**：中国→印度（6-APA 等前体供应），印度→西方（合成 API 加工），任何一层的冲击都向下传播。
- 印度的出口管制是**防御性的**，持续时间短（约 1-2 个月后部分放开），不是战略武器化（与中国稀土/镓"计划内的选择性管制"不同）。
- 印度管制能短期内造成价格冲击，但无法造成持续性断供（因为印度自己也需要再开放进口前体，且 WHO/美欧压力难以承受）。
- 长期结构变化不是由印度的禁令直接造成，而是由禁令暴露的"如果中国同时受到干扰，印度无法填补空缺"这一更深认知触发。

**反例**：「2020 年印度 API 出口管制导致了全球 API 短缺，证明这是一个有力的武器」——过三关：① 前提是否成立？——印度确实实施了禁令（成立）；② 与"全球短缺"是否可比？——不可比：实际上 2020 年全球 API 并未发生系统性短缺（中国基本维持出口，印度约 1–2 个月后部分放开，医疗系统的短缺主要是局部和暂时的）；③ 真发生了吗？——没有发生规模化全球短缺（降级）。结论：印度禁令是信号冲击而非产量断供，照出的是脆弱性的存在，不是武器的有效性。
