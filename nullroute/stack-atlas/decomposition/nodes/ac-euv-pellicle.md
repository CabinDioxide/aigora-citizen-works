# 子节点 ac-euv-pellicle：EUV 保护膜（pellicle）

> 父节点：ac-euv（EUV 光刻设备）| 栈：AI 算力栈 | 层：L0 物理·材料子层（掩模侧耗材）

## 结构层

### 1. 功能定义

EUV pellicle 是一张极薄的透光薄膜，张在光掩模（reticle / photomask）正面上方几毫米处，把掉落的颗粒挡在焦平面之外——颗粒落在 pellicle 上时离晶圆成像面足够远，不会被清晰投影成缺陷。它卡的不是「光能不能成像」，而是「一张被反复使用、价值数十万到上百万美元的 EUV 掩模会不会因一颗灰尘而批量报废」。

但这个节点和它的两个兄弟子节点（光源、光学）有一个根本区别，必须先说清楚，否则整个卡点判断会高估它：**EUV 在量产史上有相当长一段时间是「不带 pellicle」跑的**。光源没火整机就是死的（on/off），光学镜组废了无法成像（on/off），而 pellicle 在早期被很多晶圆厂判断为「带上反而亏」——因为早期 pellicle 的 EUV 透过率不够高，挂上去等于直接砍产线吞吐量和曝光剂量裕度，得不偿失。于是 TSMC、三星在 EUV 量产初期普遍选择**不挂 pellicle，靠超洁净的掩模搬运、装载锁、定期检测来替代**（C3 广泛报道）。

所以 pellicle 的功能位置是**条件性 / 软卡点**：它不是「没有它产线就停」，而是「没有它，掩模缺陷风险与停机检测成本上升，且 High-NA / 更先进节点对随机缺陷越来越不容忍时，它从可选变成接近必需」。它做的事——挡颗粒、保护掩模资产；它不做的事——不参与成像、不图形化、不提供光、不做投影。

### 2. 物质形态与可运输性

设备级精密耗材（freestanding 薄膜 + 边框 + 装框工艺），介于光刻胶那种「液体耗材」和光学那种「固态精密件」之间。

物理约束链（这一层决定它为什么难做，C3 行业共识）：
- **必须对 13.5nm 高透过**：EUV 几乎被所有物质吸收，pellicle 每被穿过一次都损失能量，且光路是「入射穿过一次、反射回来再穿过一次」，双程损耗叠加。早期目标单程透过率约 88%，行业向 90%+ 推进——每差一个百分点都直接换算成产线吞吐量损失（与光源「功率=产能」同一条节流阀逻辑）。
- **必须扛高功率热负荷**：光源往 250W 以上爬时，pellicle 在每次曝光被极紫外加热，薄膜要在高温下不变形、不破裂。功率越高，pellicle 的热失效门槛越紧——光源升功率和 pellicle 可用性是相互牵制的两条曲线。
- **必须扛氢自由基环境**：EUV 扫描机腔内用氢气清洁（防锡/碳污染），pellicle 长期泡在氢等离子体里会被刻蚀、退化。这是「EUV 光子损伤 / 碳化」之外的另一条寿命杀手。
- **耗材性**：透过率退化、机械疲劳、氢刻蚀累积 → pellicle 是有寿命的消耗件，需定期更换。

可运输性：薄膜本身轻、可空运，但它是**易碎+洁净度敏感**的精密件，真正约束不是跨境物流，是「装框良率」和「全尺寸无缺陷自支撑薄膜」的制造能力。

### 3. 供给集中度

判断比光源/光学复杂，因为这里有两个并存的事实：**(a) 能做量产级 EUV pellicle 的主体很少（高集中）；(b) 但下游有「干脆不用」这条退出路径（降低了它作为卡点的硬度）**。

- ASML 自身长期主推 **多晶硅（poly-Si）薄膜 pellicle**，并把 pellicle 制造能力相当程度握在自己手里（C3 需补原文核 ASML pellicle 产线归属与产能）。
- 候选/合作供给方包括日本 **三井化学（Mitsui Chemicals）**（光掩模 pellicle 传统强者，DUV 时代 pellicle 市场即由日系主导）、面向下一代的**碳纳米管（CNT）pellicle** 路线（芬兰 Canatu、imec 研发线、三井等参与）（C2–C3，需补各家 EUV pellicle 量产状态原文）。
- access maker：在「要不要、由谁供 pellicle」这件事上，**真正的 access maker 其实偏向 ASML + 晶圆厂的工艺选择**，而不是某个独立 pellicle 厂——因为下游可以选择不挂。这与光源「Cymer 不供你就没光」的硬度不同。

证据级：「EUV pellicle 供给方极少、ASML poly-Si 主导」= source-linked（行业广知，未逐条回原文）；「具体份额分解」= query-designed（几乎无公开口径，标 C2）。

### 5. 上游依赖（子节点）

pellicle 自己绕不开的东西：
- **薄膜材料体系**：poly-Si 路线依赖超薄硅膜沉积与释放工艺；CNT 路线依赖高质量碳纳米管薄膜（Canatu/相关）。属工艺 know-how，不是某种稀缺矿产卡点。
- **装框 / 张膜工艺与边框**：把全尺寸（约 110×140mm 量级量产掩模面）freestanding 薄膜无缺陷地张到框上，是良率主战场。
- **检测设备**：pellicle 缺陷/透过率/均匀性检测。
评估：pellicle 的上游没有出现光源 Trumpf 那种「孙单点」级硬卡点；它的难度集中在**自身的薄膜+装框良率**，而不是被某个独家上游掐住。这也是它比光源软的原因之一。

### 6. 下游依赖方

- **依赖方**：用 EUV 的先进逻辑/部分 DRAM 晶圆厂（TSMC、三星、Intel 代工）。
- **依赖强度：可缓冲 → 高（随节点推进上升）**。关键就在这里——早期可缓冲（不挂也能跑），但随着节点推进、掩模成本攀升、High-NA 引入、随机缺陷容忍度下降，pellicle 从「可选」往「实务上需要」迁移（C2–C3，趋势判断，具体各厂采用时点需核）。
- 买家侧没有「断 pellicle 即停产」的致命依赖，但有「长期没有可靠 pellicle，掩模资产风险与检测停机成本上升」的慢性依赖。

### 7. 替代路径 + fallback 等级

这个节点的 fallback 分析和别的节点反过来——**它最强的「fallback」不是换供给方，是「干脆不用 pellicle」这条已被验证可行的退出路径**：

- **退出路径：无 pellicle 运行**。fallback 等级 `operational`（这是少数真能打到 operational 的）。按五问：
  - 替代哪一层 = 整个 pellicle 功能（用超洁净搬运 + 装载锁 + 频繁掩模检测替代）；
  - 多久接上 = 即时，本来就是 EUV 量产初期的默认做法；
  - 卡在哪 = 代价是更高的掩模缺陷风险和检测停机成本，先进节点处代价上升；
  - 谁有权启动 = 晶圆厂自己的工艺选择；
  - 现场能不能执行 = 能，已大规模执行过。
  - 结论：这是真 fallback（少见地过了五问），但**它的有效性随节点先进度衰减**——越往 High-NA，越贵越难承受不挂的风险。
- **换 pellicle 供给方 / 换材料路线（poly-Si ↔ CNT）**：fallback 等级 `partial → planned`。存在多条材料路线和多个候选厂，比光源/光学「只有一家」健康得多，但 CNT 量产成熟度仍需核（C2）。
- 综合：pellicle 是本 EUV 家族里 **fallback 最不悲观的一个节点**——既有「不用」的 operational 退出，又有「多材料路线/多厂」的供给侧弹性。

### 8. 重建壁垒 + 前置期

中等偏高，但显著低于光源/光学。

要做量产级 EUV pellicle，需要：全尺寸无缺陷自支撑超薄膜的制造与装框良率、>90% EUV 透过率、扛 250W+ 热负荷、抗氢等离子体刻蚀的寿命。这些是真壁垒，但：
- 它没有光源那种「十年级协同迭代 + 失败先例（Gigaphoton）」的封死感；
- 多家（ASML、三井、Canatu、imec）在并行推进，材料路线不止一条；
- 且下游有「不用」的退路，使重建压力没有光源那么生死攸关。

lead time：以年计而非十年计（C2 推算）。真正的工程瓶颈历史上是**良率/产能**——做出一片合格 pellicle 不难，稳定地大批量做出全尺寸无缺陷、高透过、长寿命的 pellicle 才是卡点。【缺口：当前 EUV pellicle 良率/月产能是否仍是瓶颈——需 SEMI/TECHCET 或 ASML 技术披露原文】

### 9. 议价 / 控制机制

- 卡点 type：`physical`（薄膜+装框良率的制造壁垒）但**强度弱于光源**，因为叠了一个 `optional`（可不用）的减压阀。
- 卡点 mode：对所有客户基本 `open / expensive`——能买到或自做，代价是透过率损失与成本；不存在像 EUV 整机那种对华 `closed` 的独立 pellicle 封锁面（pellicle 随整机走，单独管制 pellicle 的边际意义小，因为没整机就没地方用）。
- 机制：pellicle 几乎没有独立的对外强制杠杆。它的政治价值主要是**寄生在父节点 ac-euv 上**，且因为「可不用 + 多路线」，它甚至比光源更不适合当卡点——你封 pellicle，对手用无 pellicle 工艺就绕过去了。

### 10. 历史变迁（卡点怎么移动）

pellicle 卡点的轨迹是「从被判定为累赘，到随节点先进度被重新拉回必需区间」：
- EUV 量产初期：pellicle 透过率不够，被很多晶圆厂判为「挂上亏产能」，普遍**不挂**运行（C3）。
- 中期：ASML 推 poly-Si pellicle，透过率与可靠性改进；Intel 等较早倾向使用 pellicle，逻辑代工随缺陷敏感度上升逐步增加采用（C2–C3，各厂采用时点需核）。
- 当前/向前：光源功率上行（热负荷更大）与 High-NA 引入（缺陷容忍更低）同时拉扯——一边让 pellicle 更难做，一边让「不挂」的代价更高。CNT 等新材料路线就是冲着「高透过 + 耐高功率」这对矛盾去的。
所以这个子层不是单调收敛到单点，而是**在「可选」与「必需」之间被技术代际反复推拉**。这正是它该被单独记一笔、却不该被高估为硬卡点的原因。

### 11. 因果层

主要锚在**物质约束**（薄膜透过率/热/氢刻蚀的物理上限与装框良率工程）。但它有一条别的子节点没有的特征：**约束强度本身是变量**，随光源功率和节点代际移动——所以它的物质约束不是固定边界，是一条会动的曲线。real force 与调用层基本不适用（非裂缝、无独立信任叙事）。

## 量化层

### Q1. 市场规模

EUV pellicle 是「小但关键」的细分——市场金额量级远小于光源/光学/光刻胶。

- 定性量级：EUV pellicle 全球市场大概率在**单位数到低双位数亿美元量级**（C2 推算，基于在役 EUV 机台约 150–200 台 + pellicle 单价高但用量小 + 相当比例曾不挂）。这远小于动辄数十亿的光刻胶或上百亿的整机市场。
- 含 DUV 的整体光掩模 pellicle 市场历史上也只是几亿美元量级的细分（C2）。

【缺口：EUV pellicle 专项市场规模（年营收，亿美元）——需 SEMI / TECHCET / Yole 专项报告原文。目前无可引用的硬数字，量级判断标 C2 不编精确值】

### Q2. 集中度量化

- 供给侧高度集中：ASML poly-Si 自研主导 + 三井等少数候选，CR1 估计偏高（C2，无公开份额）。
- 但「集中度高」在这里不等于「卡点硬」，因为存在 operational 退出路径（不挂）。price maker 实际上偏向 ASML（既是 pellicle 主供，又是整机方，定 pellicle 规格的一方）。
- 【缺口：CR1/CR4 数值——无公开份额数据，需专项报告】

### Q3. 关键玩家财务概况

| 主体 | 该业务年营收 | 毛利率 | 市值/估值 | 来源 |
|---|---|---|---|---|
| ASML | pellicle 并入整机/服务，不单独披露 | — | ASML 市值数千亿欧元级 | 整机财务见 ac-euv |
| 三井化学 | 集团营收约 1.7–1.8 万亿日元级（C2 需核）；pellicle 仅其极小细分，不单独披露 | — | 上市（东证）| 需三井化学年报核 |
| Canatu | 私有，规模小，CNT 应用公司 | — | 私有 | 需公司资料 |

【缺口：三井化学 pellicle 细分营收——不单独披露；Canatu 财务——私有公司。pellicle 资本纵深判断只能定性：玩家要么是巨头里的小业务（ASML/三井，纵深充足但 pellicle 非命脉），要么是小型专业公司（Canatu，纵深薄但路线前沿）】

### Q4. 下游依赖度量化

- 成本占比：单片 EUV pellicle 单价高（高技术含量小批量），但占晶圆厂总成本比例**很小**（耗材级）。它对下游的财务敞口低。
- 产能敞口（反向）：若完全无 pellicle 可用，下游不会立即停产（可走无 pellicle 工艺），但**掩模缺陷导致的报废风险与检测停机成本上升**——一片先进 EUV 掩模价值可达数十万至上百万美元（C2，需核），一次颗粒污染批量报废的代价就是 pellicle 价值的成百上千倍。这才是 pellicle 的真实经济意义：它是给昂贵掩模资产买的「保险」，不是产线的氧气。
- 【缺口：先进 EUV 掩模单价、无 pellicle 运行的实际掩模报废率/检测停机成本——需晶圆厂或 SEMI 数据】

### Q5. 断供 / 管制经济冲击量级

- **作为管制杠杆：冲击量级低**。单独管制 pellicle 几乎无意义——没有 EUV 整机的地方用不上 pellicle；有整机的盟友自己能做或不挂。它不构成独立的断供冲击源。
- **作为工业可靠性变量：冲击量级中等且随节点上升**。若高功率/High-NA 时代始终做不出可靠 pellicle，则要么牺牲产能裕度，要么承受掩模报废与停机风险——这是产能效率和良率层面的慢性损耗，不是整机断供那种急性停摆。
- 量级判断：远小于光源/光学/整机断供（那些是急性、全行业、不分敌友的产能停摆）；pellicle 更像「边际效率税」。（C2 推算）

### Q6. 资本流向与利润归宿

- ASML 把 pellicle 相当程度内化（poly-Si 自研），利润并入 ASML，逻辑同它收编 Cymer：把关键耗材风险握在自己手里。
- 三井等外部供给方对 ASML/晶圆厂有一定议价空间，但因为「下游可不用 + 多路线竞争」，定价权远弱于光源（Trumpf 对 ASML 的独家锁定）或光刻胶寡头。
- 政治压力传导：pellicle 几乎不是政治压力的有效着力点——价值小、可绕过、法域分散。压力会优先打向光源、光学、光刻胶那些「不可绕过」的节点，而不是 pellicle。这恰是把它和兄弟节点区分开的判断：**同在 EUV 家族，pellicle 是其中政治杠杆价值最低的一环**。

## 政治传动层

### A. 公开接口

pellicle 没有独立的公开管制接口——它随父节点 ac-euv 整机一同受荷兰出口许可 / 美国 EAR（含美技术触发）约束。不存在专门针对 pellicle 子件的已知管制条目（单独管制的边际意义太小）。【缺口：是否有任何针对掩模耗材/pellicle 的专项条目——需 BIS EAR / 荷兰公告原文核，预期为无】

### B. 控制状态流转

- 对华：随 EUV 整机一同处 `presumption of denial`（整机从未交付，pellicle 无独立翻转日，也无独立封锁意义）。
- 对盟友：`allow by default`。
- 区别于光源：pellicle 不给任何国家提供「独立本土管辖抓手」——制造分散在荷/日/欧盟，且下游可绕过。它在状态流转上几乎是惰性的。

### C. 适用账本

- 许可账：寄生在父节点整机许可上，无独立字段。
- 建设债账：基本不适用——pellicle 没有光源 FEL 那种「另起炉灶」级的重建工程；材料路线迭代属常规研发，不计入大额建设债。

### D. first payer

- 对华封锁场景：无独立 first payer（pellicle 随整机一起，前面已无整机）。
- 若 pellicle 长期做不可靠：first payer 是采用 EUV 的晶圆厂自己（掩模报废风险与产能裕度损失），但这是工业效率代价，不是政治传导的代价。

### E. 时点

- 无独立翻转日。pellicle 的「时点」是技术代际事件（功率升档、High-NA 引入）而非政策事件——它的状态由工艺路线图而非许可证日期推动。

### F. 叙事合法化

无独立叙事，随整机靠技术主权/国安合法化。pellicle 本身太小、太可绕过，撑不起独立叙事。标 unknown（不量化）。

## 最近一次被争夺的事件

**结论先写在前面：这个节点尚未被一场真实的政治争夺检验过——它从未成为出口管制、制裁、收购战或联盟协调的对象。空着本身就是信息，而且这个"空"恰好印证了本节点的核心判断：pellicle 是 EUV 家族里政治杠杆价值最低的一环。** 按节点深挖方法，一个从没被争夺过的节点只能给草图、标可信度较低，不硬凑一场并不存在的政治博弈。

不过，pellicle 有一类真实发生、但性质是**技术—商业**而非政治的争夺，值得如实记下来，因为它决定了这个节点未来会不会升值成政治杠杆：**围绕"High-NA EUV 到底带不带 pellicle"以及"poly-Si 与碳纳米管（CNT）两条材料路线谁能满足高功率需求"的产业内博弈**。走五个阅读动作，但每一步都要标清它停在技术—商业层、没有跨进政治层：

① **颗粒度校准**：争夺不在"谁能拒绝谁用 pellicle"这个政治层面（没有任何一方对 pellicle 行使过拒绝权），而在一个更靠里的工程—商业选择：**在光源功率往 250W 以上爬、High-NA 引入使 pellicle 的透过率损失更难承受时，晶圆厂到底选择"挂"还是"不挂"，以及 pellicle 供应方能不能做出同时满足高透过与耐高功率的产品**。这是工艺路线图上的博弈，不是许可证上的博弈。

② **跟反应链走**（均为技术—商业层，非政治）：EUV 量产初期 TSMC、三星普遍选择不挂 pellicle 运行（C3，广泛报道）→ ASML 推进 poly-Si pellicle 并把制造相当程度内化（与它当年收编 Cymer 同一手法，把关键耗材风险握在自己手里，C3 需补原文）→ CNT 路线（Canatu/imec/三井等参与）冲着"高透过 + 耐高功率"这对矛盾去（C2–C3，量产成熟度待核）→ High-NA 时代"带不带 pellicle"被重新拉回讨论。整条链上没有任何一步是主权方动手或厂商行使拒绝权，全是工艺与商业选择。

③ **点名被当作地面的一方**：这里被默认当作"中立地面"、没被追问的，是**ASML 同时是 pellicle 主供方又是整机方、还是 pellicle 规格的定义方**这个三重身份。所有关于 pellicle 的讨论都把 ASML 当作中性的技术推进者，但正是它把 pellicle 风险内化、又由它定 pellicle 规格——如果哪天 pellicle 真的升值成政治杠杆，抓手大概率落在 ASML 的荷兰法域，而不是分散的三井（日）或 Canatu（欧盟）。这是一个尚未激活、但结构上已经埋着的潜在抓手。

④ **放到时间里读**：pellicle 的"状态"由技术代际事件（功率升档、High-NA 引入）推动，而不是政策日期推动——它没有像光源 Cymer 收购、光刻胶 JSR 国有化那样的可标注的"翻转日"。这个时间结构本身说明：pellicle 至今活在技术路线图的时间轴上，还没被拉进政治事件的时间轴。

⑤ **把说法和数字当作动作**："EUV 可以不挂 pellicle 量产"这个被反复引用的说法，本身也是一个动作——它持续为"pellicle 不是硬卡点"提供正当性，压低了任何人把 pellicle 当政治杠杆的动机（你封 pellicle，对手用无 pellicle 工艺就绕过去了）。反过来，"High-NA 让不挂的代价上升"这个正在积累的技术说法，是唯一可能把 pellicle 从"可绕过"推向"接近必需"、从而让它具备政治价值的力量——但截至目前，这仍是趋势判断（C2），没有落到任何一次真实的争夺上。

**争夺照出的结构**：pellicle 的"争夺"至今只发生在技术—商业层，没有一次进入政治层。这与光源（Cymer 收购把管辖抓手落到美国境内）、光学（High-NA 交付把 Zeiss 变成全行业节拍器）、光刻胶（JSR 国有化让日本同时握有主权与所有权两条路径）这三个已被政治争夺过的兄弟节点形成鲜明对照——同在 EUV 家族，pellicle 是唯一一个还停在草图状态、未经政治现实检验的节点。可信度较低（C2），此栏随 High-NA 采用与 pellicle 是否升值为必需而更新。

## 卡点分析

- **位置**：AI 算力栈 L0，ac-euv 之下的掩模侧耗材子层。
- **持有者**：ASML（荷兰，poly-Si 自研主供）+ 三井化学（日本）+ Canatu/imec（欧盟，新材料路线）。
- **卡点来源**：技术壁垒（薄膜+装框良率）+ 规模经济，但叠加一个 `optional`（可不用）减压阀和多材料路线竞争——**这是 EUV 家族里卡点强度最弱的一个**。
- **政治进入后转移**：基本不转移，也不给任何单一法域抓手——制造分散、价值小、可绕过。政治压力会绕开 pellicle 去打光源/光学/光刻胶。
- **干预窗口**：对「卡死对手」而言窗口几乎不存在（可绕过）；对「提升自身 EUV 产能效率」而言，窗口在能否随功率/节点推进做出高透过、耐高功率、长寿命 pellicle——这是良率工程问题，不是地缘卡点问题。
- **最硬反例 + 过三关**：反例（这里反过来用，挑战「pellicle 是卡点」这个判断本身）——「pellicle 根本不是卡点，因为 EUV 可以不带 pellicle 量产，TSMC/三星早期就这么干」。
  - 前提成不成立：成立。早期普遍不挂 pellicle 量产是有据的事实（C3）。
  - 可不可比：与现状部分可比——但「不挂」的代价随节点先进度（掩模更贵、缺陷更不容忍、High-NA）上升，早期能不挂不代表先进节点永远能不挂。
  - 真发生过：真发生过（无 pellicle 量产是 operational 历史）。
  - 结论：反例**大体成立**——pellicle 确实不是光源/光学那种硬 on/off 单点，应判为**条件性软卡点**。但「软」不等于「不存在」：随高功率/High-NA 推进，它的可绕过性在衰减。把它如实记为「EUV 家族里政治杠杆价值最低、但工业可靠性意义随代际上升」的节点，比简单说「是卡点」或「不是卡点」都更准。

## 级联关系

- **上游来自**：自身上游是薄膜材料体系（poly-Si 沉积 / CNT 薄膜）+ 装框工艺，无孙单点级硬卡点。
- **下游影响**：内嵌进父节点 ac-euv（影响其掩模缺陷风险与产能裕度维度，而非有无）→ ac-fab（晶圆厂良率/掩模资产保护）。影响是「效率/良率层」的，不是「产能有无层」的。
- **跨栈耦合**：接政治栈 ps-export-control / ps-exportctrl（寄生在整机许可上，无独立耦合）；与父节点光源 ac-euv-lightsource 存在物理牵制耦合（光源升功率 ↔ pellicle 热负荷上限）。
- **跨域效应**：弱。若 Sigma 量化 EUV 产能/良率，pellicle 的「透过率损耗 + 采用与否」是良率/吞吐量模型里的一个修正项，而非主变量。

## 数据缺口清单（按影响卡点判断排序）

1. 【缺口】各晶圆厂（TSMC / 三星 / Intel）对 EUV pellicle 的采用时点与当前采用比例，以及 High-NA 是否把 pellicle 推向必需——需 SEMI / 各厂技术披露 / SPIE 论文原文。这是判定「条件性软卡点」当前位于「可选 ↔ 必需」哪一段的核心证据，直接决定本节点卡点强度。
2. 【缺口】EUV pellicle 专项市场规模（年营收，亿美元）与按主体份额——需 SEMI / TECHCET / Yole 专项报告。目前 Q1/Q2 全是 C2 量级推算，无可引用硬数字。
3. 【缺口】EUV pellicle 当前良率 / 月产能是否仍是瓶颈、poly-Si 与 CNT 路线的量产成熟度对比——需 ASML 技术披露 / SEMI 报告原文。决定第 7/8 维 fallback 与重建壁垒的真实度。
4. 【缺口】pellicle EUV 透过率目标与实测值、寿命（氢刻蚀/热失效更换周期）——需 ASML / imec SPIE 论文。把「透过率=吞吐量损耗」从定性升级为可引用数字。
5. 【缺口】先进 EUV 掩模单价与无 pellicle 运行的实际掩模报废率/检测停机成本——需晶圆厂或 SEMI 数据。对齐 Q4「pellicle 是掩模保险」的经济量级。
6. 【缺口】是否存在任何针对 pellicle/掩模耗材的专项出口管制条目——需 BIS EAR / 荷兰公告原文核（预期为无，但需证实政治传动层「pellicle 无独立管制接口」的判断）。
