## 结构层

### 1. 功能定义

ag-seed 卡的不是种子这个实物，而是**下一季能不能合法、且以有竞争力的产量种下去**。种子本身可以自我复制：一粒种子长成植株，能结出几百上千粒新种子，农民理论上留种就能接着种。这一点使它和氮肥（每季消耗掉、必须重买）在物理上完全不同：种子的自然属性是"可留种、可扩繁"，本来不该是单点。

真正的卡点在两处，都是人为在种子的可复制性上加的锁：

第一，**专利 / 品种权 IP + 性状技术**。高产、抗虫、抗除草剂这些商业价值最高的性状（转基因 Bt、抗草甘膦，以及近年的基因编辑性状）被专利和植物品种保护权圈住。农民买的不是"一袋种子"，是"这袋种子里那套受法律保护的遗传信息的一季使用许可"。留种复制这套遗传信息，在有专利保护的法域里是侵权。绕开 IP 只能退回到无保护的公共品种或本土老品种，那意味着放弃 IP 锁定的高产性状，退得回去，但要付出产量的代价（见第 7 维）。

第二，**杂交生物锁定**（本节点最独特的机制，单独展开在第 9、11 维）。杂交种子（最典型是杂交玉米）第一代（F1）表现出杂种优势、产量高，但农民留种得到的第二代（F2）性状分离、产量大幅下滑，在生物学上迫使农民每季重新购买。这不靠法律、不靠专利，靠的是育种方式本身：把杂种优势锁在 F1 代，等于把"每季重买"写进了种子的生物学里。这是全图迄今最接近"订阅制"的农业卡点：不是合同条款让你续费，而是种子的生物学结构让你没有留种这个选项。

叠加起来，种子节点的"绕不开"属性是：**物理种子本身不是单点（种得出、扩得繁），但 IP 保护 + 杂交生物锁定把"用得起最高产的那套性状"变成了少数公司控制的年度许可。** 断供不是"种子没有了"，是"能合法、高产地种下去这条路被收窄或抬价"。

它不做：肥料（ag-fertilizer-n/pk 覆盖养分投入）；不做粮食流通（ag-grain 覆盖出口贸易那一环节）；也不单独决定产量，水、肥、气候、农艺共同决定收成，种子只锁住其中"遗传潜力"这一格。

### 2. 物质形态与可运输性

许可 + 分子（信息）混合型。种子有两重属性：

一重是物理实物，种子是活的生物材料，颗粒状，体积小、单位价值高（远高于粮食散货），可用普通集装箱 / 包装运输，运输约束低。但它有生物特性：有活力保质期（多数商业种子妥善储存约 1–3 年活力可用，C2 农学常识），需要控温控湿仓储，还受各国**检疫和种子进出口许可**约束（防病虫害、防未批准转基因材料入境）。

另一重、也是杠杆真正所在的，是**信息 / 许可**：种子里那套遗传信息（性状、品种）才是被 IP 圈住、被定价的东西。这一重不能像实物那样被运走：你可以走私一袋含专利性状的种子，但你无法合法地在有专利保护的市场里用它繁育销售。控制点不在海关拦截物理种子（拦不住，种子太小太容易复制），在**专利 / 品种权 + 监管审批**这套法律信息层。

这种双重属性决定了：物理层几乎无法卡（种子可扩繁、可走私、可留种），杠杆全部集中在价值流 / 信息流的 IP 与许可那一侧。这与 ag-fertilizer-n 相反：氮肥杠杆在物理流（能源成本、产能），种子杠杆在信息 / 价值流（IP、审批）。

### 3. 供给集中度

分两层看，结论不同：

**物理种子生产端**：高度分散。全世界有数以万计的种子公司、育种站、农民留种系统。多数农作物、多数发展中国家的多数种植面积仍用农家种、公共品种或本地扩繁的种子（C2，粮农组织长期口径，需原文核）。物理供给不是单点。

**高价值商业种子 + 性状 IP 端**：高度集中。少数跨国巨头控制全球大部分商业种子销售和专利性状 IP：
- 拜耳（Bayer，2018 年收购孟山都 Monsanto）
- 科迪华（Corteva Agriscience，2019 年从陶氏杜邦分拆独立）
- 先正达集团（Syngenta Group，中国化工 2017 年收购先正达，后并入中国中化 / 先正达集团）
- 巴斯夫（BASF，2018 年从拜耳-孟山都合并的反垄断剥离资产中接手了一大块种子和性状业务）

这四家（业内常称种子/农化的"Big Four"或"三巨头+巴斯夫"）合计控制全球商业种子市场的大部分份额。常被引用的数字是**四大公司约占全球商业种子销售 50%+、占专利性状 IP 更高比例**（C3，IPES-Food / ETC Group 等 NGO 报告口径，各家精确份额需原文核）。在特定高价值作物 + 转基因性状上集中度更高：转基因玉米、大豆、棉花的核心性状专利高度集中在拜耳（原孟山都）和科迪华手里（C3，需专利数据库核）。

Access maker：谁决定农民能不能用上最高产的那套性状，是持有性状专利的那家公司（它可以授权、可以拒绝授权、可以定授权费），加上批准该性状能否商业化种植的各国监管方。这两方叠加才构成完整的 access 控制。

【缺口：ETC Group《Food Barons》系列报告 / IPES-Food 报告中四大公司商业种子市场份额的原始口径和年份；Phillips McDougall / Kynetec 等农业投入品市场研究机构的种子市场集中度数据】

### 5. 上游依赖（子节点）

种子节点自己绕不开的东西，比多数农业节点少（种子生产不依赖稀缺矿产、不高度依赖能源），但有几处结构性上游：

**种质资源（遗传材料的原始来源）**：所有商业品种都从既有的遗传多样性里选育而来，来自地方品种、野生近缘种、种质库（gene bank）里保存的样本。这套原始遗传材料的获取受《生物多样性公约》和**名古屋议定书**（Nagoya Protocol，关于遗传资源获取与惠益分享，ABS）约束：一国的种质资源被另一国公司拿去育种并申请专利，涉及惠益分享和"生物剽窃"（biopiracy）争议。这是种子 IP 最上游的政治接口：性状 IP 的原料本身有主权归属。建议下轮单列子节点 **ag-seed-germplasm**（种质资源获取与惠益分享）。

**育种技术平台（转基因 / 基因编辑）**：转基因（GMO）依赖 Bt 基因、抗除草剂基因等专利化的遗传元件和转化技术；基因编辑（CRISPR 等）依赖编辑工具本身的专利（CRISPR 核心专利有自己的一套集中和诉讼史，主要在美国 Broad 研究所 / UC 之间，属于另一个节点，可以关联、不必并入本节点）。这一层是性状 IP 的技术底座。

**监管审批数据包**：一个转基因性状要能商业化，需要在每个目标市场做安全评估、拿批准，这套审批数据的生成和维护本身是巨额沉没成本（单个性状从研发到全球审批常被引用为数亿到十亿美元级、十年以上周期，C3，需行业报告核），构成重建壁垒（见第 8 维），也是小公司进不来的原因之一。

【缺口：单个转基因性状从研发到全球监管审批的成本 / 周期数字——需 CropLife International 或 Phillips McDougall 的性状开发成本研究原文】

### 6. 下游依赖方

**致命依赖（依赖高产商业种子、且已无留种能力）**：
- 大规模商业化种植的农场（北美玉米 / 大豆 / 棉花带、南美大豆带）：几乎全部使用商业杂交种 / 转基因种，每季重买，留种既不划算（杂交衰退）也常违约 / 侵权。断供或授权费大涨直接推高种植成本。
- 依赖特定抗除草剂性状体系的农场：种子和配套除草剂绑定，换种子等于换整套农艺体系，转换成本高。

**高依赖（可缓冲但代价大）**：
- 用商业杂交种但可退回公共品种的种植体系：退回去产量下降，但不是种不出来。
- 发展中国家采用绿色革命 / 商业杂交种的地区：对商业种子有依赖，但常有平行的公共育种和农家种系统作底。

**低依赖 / 可自给**：
- 大量小农、口粮作物（很多地区的小麦、水稻自留种比例仍高；自花授粉作物如小麦、水稻留种性状衰退远小于杂交玉米）。这部分下游对商业种子 IP 的依赖天然低。这是种子节点和氮肥节点的关键区别：氮肥没有"自给"退路（土壤氮必须补），种子对相当一部分作物和农户是有自给退路的。

依赖强度判断：**依赖度高度分作物、分种植体系**。杂交玉米 + 转基因大豆 / 棉花的商业种植体系依赖度"致命"；自花授粉口粮作物 + 小农体系依赖度"可缓冲到低"。不能用"种子"一个数字概括。

【缺口：主要作物商业种子 vs 农家种 / 自留种的种植面积占比——需粮农组织或各国农业部的种子来源统计】

### 7. 替代路径 + fallback 等级

分机制看，退路强弱差别很大：

**退回公共品种 / 本土老品种（绕开 IP 锁定的性状）**：`partial`
- 替代哪一层：受专利 / 品种权保护的高产性状
- 多久接上：即时可得（公共品种、种质库品种现成存在），但产量和抗性下一档
- 卡在哪个转换环节：①产量差，放弃 IP 性状通常意味着单产下降（幅度分作物、分性状，玉米杂交 vs 农家种差距可达数成，C2 推算，需农学数据核）；②配套农艺，抗除草剂体系一旦退出，整套除草方案要重做；③种子扩繁能力，公共育种和地方扩繁体系在很多地方已萎缩，短期难以规模供种
- 谁有权限启动：农民 / 国家公共育种体系
- 现场执行能力：公共育种机构（CGIAR 系统、各国农科院）确实存在并运转，但资金和覆盖远不及商业巨头
- 结论：退得回去，但要付产量 + 农艺重组的代价，且公共育种供种能力是瓶颈 → `partial`

**留种（针对杂交种）**：`blocked`（生物学阻断）
- 杂交种留种得到 F2，性状分离、产量大幅下滑，生物学上不成立
- 这不是"退路差"，而是"退路被种子的生物学结构关掉了"，这正是杂交生物锁定的意义
- 对自花授粉作物（小麦、水稻）留种：`operational`（留种性状衰退小，是真退路，这也是为什么小麦 / 水稻的种子 IP 卡点远弱于玉米）

**本土 / 新兴种业公司替代跨国巨头 IP**：`possible reroute`
- 中国、印度有本土种业公司（隆平高科、先正达集团中国资产、印度的种业企业等），能在部分作物、部分市场提供替代；但核心转基因性状 IP 和全球审批数据包的差距是中长期（5–10 年以上）
- 结论：`possible reroute`（不是当季 fallback）

**基因编辑绕开旧转基因专利**：`planned / possible reroute`
- 基因编辑（CRISPR）理论上可以做出不含旧 Bt / 抗草甘膦专利的新性状，绕开孟山都系专利；但 CRISPR 本身有专利、且各国对基因编辑作物的监管定性尚在演变（欧盟收紧、美国相对宽松）
- 结论：结构上是绕开旧 IP 的潜在路径，但受新一轮专利和监管约束，不是现成退路

### 8. 重建壁垒 + 前置期

种子节点的重建壁垒不在物理生产（育种站、扩繁田不是稀缺资产），在三处无形壁垒：

- **性状 IP + 专利组合**：核心商业性状被专利圈住，重建等于要么绕开（基因编辑，见上）、要么等专利到期（部分早期转基因专利已陆续到期，如第一代抗草甘膦大豆专利约 2014–2015 年到期，衍生出"generic GMO"讨论，C3 需核），要么授权（付费）。专利到期是这个节点最确定的"卡点会移动"的变量。
- **全球监管审批数据包**：一个性状要在多个市场合法商业化，需要各国批准；这套数据的生成和维护是十年级、数亿美元级的沉没成本（C3 需核），中小公司和多数发展中国家育种体系跨不过去。
- **育种数据 + 种质积累**：几十年的育种数据、亲本材料、性状库是复利资产，新进入者难以在短期复制。

前置期：从零建立一个能与四大巨头在核心转基因作物上竞争的性状 + 品种 + 全球审批体系，是 10 年以上；退回公共品种是即时的（但降档）。这个"重建壁垒高、但退回降级版即时可得"的组合，决定了第 7 维 fallback 是 `partial` 而非 `blocked` 或 `operational`。

### 9. 议价 / 控制机制

- 卡点 type：`information`（专利 / 品种权 IP，控制的是遗传信息的合法使用）+ `permission`（各国转基因 / 基因编辑审批、种子进出口检疫许可）+ `physical`（杂交生物锁定：这一条罕见地把物理 / 生物机制本身变成卡点，而不是靠外部规则）
- 卡点 mode（分机制）：
  - 杂交种（玉米）：`toll` 型，接近"订阅"，农民每季必须付费重买，没有免费留种选项，但市场上有多家杂交种供应商，不是单一 `closed`
  - 专利性状授权：`toll`（付授权费可用）到 `selective`（专利持有者可拒绝授权给特定对象 / 特定用途）
  - 转基因审批：`allow by exception`，一个性状默认不能商业化种植，必须逐国拿批准；某国不批 = 对该市场 `closed`
  - 公共品种 / 自花授粉作物留种：`open`（无锁）
- 关键机制区别（对全图的意义）：**种子节点是全图唯一一个把"生物学结构本身"用作卡点的节点。** 别的节点靠许可（芯片出口管制）、靠物理单点（海峡）、靠网络效应（贸易融资）、靠命令（制裁）；杂交生物锁定靠的是育种方式让种子自己丧失可留种性。这是一种"来历"上极特殊的控制点：它不是建造时设计进系统，也不是被挪用，而是把控制点直接编进了产品的生物学。它最接近领域核第四节之六说的"由经济规律自然形成"里最硬的一种：一旦农民采用杂交高产种，留种衰退这个生物事实就自动完成了锁定，不需要任何人每季去执行拒绝。

### 10. 历史变迁（卡点怎么移动）

几个节点标记了种子卡点的形成和移动：

**1930 年代起：杂交玉米商业化，锁定机制诞生**。美国杂交玉米从 1930 年代大规模推广，产量大幅提升，同时农民从"留种自给"转为"每季买种"（C3，农业史广知）。这是杂交生物锁定第一次大规模把一种主粮的种子变成年度商品，早于任何专利法，纯靠生物学。

**1980 年代起：植物品种可专利化，IP 锁登场**。美国最高法院 Diamond v. Chakrabarty（1980）确立生物可专利，此后植物性状、转基因构建物进入专利体系（C3 需核判例）。种子的控制从"生物学锁定"叠加上"法律 IP 锁定"，两把锁并用。

**1996 年起：转基因商业化，性状 IP 集中**。孟山都的抗草甘膦（Roundup Ready）大豆、Bt 玉米从 1996 年商业化，配套"种子 + 除草剂"捆绑和禁止留种的技术使用协议（TUA）。转基因把种子 IP 推到高度集中，核心性状专利集中在孟山都等少数公司（C3）。

**2016–2019 年：三场大合并，四巨头格局定型**。行业在三年内完成史上最大规模农业并购重组：
- 2016–2017 年，中国化工（ChemChina）约 430 亿美元收购瑞士先正达（C3，本节点主争夺事件，详见下文）
- 2018 年，拜耳约 630 亿美元收购孟山都（C3），为过反垄断向巴斯夫剥离约 70–90 亿美元种子 + 性状资产（C3 需核）
- 2017–2019 年，陶氏与杜邦合并再分拆，农业部分独立为科迪华（C3）
这三场并购把此前的六大（"Big Six"：孟山都、杜邦先锋、先正达、陶氏、拜耳、巴斯夫）收敛成四大，集中度进一步上升。

**卡点移动趋势**：从"纯生物学锁定（杂交）"→ 叠加"法律 IP 锁定（专利）"→ "全球性状 + 审批体系的资本壁垒"→ "四巨头 + 一个跨法域争夺（中国控制先正达）"。下一步的两个变量：①早期转基因专利陆续到期（松动 IP 锁）；②基因编辑 + 各国对其监管定性（可能重开性状竞争，也可能形成新一轮专利集中）。

### 11. 因果层

三层都在，权重和技术节点不同：

**物质约束（这里表现为"生物学约束"，是本节点最独特的一层）**：杂交衰退是一个硬生物事实，F1 杂种优势不能通过留种传给 F2，这不由任何人的意志决定。这一层给了种子节点一个别的节点没有的性质：卡点不需要持续的人为执行，生物学自己每季完成一次锁定。确定性极高，可以下确定的判断。

**real force（重要）**：种子接的是和 ag-grain / ag-fertilizer-n 同一条 real force 链——粮食安全是政治红线。但种子这一格的 real force 有自己的色彩：**种质主权和粮食自主**。一国的主粮种子 IP 若被外国公司控制，被广泛感知为国家安全 / 农业主权问题（中国收购先正达的核心动因之一正是补种业短板、掌握性状 IP）。转基因还叠加了消费者层面的 real force：公众对转基因的接受 / 抵制（欧盟严、美国宽、各国分化）本身是一股能改写监管、影响市场准入的真实力量，且它不可被还原为技术风险数据（领域核第九节盲区提醒：不要把民族主义 / 公众情绪压缩成技术问题）。

**individual leverage（有条件）**：三场大合并中，各家 CEO 和监管审查（美国 CFIUS、欧盟竞争总署、中国商务部）的具体人物和时机属于调用层，结构分析预测不到，但可从物质约束（IP 是复利资产、审批是沉没成本）和 real force（种业主权）解释为什么这些交易被这样审、这样批 / 卡。

### Q4. 下游依赖度量化

方向一（本节点对下游成本的影响）：
- 种子成本占大田作物（玉米 / 大豆）总种植成本约 10–20%（C2 推算，需 USDA ERS 成本结构数据核）；转基因种 + 性状费使这一比例高于常规种
- 抗除草剂性状体系还捆绑除草剂支出，实际"种子 + 配套农化"占比更高

方向二（断供 / 涨价后下游的处境）：
- 高产商业种子授权费大涨 → 商业农场种植成本上升，但当季仍能买到（不是物理断供）
- 若某性状被撤销授权 / 某国不批 → 该市场退回上一代品种，产量下降（幅度分作物）
- 种子的"库存缓冲"概念不同于氮肥：农民播种前采购，一季一次，错过播种窗口当季无法补种

【缺口：USDA ERS 玉米 / 大豆种植成本结构中种子成本占比；转基因种 vs 常规种单价差数据】

### Q5. 断供 / 管制的经济冲击量级

- 种子节点很少发生"断供"型冲击（种子分散、可扩繁、可退回公共品种），历史上的冲击更多是**价格 / 授权 / 并购审查**型，不是物理归零
- 可参照的量级：三场大合并的交易规模本身（先正达 430 亿、拜耳-孟山都 630 亿）是种子 / 农化行业价值的直接标尺（C3）
- 系统性风险不在"某季种子断供"，在"少数公司控制主粮性状 IP"的长期结构性依赖——这类风险难以货币化，更接近 real force 层（种业主权）而非可算的 GDP 损失

【缺口：若要量化"性状 IP 集中的经济影响"，需 OECD 或世界银行关于种业集中度对农民成本 / 创新影响的研究报告；目前无现成的断供冲击货币化数字】

### Q6. 资本流向与利润归宿

- **育种 / 性状研发端（四大公司）**：利润在这里沉淀——性状 IP 是高毛利资产，专利期内的授权费和种子溢价是主要利润来源
- **种子扩繁 / 分销端**：毛利低于性状端
- **农民端**：种子 + 配套农化是成本项；杂交生物锁定和 IP 使农民无法通过留种把这部分成本内部化（对自花授粉作物则可以）
- **公共育种体系（CGIAR、各国农科院）**：产出公共品种、无 IP 溢价，长期资金不足

政治压力落到哪张资产负债表：
- 转基因审批收紧（某国不批）→ 首先打持有该性状的公司的市场准入 + 该国采用该性状的农民
- 种质资源惠益分享争议（名古屋议定书）→ 打育种公司的原料合法性
- 跨法域收购审查（CFIUS 型）→ 打收购方的交易能否完成 + 目标公司 IP 的控制权归属

## 政治传动层

### A. 公开接口

- **品种权 / 专利**：UPOV 公约（国际植物新品种保护联盟）+ 各国植物品种保护法 + 专利法（转基因构建物专利）；美国 Plant Variety Protection Act、专利体系；这是 IP 锁的法律接口
- **转基因 / 基因编辑审批**：各国生物安全监管——美国 USDA APHIS / EPA / FDA 协调框架；欧盟 GMO 授权指令（Directive 2001/18/EC 等，严格）；中国农业农村部转基因安全评估；这是性状能否商业化的许可接口
- **种质资源获取与惠益分享**：《生物多样性公约》+ 名古屋议定书（Nagoya Protocol，ABS）+ 粮农组织《粮食和农业植物遗传资源国际条约》（ITPGRFA）；这是种质原料的主权接口
- **跨国收购审查**：美国 CFIUS（外国投资审查，中国化工收购先正达经此审查）；各法域反垄断（欧盟竞争总署、美国 FTC / DOJ、中国商务部——三场合并都过多法域反垄断）

【缺口：中国化工收购先正达的 CFIUS 审查结论原文 / 时间；欧盟竞争总署对拜耳-孟山都、陶氏-杜邦、中国化工-先正达三案的反垄断决定文号】

### B. 控制状态流转

- 转基因性状商业化：`presumption of denial`（拒绝推定），默认不能种，必须逐国拿批准才 `allow by exception`；欧盟长期停留在高门槛端，美国相对宽
- IP 授权：`allow by default`（付费可用）→ 专利持有者可对特定用途 / 对象 `selective`
- 跨国收购：`allow by exception`，大型农业并购默认要过多法域反垄断 + 战略审查，翻转门槛是各监管方（可要求剥离资产，如拜耳-孟山都向巴斯夫剥离）
- 杂交生物锁定：无"状态流转"，它不是政治开关，而是生物学常态，不需要谁翻转

翻转门槛：转基因审批看各国监管机构（一国政治 + 科学评估）；收购看多法域反垄断，需分别过关，任一法域可否决或要求剥离；这是种子节点区别于单一法域节点的特征：控制权分散在美欧中三套审查体系。

### C. 适用账本

- 许可账：转基因审批批文；品种权 / 专利登记；种子进出口检疫许可
- 建设债账：性状研发 + 全球审批数据包（十年级沉没成本）；公共育种体系投入
- 收费时点账：种子销售（每季，杂交种必买）；性状授权费

### D. first payer

- 转基因审批收紧：first payer = 持有该性状的公司（市场准入损失）+ 想用该性状的农民
- 收购被否 / 要求剥离：first payer = 收购方（拜耳被迫向巴斯夫剥离约 70–90 亿美元资产）
- 种质资源惠益分享争议：first payer = 育种公司（原料合法性 / 惠益支付）
- 授权费上涨 / 杂交必买：first payer = 农民（每季种子成本）

### E. 时点

- 中国化工收购先正达完成：2017 年（C3，需核 CFIUS 通过和交易完成的精确日期）
- 拜耳收购孟山都完成：2018 年 6 月（C3，需核）
- 科迪华从陶氏杜邦分拆独立：2019 年 6 月（C3，需核）
- 巴斯夫接手拜耳-孟山都剥离资产：2018 年（C3，需核）

### F. 叙事合法化

- **中国（收购先正达）**：种业主权 / 补农业科技短板 / 粮食安全——"掌握核心种源和性状 IP 是国家安全"（C3）
- **拜耳 / 科迪华（并购）**：规模 + 研发协同 / 喂饱增长的人口 / 创新效率——用"农业创新和粮食安全"为集中度上升辩护（C3）
- **反对方（NGO：ETC Group / IPES-Food / 农民组织）**：种子主权 / 反垄断 / 农民留种权 / 反生物剽窃——把集中度和 IP 锁叙述为对农民和粮食体系的威胁（C3）
- **转基因监管两极**：欧盟用预防原则 / 消费者选择权为严格审批辩护；美国用科学等效 / 创新为宽松辩护——同一技术，两套 real force 叙事

## 卡点分析

- **位置**：ag 栈 L0 投入品层，ag-grain 的上游（种子决定能种什么、产量遗传上限）。卡点集中在三处：①性状 IP（专利 / 品种权）②转基因 / 基因编辑审批（各国监管）③杂交生物锁定（生物学）
- **持有者**：拜耳（原孟山都，核心转基因性状）；科迪华（玉米 / 大豆性状）；先正达集团（中国实控）；巴斯夫；各国监管方（审批）；持有种质资源的原产国（名古屋议定书）
- **卡点来源**：监管护城河（审批数据包 + 品种权）+ 网络效应 / 规模经济（育种数据 + 专利组合复利）+ 标准锁定（性状 + 配套农化捆绑）+ **生物锁定（杂交衰退，全图独有）**。多重叠加；物理种子本身不是单点。
- **政治进入后转移**：中国化工收购先正达是这个节点最大的一次控制权跨法域转移——把一家瑞士种业巨头的性状 IP 和品种控制权移到中国国有资本手里。此外，早期转基因专利到期正在缓慢松动 IP 锁（一个自动发生的转移）。
- **干预窗口**：
  - 反垄断 / 收购审查：窗口在交易发生时（已用过——三场合并都过审，部分被要求剥离）
  - 转基因审批：各国持续开着的政策杠杆（欧盟严 / 美国宽）
  - 专利到期：自动发生，无需干预，但催生"generic GMO"和公共品种复兴的机会窗口
  - 公共育种投资：长期窗口，是对冲 IP 集中的结构性手段
  - 杂交生物锁定：无干预窗口——生物学不由政策翻转，只能靠"改用自花授粉作物 / 公共品种"绕开
- **最硬反例 + 过三关**：「种子可以留种、可以扩繁，所以种子 IP 不构成真正的卡点」
  - 前提成不成立：部分成立——种子物理上确实可复制，对自花授粉作物（小麦 / 水稻）留种是真退路，这类作物的 IP 卡点确实弱。
  - 可不可比：对杂交作物（玉米）不可比——杂交衰退是生物学阻断，留种不是"违法"而是"产量不成立"，物理可复制性在这里被生物学关掉了；对受专利保护的转基因性状也不可比——复制是侵权，退回无专利品种要付产量代价。
  - 真发生过：农民对孟山都留种侵权的诉讼（如美国 Bowman v. Monsanto，2013 年最高法院判孟山都胜，确认专利种子留种侵权，C3 需核判例）是 IP 锁真实生效的实证；杂交玉米八十年来农民每季买种是生物锁定的实证。
  - 结论：种子的物理可复制性使它对自花授粉作物 + 无 IP 品种是弱卡点（真有留种退路）；但对杂交作物（生物锁）和受专利保护的转基因性状（IP 锁）是真卡点——卡点不锚在物理种子，锚在生物学 + IP 这两把加在可复制性上的锁。

  - fi-usd（种子 / 性状国际贸易与授权费美元计价，弱耦合）
  - ip-patent（如果全图有 IP / 专利栈，种子性状专利是其中一个高度集中的节点；CRISPR 专利战可耦合）
  - ag-grain（下游，一季滞后的产量传导，同 ag-fertilizer-n 的结构）
- **跨域效应**：
  - Sigma：绿色革命后种子 / 性状与产量 / 人口的量化关系是大历史数据；种业集中度是量化政治经济学变量
  - 余笺：农民留种传统的消失、种子与农家生活的个体史
  - 法玛：转基因的公众接受 / 抵制是 AI 之外另一个"技术与社会相互塑造"的经典案例（可作类比参照，不作诊断框架——见方法层第 10 条和用户"别拿跨域类比当诊断框架"的纠正）

## 方向、两条流、最近一次被争夺的事件

### 拒绝方与操作方

**拒绝方（自上而下能拒绝的）**：
- **性状专利持有者**（拜耳 / 科迪华等）：可拒绝授权、可定授权费、可起诉留种侵权。拒绝权来源：对遗传信息的知识产权（所有权的信息版）。
- **各国监管方**：可拒绝批准某转基因 / 基因编辑性状商业化（欧盟长期实际拒绝多数转基因种植）。拒绝权来源：国家主权对本国农业和生物安全的管辖权。
- **种质原产国**（名古屋议定书下）：可主张遗传资源主权、要求惠益分享，拒绝无授权取用。拒绝权来源：对本国遗传资源的主权。
- **收购审查方**（CFIUS / 反垄断）：可否决或附条件批准跨国种业收购。拒绝权来源：国家 / 联盟对战略资产和市场竞争的监管权。

**操作方（运转育种和扩繁、能从内部停止配合的）**：种子节点的操作方力量很弱。实际运转育种和扩繁的是育种科学家、扩繁农户、种子加工厂，这是分散的、技术密集的、不依赖大量可集体行动体力工人的环节（像 ag-fertilizer-n 的化工工程师，不像煤矿工人）。育种数据和亲本材料握在公司手里，扩繁可外包、可转移。所以种子节点几乎没有"操作方从内部卡住"的力量，杠杆完全在拒绝方（IP 持有者 + 监管方）这一侧。唯一接近操作方力量的是**农民集体的采用 / 拒用选择**：如果大量农民集体拒绝某性状（如欧洲农民 + 消费者对转基因的抵制），能反过来压制市场准入，但这更接近 real force / 人心层，不是传统意义的操作方罢工。

### 两条流：种子 IP 更像价值流中断点还是物理流

**结论：种子 IP 是价值流 / 信息流的中断点，不是物理流的中断点。**

**物理流（几乎卡不住）**：种子作为实物从育种 → 扩繁 → 加工 → 分销 → 农民，物理运输约束低，且种子可扩繁、可走私、可留种（对自花授粉作物）。想在物理层"断种子供应"极难，它太分散、太容易复制。物理流不是这个节点的杠杆所在。

**价值流 / 信息流（真正的中断点）**：杠杆全部在这一侧。
- IP（专利 / 品种权）控制的是"合法使用那套遗传信息"的权利，这是信息流 + 价值流的交叉：谁能用这套遗传信息（信息流），以及用它要付多少授权费 / 种子溢价（价值流）。
- 断这条流的方式不是拦截物理种子，是：拒绝授权、抬高授权费、起诉留种侵权、监管不批准商业化。这些都作用在信息 / 价值层，不作用在物理运输层。
- 杂交生物锁定是一个特例：它既不是纯物理流也不是纯价值流，它把"每季付费"这个价值流事实用生物学（物理机制）固定下来，用物理手段实现价值流的持续收费。

对比 ag-fertilizer-n（杠杆在物理流：能源成本、产能、断供）和 ag-grain（物理流通道 + 价值流融资双卡）：种子节点是农业栈里**杠杆最偏向价值 / 信息流的一个**：物理种子几乎不可控，控制权全部建立在 IP 和监管这套信息 / 许可结构上。这与领域核第二节"在系统中位置越低不等于权力越大"一致：种子的物理实物层（低位）几乎无权力，真正取走价值、控制准入的是其上的 IP 和审批层。

### 最近一次被争夺的事件（主）

**事件：中国化工收购先正达（2016 年 2 月宣布 — 2017 年 6 月完成，约 430 亿美元）**

这是全球种子 / 性状 IP 控制权历史上最大的一次跨法域转移：一家中国国有企业买下一家瑞士种业 + 农化巨头，把先正达的性状 IP、品种和全球研发平台的控制权移到中国手里。用五个阅读动作读这场争夺：

**① 校准颗粒度**：争夺的焦点不是"先正达这家公司"这个整体，而是**先正达手里的种子 + 性状 IP 和研发平台的控制权归谁**。中国要的核心不是先正达的存量农药销售，而是它的育种数据、性状专利组合和全球审批能力，中国种业长期缺核心性状 IP，收购是补这个短板最快的路。所以真正被争夺的节点，是"性状 IP + 育种平台的控制权"，先正达这家公司只是承载它的壳。同时，这场收购要过的不是一道关，是**多法域审查**（美国 CFIUS、欧盟竞争总署、以及其他二十多个司法辖区的反垄断），每一道审查都在争夺"这套 IP 落到中国手里，本法域接不接受"。

**② 跟着反应链走**：宣布收购（2016-02）→ 美国 CFIUS 启动国家安全审查（先正达在美国有大量农业资产和种子业务，触发外资审查）→ CFIUS 最终放行（2016 年，据报道审查聚焦农业数据和粮食安全，最终通过，C3 需核结论原文）→ 欧盟竞争总署反垄断审查，要求剥离部分农药资产作为批准条件（C3 需核）→ 其他法域陆续放行 → 2017-06 交易完成 → 此后引发广泛的"种业主权"讨论：一个大国的农业性状 IP 是否应该被另一个大国的国企控制。反应链暴露的当事方：中国化工 / 中国政府（收购方 + 战略意图）、先正达管理层 + 瑞士（被收购方）、美国 CFIUS（战略审查）、欧盟竞争总署（反垄断）、以及被这笔交易刺激加速的拜耳 / 陶氏杜邦（同期启动自己的大合并以维持竞争地位）。

**③ 点名那个被当成舞台的一方**：主流叙述把这讲成"中国 vs 西方争夺种业"，把**监管审查体系本身**（尤其 CFIUS 和欧盟竞争总署）当成中立的地面。但审查方不是地面，它们有自己的决定性手段：CFIUS 有权直接否决交易（它否决过其他中国收购案），欧盟竞争总署有权要求剥离资产作为放行条件。这场交易能不能成、以什么形态成，决定权相当程度在这些"被当成程序背景"的审查机构手里。另一个被当成舞台的是**先正达的性状 IP 所嵌入的美欧专利体系**：IP 虽然控制权转移给中国，但专利本身仍注册在美欧法域、受美欧法律管辖，中国拿到的是"控制一家公司"，不是"把 IP 搬回中国脱离美欧法域"。这层结构被"中国买下先正达"这个说法盖住了。

**④ 把节点放到时间里读**：先正达的控制权历史，瑞士本土公司（诺华 + 阿斯特拉捷利康农业部分 2000 年合并成先正达）→ 2015 年拒绝孟山都的收购要约（先正达曾是收购别人的一方）→ 2016–2017 年被中国化工收购 → 后并入中国中化 / 先正达集团，一度推进 A 股上市又撤回。控制权从"瑞士独立巨头"到"中国国有资本实控"，而性状 IP 仍分布在美欧中三套法域。静止快照（"先正达现在是中国的"）盖住了这套跨法域控制结构的复杂性。

**⑤ 把说法和数字当动作**：
- "中国买下了瑞士种业巨头"这个说法准确，但盖住了"IP 仍在美欧专利体系里、中国控制的是公司不是脱域的 IP"这层结构。
- "430 亿美元"这个数字，是当时全球最大的中国海外收购，数字本身被中国用作"种业投入决心"的信号，也被西方用作"中国战略性收购关键农业资产"的警号，同一个数字被两边当作不同叙事的动作。
- "种业主权 / 粮食安全"叙事：中国用它对内合法化巨额收购（补种业短板是国家战略），西方部分声音用它警示战略资产外流；这套叙事本身是争夺的一部分，不是对事件的中立描述。

**结论**：这场争夺照出了 ag-seed 节点最关键的结构特征：**种子的杠杆不在物理种子，在性状 IP + 育种平台的控制权，而这套控制权可以通过收购一家公司整体转移，却又受制于 IP 注册所在的多个法域。** 中国没有、也无法"把种子搬回国"，因为种子物理上到处都是；它做的是买下承载性状 IP 和育种能力的公司，把控制权移到自己手里，同时接受这套 IP 仍嵌在美欧专利和审查体系里的现实。这也解释了为什么这场争夺的主战场是 CFIUS 和反垄断审查室，而不是任何港口或农田：种子节点的争夺发生在 IP 和监管的信息 / 价值层，不在物理层。

（本节点的次要争夺事件候选：拜耳收购孟山都的反垄断审查 + 向巴斯夫的剥离，可在下轮补深挖；孟山都留种侵权诉讼 Bowman v. Monsanto 是 IP 锁生效的判例实证，可作卡点分析支撑。因本节点从零起草、精力集中在一场深挖，次事件留待下轮。）
