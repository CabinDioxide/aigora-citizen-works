## 结构层

### 1. 功能定义

AI 加速器是把矩阵乘法跑快的引擎。一次大模型训练要做的本质上是天量的浮点矩阵运算，CPU 跑这个慢得不可接受，GPU（和它的衍生 ASIC）卡的就是这件事：**没有足够多、足够快、能互联成集群的加速器，模型就训不出来，推理也供不起。**

但这个节点真正绕不开的地方不在硅片本身，在硅片上面那层软件。NVIDIA 的护城河有两段，分清楚很重要——

- **硬件段**：单颗芯片的设计领先（制程 + 架构 + 高速互联 NVLink）。这一段是真的，但窄，AMD MI300、Google TPU、Amazon Trainium 在纸面算力上已经能逼近甚至局部超过。
- **软件段：CUDA 生态**。十几年累积的 CUDA 库、框架适配、开发者技能、调好的算子。这一段才是别人换不掉的——你买得到一块算力相当的 AMD 卡，但把整套训练代码、调优经验、算子库迁过去的成本，让多数客户宁可排队等 NVIDIA。

所以 ac-gpu 的卡点不是「谁能造出快芯片」，是「谁的快芯片插进去就能跑、生态现成」。这让它和上游 ac-fab 性质相反：ac-fab 是物理单点（产能在某座岛上，搬不走），ac-gpu 是**生态锁定型单点**（芯片哪都能设计，但生态迁不动）。

它不做：制造（fabless，全押 TSMC，见 ac-fab）、不做存储（HBM 是 ac-hbm，但要堆进同一颗加速器）、不做封装（CoWoS 在 TSMC）。NVIDIA 只画图 + 建生态，物理实现全靠上游。

### 2. 物质形态与可运输性

比特（设计 IP + CUDA 软件）+ 设备（成品加速器卡/服务器），双重。

物理形态的卡脖子含义：
- **设计是比特，能瞬时跨境流动**——这意味着 GPU 的「图纸」本身没有运输卡点，约束全在两端：上游能不能造出来（TSMC），下游能不能合法买到（出口管制）。
- **成品是高价值密度设备**，一台 8 卡 H100/H200 服务器价值数十万美元，体积小、易运输、易走私——这恰恰是它被出口管制和灰色转运同时盯上的原因。一批先进 AI 服务器能装进几个箱子，物理上拦不住，只能靠法律和金融追踪拦。
- **CUDA 是纯比特，但迁移成本极高**：软件可以免费复制，但「让现有代码跑在别家硬件上」的工程成本是真实的物质性壁垒——它不锁在某个文件里，锁在几百万开发者的肌肉记忆和几十万行调优过的算子里。

可运输性的政治含义：和 EUV 整机那种「重型设备运输即可追踪」不同，AI 加速器是**小型高价值物**，走私和第三国转运是真实漏洞（已有大量经新加坡/中东转运至中国的报道，C3）。管制的执行难点不在生产端（NVIDIA 在美国法域，听话），在流通端（货太小、太值钱、太多中间商）。

### 3. 供给集中度

AI 加速器（数据中心训练/推理 GPU）是高度单点，NVIDIA 一家近乎独占。

- **AI GPU / 加速器市场 NVIDIA 份额**：约 **80%+**（C2–C3，行业口径，2024 年估计高达 ~87%，分析机构预计随 AMD + 自研 ASIC 放量逐步降至 ~75% 量级，2026 估计）。
- AMD：约 **5–7%**（C2，2026 初口径），是名义上的第二点。
- 自研 ASIC（Google TPU、Amazon Trainium、Microsoft Maia、Meta MTIA）：合计份额上升中，但主要自用、不外卖，且仍大量并行采购 NVIDIA。

access maker：NVIDIA 是 AI 算力的 access maker——它通过**产能分配**决定哪个客户、什么时候、拿到多少 H100/H200/B200。2023–2024 算力荒期间，「能不能排到 NVIDIA 的货」直接决定一家 AI 公司的训练节奏，分配权本身就是权力。

证据级：NVIDIA AI GPU ~80% 份额 = source-linked（行业广泛口径，第三方机构估算，非官方披露，口径随机构变动）；CUDA 生态锁定 = query-designed（结构判断，强度难精确量化）。

### 4. 主要持有者 + 份额 + 法域

|---|---|---|---|---|

**法域要记一笔——这是整个 Stack Atlas 里最干净的「技术单点直接落入单一国家法域」的案例**：AI 加速器的卡点持有者（NVIDIA、AMD、Intel、四家自研 ASIC 的母公司）**全部是美国公司，全部在美国本土法域**。这和上游 EUV 完全不同：EUV 的美国抓手是「含美技术」的 FDP 域外触发（间接），而 AI 加速器是美国公司在美国境内设计——美国对它的管辖是**直接本土管辖**，不需要借道任何域外规则。H20 案例（见政治传动层）就是这个直接抓手的实操证明。

唯一的非美法域玩家是华为昇腾，但它被卡在上游：自己设计得出，却造不出（被 TSMC 拒单，退回中芯 7nm DUV，先进制程上限受 ac-fab 节点的封锁直接制约）。

### 5. 上游依赖（子节点）——拆到子供应商

ac-gpu 的特殊之处：**它本身是下游的卡点持有者，但对自己的上游是彻底的人质**。NVIDIA 卡着全世界的 AI 算力，但 NVIDIA 自己绕不开的东西一个比一个硬：

- **先进制程代工：TSMC（ac-fab）**。H100/H200/B 系全在 TSMC 先进节点 + CoWoS 封装。致命单点，已拆（ac-fab）。NVIDIA 没有 plan B——三星顶不了同档良率。
- **HBM 高带宽内存：SK 海力士 / 三星 / Micron（ac-hbm）**。AI 加速器的算力被内存带宽卡着，HBM 堆叠是物理必需。三家寡头，SK 海力士主导（HBM 占其 4Q24 DRAM 营收 >40%，source-linked，来源 magnitude-seed-ledger `lg-skhynix-hbm-dram-4q24`）。已拆（ac-hbm）。
- **CoWoS 先进封装：TSMC**。把 GPU die 和 HBM 堆一起靠 CoWoS。2023–2024 AI 芯片荒一度就卡在 CoWoS 产能而非晶圆本身（C3）。这条让 ac-gpu 和 ac-fab/ac-hbm 在封装层强绑定。
- **EDA 设计工具：Synopsys / Cadence / 西门子 EDA（ac-eda）**。版图到流片必经，软件单点。
- **ABF 载板 / FC-BGA 封装载板：味之素 + 载板四厂（ac-abf / ac-substrate）**。GPU 封装的隐形物料瓶颈（来源 magnitude-seed-ledger `gb-abf` / `gb-substrate`）。

评估：ac-gpu 是「下游卡点持有者 + 上游人质」的双面节点。它对客户是 access maker，对供应商是 dependent。任何上游单点（TSMC 产能、HBM、CoWoS）断，NVIDIA 也出不了货——这是它和真正的物理单点（EUV 光源、TSMC 产能）的区别：NVIDIA 的力量更多锚在 CUDA 生态这条 real force 上，硬件供给链它自己也是被卡的一方。

### 6. 下游依赖方

- **致命依赖：所有做大模型的实验室 + 超大规模云**。OpenAI、Anthropic、Google、Meta、xAI、所有 AI 创业公司，以及 AWS/Azure/GCP/Oracle 的 AI 算力出租，训练算力压倒性押在 NVIDIA。依赖强度：致命，且短期无等量替代（CUDA 锁定）。
- **致命依赖：主权 AI / 国家算力计划**。各国「算力主权」计划（建本国 AI 算力底座）现阶段绝大多数还是买 NVIDIA——主权叙事喊得响，硬件还是同一家美国公司的（这条接叙事层 ac-sovereignty，反讽点：算力主权的物理基础在另一国手里）。
- **间接依赖：全球 AI 应用层**。模型训不出来/推理供不起，上面的应用全停。
- 依赖强度：致命。fabless 设计公司 + 软件生态锁定的组合，让下游被锁得比对 ac-fab 更深——ac-fab 还能转单给三星顶一部分，CUDA 生态短期内无处可转。

### 7. 替代路径 + fallback 等级

- **AMD MI300/MI350 系顶替 NVIDIA**：fallback 等级 `partial`。按五问：
  - 替代哪一层 = AI 加速器硬件 + ROCm 软件栈；
  - 多久接上 = 硬件现成可买，但软件迁移以季度到年计；
  - 卡在哪 = ROCm 生态成熟度落后 CUDA、现有训练代码迁移成本、调优经验不可移植；
  - 谁有权启动 = 客户自己（已有 Microsoft Azure / Oracle 采用 MI300X 做多元化）；
  - 现场能不能执行 = 能跑一部分（尤其推理 + 对成本敏感的 hyperscaler），顶不了全量训练生态。
  - 结论：`partial fallback`——硬件是真第二点，软件生态不是等量替代。分流得了价格压力和部分推理负载，顶不了 CUDA 锁定的训练大盘。
- **自研 ASIC（TPU / Trainium / Maia）**：fallback 等级 `partial / 自用专用`。Google TPU 在自家工作负载上是成熟替代（Gemini 全程 TPU 训练），但 TPU 不外卖、且每家 ASIC 都绑自家软件栈，不是开放市场的通用 fallback。对自研方是 operational，对市场是 `not available`。
- **CUDA → ROCm / OpenAI Triton / 各家编译器替代**：fallback 等级 `planned → 局部 operational`。软件层去 CUDA 化在推进，但「让任意现有 CUDA 代码无痛跑别家硬件」仍是 `possible reroute`，不是 operational fallback。
- **华为昇腾 / 中国本土 AI 芯片（对中国客户）**：fallback 等级 `forced partial`。被 NVIDIA 高端断供逼出来的国产替代，在中国市场内放量，但受 ac-fab 封锁制约先进制程上限，单卡算力 + 集群规模 + 软件生态全面落后。是「被迫的本土化」而非等量替代，且本身被上游卡着。

### 8. 重建壁垒 + 前置期

要复制 ac-gpu 这个位置，要同时拿下三样，任何一样都以年计：

- **先进 GPU 设计能力**：架构 + 高速互联（NVLink 级）+ 与先进制程协同。有钱能挖人，但追平架构代差以年计。
- **拿到先进制程产能**：自己得能下单 TSMC 先进节点 + CoWoS（中国玩家这一关被直接封死）。
- **建起生态**：这是最难的一关，也是十几年级的。CUDA 从 2006 年推出到锁定全行业用了十几年，靠的是长期免费投入 + 学术界绑定 + 框架默认适配。这不是钱能加速的——它要的是时间和开发者惯性的累积。

lead time：硬件追赶以 2–4 年计（AMD/自研 ASIC 已在做），生态追赶以 5–10 年计且不保证成功。这一维直接判定第 7 维：硬件 fallback 能到 partial，生态 fallback 短期到不了 operational。

### 9. 议价 / 控制机制

- 卡点 type：`information/service`（CUDA 生态锁定 + 设计 know-how）叠加 `capital`（设计研发 + 流片资本）叠加 `permission`（受美国出口管制，因 NVIDIA 是美国公司=直接本土管辖）。注意它**不是** `physical` 单点——这是它和 ac-fab/EUV 的根本区别。
- 卡点 mode：对盟友客户 `open`（排队 + 分配，算力荒时 `expensive/toll`——产能紧张时优先大客户、加价）；对中国 `selective-seizure → near-closure`（高端 H100/H200/B 系禁售，降级版 H20 一度可售后又收紧，见政治传动层）。
- 机制：双重。商业上靠 CUDA 生态锁定 + 产能分配议价（access maker）；政治上靠「NVIDIA 是美国公司」这条**直接管辖链**——美国可以命令 NVIDIA 不得向特定国家/实体出售特定性能以上的芯片，无需任何域外规则。这是整个 ac 栈里政治杠杆最直接、翻转最快的卡点：一纸 BIS 通知，当天生效。

### 10. 历史变迁（卡点怎么移动）

GPU 卡点的移动轨迹是「从图形渲染卡，移动到通用计算，再锁定成 AI 生态护城河」：

- 1999–2006：GPU 是游戏显卡，NVIDIA 与 ATI（后被 AMD 收购）双雄，卡点是图形渲染性能，无地缘意义。
- 2006：NVIDIA 推出 **CUDA**，把 GPU 变成通用并行计算平台。当时不被看好（「显卡公司搞什么编程框架」），但这是后来一切锁定的种子——它开始把开发者绑进自己的软件栈。
- 2012–2017：深度学习起飞（AlexNet 2012 用 GPU 训练），GPU 成为 AI 训练的事实标准，CUDA 十年免费投入开始结算成生态壁垒。卡点从「算力」移动到「算力 + 生态」。
- 2022–2025：大模型爆发，AI 加速器成为最稀缺战略资源。NVIDIA 数据中心营收 FY2025 飙到 $115.2B（+142%，官方财报）。同时美国把 AI 芯片纳入出口管制核心标的——2022.10 起对华限制先进 AI 芯片，2025.4 连降级版 H20 也要许可（直接管辖抓手坐实）。
- 现在的移动方向有两股相反力：一股是 AMD + 自研 ASIC + 去 CUDA 化，试图打破单点（去集中）；另一股是 NVIDIA 用 NVLink/网络/软件继续把「集群级」锁定加深（从单卡锁定升级到机柜/数据中心级锁定，再集中）。下一步看 ROCm/Triton 生态能否真正打开 CUDA 的锁。

### 11. 因果层

主要锚在 **real force**，这是 ac-gpu 区别于 ac-fab/EUV 最关键的一点。

- ac-fab/EUV 的杠杆锚在**物质约束**（不可迁移的产线、十年级工程 know-how、物理单点）——你绕不开它，因为物理上没有第二条路。
- ac-gpu 的硬件段也有物质约束（设计领先 + 上游产能），但这一段相对窄、可追赶（AMD/ASIC 已逼近）。它真正durable 的杠杆是 **CUDA 生态锁定**——这是一种被全行业开发者认可、累积出来的力量：现成的库、调好的算子、几百万人的技能惯性。它能被调用（NVIDIA 靠它定价、靠它锁客户），不随某颗芯片过时而消失。

这条 real force 有个重要边界，决定它会不会贬值：感召力那种锚在「人对人认可」上的 real force，一旦可批量生产就立刻贬值，稀缺是构成要件。但 CUDA 生态锁定不锚在感召力上，锚在**切换成本 + 累积代码资产 + 工具链**上——它更像基础设施型 real force，不吃「批量生产即贬值」这一套。它会被侵蚀，但路径是「另一套生态长到够大、迁移成本降到够低」，是十年级的缓慢过程，不是一夜归零。这就是为什么我判 ac-gpu 的硬件单点比 ac-fab 软（可追赶），但它的生态单点反而更黏。

调用层（个人调用技巧）：暂不适用——这是稳态生态锁定，不是裂缝时刻节点。但要留意一个潜在裂缝：如果某次架构换代（如训练范式变化）让现有 CUDA 算子大面积失效，生态锁定的「累积资产」价值会被重置，那一刻才是真正的干预窗口。

### Q4. 下游依赖度量化

两个方向：

- **本节点对下游的收入敞口**：NVIDIA 数据中心营收高度集中于少数超大规模云 + 大型 AI 实验室——「少数大客户占数据中心营收很大比例」（C2，NVIDIA 10-K 风险章节有客户集中度披露，需逐字核具体比例）。这是双向锁定：客户依赖 NVIDIA 供货，NVIDIA 也依赖少数几家 hyperscaler 的资本开支周期。
- **下游对本节点的产能/生态敞口**：一家做前沿大模型的实验室，训练栈深度绑 CUDA，短期内无法迁移到 AMD/ASIC 而不损失训练进度——切换成本以季度计且有风险。算力供给中断时，在手 + 在途 GPU 库存能撑训练多久取决于各家囤货，但新模型迭代节奏直接被 NVIDIA 分配卡死。
- **缓冲时间**：硬件供给上，下游靠提前下单 + 囤货缓冲（大厂囤货以季度计）；生态依赖上，无缓冲——CUDA 锁定是结构性的，不是库存问题。

【缺口：NVIDIA 10-K 客户集中度具体比例（前 N 大客户占数据中心营收 %）——需 SEC EDGAR 10-K 风险章节逐字核；各 hyperscaler AI capex 中 NVIDIA 采购占比——需各家财报 + 供应链分析】

### Q5. 断供 / 管制经济冲击量级

**场景 A：美国对华 AI 芯片管制（已实际发生，且是 Stack Atlas 里执行最干净的管制案例）**
- 2022.10 起禁高端 AI 芯片（A100/H100）对华；NVIDIA 推降级版 A800/H800 规避，又被堵；再推 H20。
- **2025.4.9：美国要求 H20 对华出口须许可（无限期）**。NVIDIA 随即宣布 **$5.5B charge**（Q1 FY2026，季度截至 2025-04-27），被称为芯片业史上最大单笔减记（C3，公司公告 + 广泛报道）。
- 量级：H20 在 2024 年估计贡献 **$12–15B 营收**（C2–C3，分析机构估）；NVIDIA 称该季度若无管制销售本可多 **$2.5B**；BNP Paribas 估 $5.5B 减记可折算成未来 12 个月约 **$15B 营收冲击**（C3，引用口径）。
- 但 NVIDIA 凭 75% 毛利率 + 数据中心 +142% 的非中需求，一个季度就把这笔减记吸收了——管制打疼了它的中国营收，没动它的命门。打到的反而是**中国 AI 产业**：拿不到最高端算力，被迫退回昇腾 + 受 ac-fab 封锁制约的本土制程上限，集群规模和单卡算力全面受限。

**场景 B：NVIDIA 上游断供（TSMC/HBM/CoWoS 中断）**
若 ac-fab（台海）或 ac-hbm 出现重大中断：NVIDIA 出不了货，全球 AI 算力扩张瞬间停摆，不分敌友。这个场景的冲击量级 = ac-fab 台海情景（Rhodium 2022 估 >$2T 全球受扰，见 ac-fab Q5），因为 AI 加速器是 ac-fab 先进产能最大的下游之一。ac-gpu 在这个场景里是受害者不是卡点持有者。

【缺口：H20 对华营收的官方口径（NVIDIA 未单独披露 H20 营收，$12–15B 为分析机构估）——需 NVIDIA 10-K/10-Q 地区营收 + 管理层讨论；2025.4 H20 许可要求的 BIS 原文/通知——需 BIS 文件，对应 ps-exportctrl】

### Q6. 资本流向与利润归宿

价值链利润高度沉淀在 **NVIDIA（设计 + CUDA 生态定价权）** 这一端——这是 ac 栈「微笑曲线」设计端最厚的利润点：

- NVIDIA 凭 AI GPU 设计 + CUDA 生态拿 **75% 毛利率**（FY2025，C3）——比上游 TSMC 的 54.4%（FY2023 20-F）还高一截。原因：TSMC 卖的是不可替代的制造，但仍是制造（资本密集、有可比对手）；NVIDIA 卖的是不可替代的生态（软件 + 锁定，可批量复制、边际成本极低）。
- 上游 TSMC 拿 54.4% 毛利率（制造端，厚但低于 NVIDIA）；HBM 三寡头拿周期性高毛利（紧缺时厚）；载板/封装环节利润薄。
- 下游 hyperscaler 和 AI 实验室：现阶段是「烧钱买算力」端，利润尚未沉淀（多数 AI 应用未盈利），资本大量流向 NVIDIA 的资产负债表。

政治压力传导路径：美国对华 AI 芯片管制，第一打击的是**中国 AI 产业**（拿不到算力），其次是 NVIDIA 的中国营收（已计入 $5.5B charge）。但因为 NVIDIA 的利润几乎全来自非中市场的旺盛需求 + 75% 毛利的资本纵深，管制打不动它的命门——这和 TSMC 类似（管制能转单/转市场，物理风险才是命门）。NVIDIA 真正的命门不是政治管制，是上游（台海 TSMC + HBM）的物理风险，和下游 AI 资本开支周期一旦逆转的需求风险。

## 卡点分析

- **位置**：AI 算力栈 L1 芯片设计 + L2 软件生态，上承 ac-fab（TSMC）+ ac-hbm + CoWoS + ac-eda + 载板，下接全部 AI 训练/推理 + 全球 AI 应用层。
- **持有者**：NVIDIA（美国）AI 加速器近独占 + CUDA 生态；AMD（美国）partial 第二点；自研 ASIC（美国四家）自用替代；华为昇腾（中国）被上游封锁的本土替代。
- **卡点来源**：网络效应/生态锁定（CUDA，最硬）+ 数据/软件壁垒（开发者技能 + 算子库）+ 技术壁垒（架构 + 互联设计）+ 监管护城河（叠加美国直接本土出口管制）。注意：**不是单点物理**——这是它和 ac-fab/EUV 的根本区别。
- **政治进入后转移**：卡点不转移，反而把美国直接本土管辖坐实——持有者全是美国公司，美国对它的杠杆是全栈最直接、翻转最快的。对华管制把中国推向昇腾本土替代，但本土替代被 ac-fab 封锁卡着上游，短期内是「降级的自给」而非等量替代。
- **干预窗口**：对「打破 NVIDIA 硬件单点」窗口开着但缓慢（AMD/ASIC 在追，2–4 年级）；对「打破 CUDA 生态锁定」窗口更慢（ROCm/Triton 去 CUDA 化，5–10 年级，不保证成功）；真正的突变窗口在「训练范式换代让现有 CUDA 算子资产贬值」那一刻——目前未到。对华管制窗口对美国一侧是「持续开着、可随时收紧」（直接本土管辖）。
- **最硬反例 + 过三关**：反例「AMD MI300 算力已逼近 H100/H200，自研 ASIC（TPU）已能训前沿模型（Gemini），NVIDIA 不是真单点」。
  - 前提成不成立：成立——MI300 纸面算力确实逼近，Google TPU 确实训出了 Gemini。硬件段的单点判断本来就只给到「可追赶」。
  - 可不可比：但「硬件能逼近」不等于「生态能等量替代」。TPU 是 Google 自用 + 自家软件栈，不外卖；MI300 的 ROCm 生态成熟度 + 现有 CUDA 代码迁移成本仍是真实壁垒。在「开放市场上能不能等量替代 NVIDIA 的训练生态」这个问题上不可比——它们是 partial 替代（硬件真，生态不真）。
  - 真发生过：实际发生的是「自研方在自家栈上成功（TPU 训 Gemini）+ 外部市场仍压倒性押 CUDA」。不是「CUDA 锁定被打破」，是「自给方绕过了它、开放市场没绕过」。
  - 结论：反例部分成立但不推翻判断——硬件单点本就判为可追赶（比 ac-fab 软），但 CUDA 生态单点仍未被等量替代（比 ac-fab 的物理单点更黏在软件层）。ac-gpu 是「硬件易、生态难」的双层单点，反例打中了易的那层，没打中难的那层。

## 最近一次被争夺的事件（2026-06-28 回填）

**事件：2023-2024 AMD MI300X vs H100，CUDA 护城河的第一次真实压力测试**

**颗粒度校准**：这场争夺不是在争 GPU 市场整体，而是在争"先进 AI 训练工作负载能不能从 NVIDIA H100 迁移到 AMD MI300X"。节点边界是 CUDA 生态的粘性——硬件性能差距已经缩小，测试的是切换成本是否真的是护城河。

**反应链**：
- 2023 Q3：AMD 发布 MI300X，宣称 HBM 容量和内存带宽上超过 H100（192GB HBM3 vs H100 SXM5 80GB）。这是第一次有竞争芯片在特定规格上超过 NVIDIA 旗舰型号（C3，AMD 产品发布）。
- 2024 Q1：Meta 宣布将 MI300X 用于部分 AI 推理工作负载；Microsoft Azure 和 Oracle Cloud 上线 MI300X 实例（C3，广泛报道）。这是 CUDA 生态的第一次大规模商业渗透实证。
- 2024 全年：NVIDIA 同期发布 H200（更大 HBM3e）和 Blackwell（B100/B200/GB200），持续保持至少 1.5-2× 的有效训练吞吐率领先（C2 估算）；CUDA 库更新和 NVLink 互联优势使单集群扩展性仍明显优于 AMD ROCm + 以太网方案。
- AMD FY2024 数据中心营收：约 $16.6B（C2，行业估算，AMD 未单独披露 GPU 分部）——相比 NVIDIA 数据中心 $115.2B，约 14% 的相对规模，从市场零份额追到了个位数级别。

**被当成舞台的一方**：CUDA 生态是这场争夺的核心战场，AMD ROCm 是挑战方。NVIDIA 没有选择 CUDA 作为竞争工具——CUDA 的护城河是历史积累，不是这场争夺里新建的防御。Meta 和 Microsoft 选择 MI300X 时，不是因为 ROCm 技术上替代了 CUDA，而是因为它们有足够大的内部工程团队能承担部分迁移成本，并专门维护了双后端支持（PyTorch 同时支持 CUDA 和 ROCm）。

**照出的结构**：这场争夺验证了 ac-gpu 节点判断的核心区分——**硬件段可追赶，软件段更难追**。AMD MI300X 在硬件性能上达到可竞争的水平（内存容量甚至领先），但 CUDA 迁移成本使市场份额没有按硬件性能比例翻转。护城河是真实的，但不是无限的：超大规模客户（Meta/Microsoft）因为工程能力足够，可以分摊迁移成本，所以开始渗透；中小型 AI 公司和科研机构仍然完全依赖 CUDA，迁移成本相对更高。争夺照出"CUDA 锁定是规模敏感的"——客户规模越大，绕开的能力越强；客户规模越小，锁定越深。
