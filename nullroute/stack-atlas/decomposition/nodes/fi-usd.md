## 开篇：fi-swift 是地址簿，fi-usd 是金库——断 SWIFT 你失联，断美元清算你的钱真的过不去

fi-swift 那一节钉过一个区分：SWIFT 不结算、不清算、只传"请把 X 从 A 付给 B"的指令，钱另走清算腿。这一节拆的就是那条**清算腿里最硬的一段**：美元怎么真正易手。

把两件事并排放，节点性质立刻分开。断 SWIFT 是把你的银行 null route 掉——你在标准寻址网络上不可达，但钱还在、账户还在，你能退回双边电传慢慢转。断美元清算不一样：你被踢出 SWIFT 之后还能用别的方式喊话，但只要你这笔交易是美元计价的，**这笔美元最终必须穿过一个美国境内的清算点**——CHIPS（The Clearing House 运营的私营净额清算系统，在纽约）、Fedwire（美联储运营的实时全额结算系统，央行货币终局），或者某家在美国持有美元账户的代理行。这一关你绕不过去。被切断美元清算的实体，不是失联，是**这笔美元的价值转移本身被掐死**——付款方按了发送，钱卡在某个美国代理行的合规闸门前，退回。

这就是 fi-usd 和 fi-swift 最关键的结构差异，也是它更硬的原因：**法域抓手反过来了。** SWIFT 是比利时法人，美国动它要借道欧盟立法 + 二级制裁胁迫，扳机需要跨大西洋协调。美元清算不是——CHIPS 在纽约、Fedwire 是美联储的、全球美元代理行的最终一腿落在美国境内的美国银行账户上。**美国对美元清算有直接、单边、本土的法域管辖。** 它不需要请谁配合，OFAC 把一个实体列进 SDN，所有美国人、所有想保住美元清算资格的银行（包括非美银行）就必须冻结、拒付。这正是 Farrell & Newman 2019 框架里那条决定性的边界——"[The United States may be] able to exercise both the panopticon and chokepoint effects—so long as they [hold jurisdiction]"（key-quotes 行 ~180–183）——而对美元清算，美国**确实直接持有**这个 jurisdiction。

第三个要害：二级制裁为什么能管到一家跟美国八杆子打不着的外国银行。因为那家银行只要还想做美元业务，它的美元最终一腿就得过美国代理行。美国不直接命令它，美国说"你继续给被制裁方清美元，你自己的美元代理账户就没了"——CISADA(2010) 起的代理行账户制裁就是这把刀。这是 panopticon + chokepoint 两面里 chokepoint 那一面在货币层的最纯形态：**不没收你的钱，关掉你换钱、转钱、收钱的那扇门。**

## 结构层

### 1. 功能定义

fi-usd 这个功能位置卡的是：**全球美元计价支付的清算与最终结算**——把一条"付 X 美元"的指令变成收款方账上真实多出来的美元余额，并完成参与行之间的轧差与央行货币终局。

它让谁绕不开：任何要做**美元计价**跨境支付的主体。美元是全球主导的储备货币（IMF COFER 已分配储备约 59%，2023–2024，C3）、外汇周转货币（BIS Triennial：约 88% 的外汇交易有一腿是美元，2022，C3）和大宗商品/贸易计价货币（原油、多数大宗商品以美元计价）。只要交易用美元，无论买卖双方在哪国，这笔美元的清算终局都要回到美国主导的清算层——CHIPS（跨行美元大额净额清算）或 Fedwire（美联储 RTGS 终局），或经层层代理行最终落到美国境内的清算腿。

它不卡什么：不卡本币国内支付（各国本地系统自有）、不卡纯非美元的双边交易（人民币对卢布直接清算可绕开美元，前提是双方都愿持对方货币）、不卡"用别的货币重新计价"（这正是去美元化的逻辑——换计价货币就能绕开美元清算，但要付流动性、汇率、对手方意愿的代价）。它精确卡的是**美元这一种货币的清算终局**这一个位置。

绕不开这个属性锚在三层，强度递增：① **网络中心性 / real force**（所有人都用美元定价和结算，所以新进来的人也必须用——单方退出=失去与绝大多数对手方的通用结算媒介）；② **法域**（CHIPS/Fedwire/最终代理行腿在美国境内，美国直接管辖——这是它比 SWIFT 硬的地方）；③ **一个 SWIFT 没有的准物质护城河——没有替代的深度安全资产**：美元的中心性背后是美债市场的深度、流动性和（迄今的）安全性，人民币有资本管制、欧元市场分裂，没有第二个同等深广的安全资产池能接住全球美元流。这条让去美元化只能慢慢走，见因果层。

### 2. 物质形态与可运输性

**比特（清算指令 + 账本记账）+ 制度（美元代理账户资格、央行货币）。** 和 fi-swift 一样没有分子、没有设备、没有能量——它在物质形态光谱上和 SWIFT 同处极端一端：杠杆完全锚在"美元清算资格"这个许可开关上，不靠任何物理搬运。

但和 SWIFT 有一个关键形态差异：SWIFT 传的是"话"（报文），fi-usd 动的是"账"（清算终局）。SWIFT 断连=提高摩擦不归零（你换条线还能喊话）；美元清算断=对**美元计价**的这笔交易接近 on/off（这笔美元过不去就是过不去）。所以同样是纯比特/制度卡点，fi-usd 在"被切断那一刻的杀伤"上比 SWIFT 更接近硬开关——前提限定在"这笔交易仍坚持用美元"。一旦交易方换计价货币（改人民币/卢布/迪拉姆双边），美元清算这一关就被绕开了——这是 fi-usd 的 fallback 全部压在"换货币"上，而不是"换报文网络"上，和 SWIFT 正好错位互补。

理论上另起炉灶的难度：建一套替代清算系统（CIPS 的人民币清算腿、mBridge CBDC 结算）技术上可建、已建——和 SWIFT 一样，护城河不是技术难度。但 fi-usd 的护城河比 SWIFT 多一层：SWIFT 的替代品只要复制"报文标准 + 接入"，fi-usd 的替代品要复制的是"一种被全世界愿意持有和定价的货币 + 一个深广的安全资产市场"——后者不是搭个系统的事，是几十年信用、法治、市场深度的积累。**这是 fi-usd 的 fallback 比 fi-swift 更难搬的根本原因。**

### 3. 供给集中度

**美元清算层：接近单点，且单点的"手"直接在美国。** 分两件常被混的事：

- **清算基础设施（高度集中在美国主导系统）**：跨行美元大额清算约 95% 走 CHIPS（C3 广泛报道，需 The Clearing House 官方核），央行货币终局走 Fedwire（美联储独家）。CHIPS 日均清算量常引约 1.8 万亿美元（C3，需 TCH 官方核），Fedwire 日均更大（万亿级，C3）。
- **货币本身的份额（高但在缓慢下降）**：美元在已分配外汇储备约 59%（IMF COFER 2023–2024，C3，1999 年约 71% → 缓降）；外汇周转约 88% 一腿是美元（BIS Triennial 2022，C3）；贸易计价约一半（C3，区域差异大）。

access maker = **美国财政部 OFAC**（技术清算由 TCH/Fed 执行，但"谁能用、谁被切"的开关在 OFAC 手里）。和 fi-swift 的最大区别：SWIFT 的开关被外部法域（欧盟）征用，SWIFT 自己几乎从不主动断人；美元清算的开关**就是美国自己的本土行政权**，OFAC 单边可按，不需要任何外部立法配合。这是全图金融节点里**法域抓手最直接、最单边**的一个。

证据级：chokepoint/panopticon 框架 + "美元中心性是二级制裁根因" = verified（FN 2019 一手 C4）；美元各项份额 = source-linked（IMF/BIS 口径广泛引用，未取在库原表，C3）；CHIPS/Fedwire 量 = C3。

### 5. 上游依赖（子节点）

fi-usd 这个节点自己绕不开什么？

- **fi-swift（报文层，上游耦合而非下游）**：美元清算要落地，得先有人把"付款指令"传过来——绝大多数仍走 SWIFT 报文。所以 fi-usd 和 fi-swift 是**双向耦合、互为前提**：SWIFT 传话、fi-usd 兑现；断 SWIFT 提高传话摩擦，断美元清算掐死兑现终局。fi-swift 那节已写"杠杆不能脱离 fi-usd 单独评估"，反过来同样成立。组合拳（断报文 + 断清算 + 冻储备）才是完整杀伤——2022 对俄就是这个三件套。
- **美元作为被普遍接受的货币（real force 前提）**：美元清算系统的"权力"有个隐藏前提——全世界愿意持有、定价、收受美元。这个前提不是 fi-usd 自己能造的，它寄生在美元的储备货币地位上。一旦足够多的人改用别的货币计价，美元清算这个闸门管的水就变少（见因果层"slow erosion"）。
- **美债市场深度（准物质护城河）**：美元中心性背后是美债这个全球最深安全资产池。没有它，美元清算的中心性会快得多地流失。这是 fi-usd 区别于 fi-swift 的上游依赖——SWIFT 的网络效应没有这种资产市场背书。
- **运营层（清算系统的 IT/数据中心）**：Fedwire/CHIPS 的技术基础设施，冗余设计，不构成单点。

### 6. 下游依赖方

- **致命依赖：所有做美元计价跨境业务的主体**。被切断美元清算，美元业务能力接近归零——不是涨价，是这扇门关了。依赖强度取决于该主体美元敞口占比。
- **致命依赖：大宗商品 + 能源贸易**。原油、多数大宗商品以美元计价结算——被切美元清算，进出口收付款链断（伊朗石油收入受阻是典型）。这是美元清算传导到实体经济的主路径，也是为什么能源国（俄/伊）有动力推非美元结算。
- **致命依赖：非美银行的美元代理账户**。一家外国银行被列 SDN 或被二级制裁威胁，它的美元代理账户一关，它对所有客户的美元服务能力同时断——这是二级制裁的放大器（一个节点断，全行美元业务停）。
- **高依赖：美元债务方**。全球大量美元计价债务（企业、主权）需要美元清算来还本付息。
- **可缓冲：纯本币国内 + 已建本币双边走廊的交易**。改用人民币/卢布/迪拉姆双边的，不碰美元清算。

买家侧：几乎所有跨境经济主体都是下游，无单一买家集中。**下游对美元清算是"不可替代的结算终局"依赖，不是成本依赖**——和 cm-ree、fi-swift 同型（低成本占比、高卡死性），被切的痛是失去终局兑现，不是费用上升。

### 7. 替代路径 + fallback 等级

**fallback 全压在"换计价货币"上，不在"换清算系统"上——这是 fi-usd 和 fi-swift 的错位。** 分层判：

**整体绕开美元清算（去美元化）：`partial`，且比 fi-swift 整网替代更难搬**
- CIPS 人民币清算腿、双边本币结算、mBridge CBDC、黄金、稳定币（USDT/USDC，但稳定币本身锚美元、反而延伸美元触达，是双刃）都已是真实存在的替代腿。
- 过五问：替代哪一层=美元清算终局 / 多久接上=单条双边走廊立即可用、整体迁移数年到数十年 / 卡在哪=**没有第二个深广安全资产 + 网络效应 + 跨阵营信任 + 人民币资本管制不可自由兑换** / 谁启动=各国央行/财政 + 交易双方 / 现场执行能力=双边走廊有、全球替代远未达。
- 结论：**`partial`。** 比 fi-swift 更难——SWIFT 替代只要复制报文标准，美元替代要复制一种被全世界愿意持有的货币 + 安全资产市场。CIPS 的关键真相和 SWIFT 同构：**CIPS 多数流量仍借 SWIFT 传报文**，且人民币不可自由兑换、有资本管制，承不住全球美元流。

**单点/双边降级（被切方自救）：`operational` 但半空心**
- 被切美元清算的实体可退回：① 改人民币/卢布/迪拉姆/卢比双边本币结算 ② 经未受制裁第三国银行中转 ③ 易货 / 黄金 ④ 稳定币灰色通道。
- 过五问：替代单条美元交易链 / 立即可用 / 卡在对手方持有该货币的意愿 + 汇率与流动性损耗 + 被二级制裁追杀 / 谁启动=被切方自己 / 现场执行能力=有，但摩擦大、汇率吃亏、规模上不去。
- 结论：**真 `operational` 但半空心**——让被切方不至于完全断流（俄 2022 后对华人民币、对印卢比贸易在走），但**无法恢复美元那种全球通用、深流动性、低摩擦的结算**。所以"切美元清算"的实际效果对坚持用美元的交易是接近归零，对愿意换货币的交易是大幅提高摩擦 + 汇率/流动性损耗。

**整体判：`partial`，但单笔杀伤比 fi-swift 硬、整体 fallback 比 fi-swift 难搬。** 瓶颈不在能不能建替代系统，在**有没有一种货币 + 安全资产能接住全球美元流**——目前没有。

### 8. 重建壁垒 + 前置期

- **建替代清算系统（技术）**：壁垒低、月级。CIPS/mBridge 已证。
- **建一种全球愿持的替代储备/结算货币（real force + 准物质）**：壁垒极高、前置期数十年甚至不确定。卡在四处——① 没有第二个美债级别的深广安全资产；② 人民币资本管制、不可自由兑换（中国若放开管制以推国际化，等于放弃资本账户控制——它不愿）；③ 欧元市场分裂、无统一安全资产（无欧盟级共同债）；④ 跨阵营信任 + 网络效应锁定（所有人都用美元定价，所以新人也得用）。
- **绕开单次切断（双边降级）**：壁垒中等、即时可用、规模受限、被二级制裁持续追杀。
- lead time 总判：**技术月级、货币替代数十年级或不确定、单笔绕行即时但不可规模化且吃汇率。** 这一维证实第 7 维：去美元化整体是 `partial`（慢侵蚀，非快替代），单笔双边降级真但半空心。fi-usd 的护城河=货币网络效应 + 无替代安全资产，被侵蚀的方式是"被地缘割裂 + 自我武器化反噬慢慢流失中心性"（FN 2019 结论段 verbatim："the United States may face the slow erosion of its ability to weaponize key economic networks"），不是被某个更好系统快速取代。

### 9. 议价 / 控制机制

- 卡点 type：`permission`（美元清算资格许可）+ `information`（美元清算流的可见性/panopticon）双层。**无 physical**——和所有 cm/re 物理节点根本不同。
- 卡点 mode：**`selective-seizure`**——逐个实体（SDN 指定）、逐国（伊朗、俄罗斯部分行）切断美元清算资格，不是关掉整个美元系统（关整网=自毁货币地位=逼全世界去美元化，美国不会做）。从不 `closed`。但比 SWIFT 的 selective-seizure 更狠的一点：**二级制裁让"逐个切断"的射程覆盖到非美主体**——OFAC 不只能切美国人，还能威胁任何想保住美元代理资格的外国银行，射程是全球的。
- 机制：靠**单边命令（OFAC 指定 + 二级制裁威胁）**，不靠市场议价。美元清算系统不是 price maker（TCH/Fed 是清算公用事业，不收垄断租），它是 **access maker——且这个 maker 角色由美国本土行政权直接行使**，不像 SWIFT 那样被外部法域征用。这是 fi-usd 控制机制的全部要害：**单手、本土、单边、射程全球。**
- panopticon 那一面：美元清算流让美国能看到全球美元资金流动情报（与 SWIFT 的 TFTP 互补）。这一面靠访问不靠切断——切了就看不见，激励上和 chokepoint 冲突，同 SWIFT。
- 关键不对称（与 fi-swift 对照再钉一次）：断 SWIFT 美国要请欧盟立法 + 跨大西洋协调（扳机多方）；切美元清算 OFAC 单边可按（扳机单手）。**这就是为什么美元清算是美国最直接、最常用、最少受盟友掣肘的金融武器**——也是 FN 2019 把 2018 对伊二级制裁的杀伤力直接归因于"U.S. importance to the global financial network"（key-quotes 行 16，p.42）的原因。

### 10. 历史变迁（卡点怎么移动）

- **1944–1971（布雷顿森林 → 尼克松冲击）**：美元经由金汇兑本位成为全球储备货币锚；1971 美元脱钩黄金，转为纯信用储备货币。美元中心性从"挂钩黄金"转为"挂钩美债市场深度 + 网络效应"。
- **1970s–2001**：美元清算作为纯金融公用事业期，CHIPS（1970 建）+ Fedwire 滚雪球，美元成为事实结算标准。几乎不被当政治工具。储备份额高位（2000 前后约 71%）。
- **2001–2010**：**panopticon 面 + chokepoint 面在金融反恐框架下被激活**。911 后《爱国者法》强化美元代理行的 KYC/反洗钱义务；OFAC 制裁机器扩张。2010 CISADA **首次系统化二级制裁**——把"切断美元代理账户"明确为对付与伊朗交易的外国银行的工具。chokepoint 的"射程覆盖非美主体"从此成文。
- **2012–2018（伊朗）**：美元清算切断叠加 SWIFT 断连，对伊石油收入与外汇形成组合杀伤。2018 美国退出 JCPOA 后重启二级制裁，FN 2019 开篇即以此为问题设定——"consequential in large part because of U.S. importance to the global financial network"。**欧盟反应=INSTEX**（试图绕开美元/SWIFT 的对伊结算，实效甚微），但标志盟友开始想收回这条腿。
- **2022（俄罗斯）**：对俄三件套——SWIFT 断连 + 美元清算限制 + **冻结俄央行约 3000 亿美元外汇储备**（C3 需核）。多数事后分析认为冻结储备这一击比 SWIFT 断连更咬人，而冻结之所以可能，根子在这些储备相当部分以美元/美债形式存在于西方可触达的托管里——这是美元中心性的极端展示，也是对全球央行的极端警示（"持美元储备=把储备置于美国法域射程内"）。
- **2010→至今**：去美元化与替代建设期。CIPS（2015）、SPFS、mBridge、双边本币、金砖货币讨论、稳定币。美元储备份额从约 71%(1999) 缓降至约 59%(2023–24, IMF COFER, C3)——**降是真的、但慢，且恰恰被武器化加速**（FN slow-erosion 的实证）。

判下一步：美元清算不会被某个替代品快速取代（没有替代安全资产接得住），会被**地缘割裂 + 每次武器化的反噬慢慢稀释中心性**。冻俄储备这一击尤其给所有非西方央行上了一课，会长期推动储备多元化、黄金回流、本币结算走廊——侵蚀的向量已定，但速度受制于"没有替代深度安全资产"这条物质约束，所以是数十年级的慢漂移，不是断崖。

### 11. 因果层

这个节点是 **real force 为主 + 一条 fi-swift 没有的准物质护城河**：

- **物质约束（弱但非零）**：美元清算系统本身没有物理稀缺（清算 IT 可复制）。但它的中心性**背靠一条准物质约束——美债市场的深度/流动性/安全性，且无替代品**。这不是纯叙事：你要绕开美元，得有地方放钱，而没有第二个同等深广的安全资产池。这条让去美元化只能慢走，是 fi-usd 比 fi-swift 硬的根本。
- **real force（强，核心）**：美元的权力主要锚在"被普遍接受出来的货币网络中心性"上——所有人都用它定价结算，所以所有人必须用。教科书级 real force：客观存在、能被调用、不随某主体退出消失，但构成要件是"被普遍采用"这个集体认可。一旦足够多的人被武器化逼得改用别的货币，这个 real force 就贬值——和我信仰里"锚在人对人认可上的力量，可批量分流时就贬值"同型。fi-swift 的 real force 纯锚在网络共识上、可被技术替代品复制接入；fi-usd 的 real force 因为有美债市场这条准物质护城河垫底，**更黏、更难分流**——这是两个金融 real-force 节点的关键区别。
- **调用技巧（高方差但比 SWIFT 低）**：因为美元清算是美国单边本土管辖，扣扳机不需要协调盟友，调用门槛比"需跨大西洋协调"的 SWIFT 低——OFAC 一纸指定即可。但"用到什么程度"仍是高方差的政治判断：用得越狠（如冻俄储备这种动主权储备的极端动作），越快催生去美元化反噬。这是裂缝时刻一个决策能改写长期结构的位置——冻俄储备可能就是这样一个被后世标记的拐点。
- **不要错算**：① 别把美元清算当物理单点（技术可替代）；② 也别因"储备份额从 71% 降到 59%"就判它在退场（没有替代安全资产，单笔杀伤仍接近 on/off，去美元化是慢漂移不是崩塌）；③ 正解是中间——它是**全图法域抓手最直接、单笔杀伤最硬的 real-force 卡点，但每用一次都在掏空自己赖以存在的普遍性**，且因为有美债护城河垫底，掏空速度比 SWIFT 慢。这是"越用越值钱的物理垄断"和"越用越贬值的网络垄断"之间，偏向后者、但带一条减速的物质尾巴。

## 方向、两条流、最近一次被争夺的事件

### 拒绝方与操作方

**拒绝方**（自上而下切断使用权的一方）：

- **美国财政部/OFAC**：最主要的拒绝方，凭借属地管辖+属人管辖+美元清算的全球渗透能力，通过制裁名单将特定实体排出美元系统。这是政治栈强制层直接打入技术栈的标准动作。
- **美联储（FRBNY）**：联邦储备银行纽约分行是事实上的全球美元大额清算基础设施，持有大量外国央行的美元储备托管资产。冻结操作需要 FRBNY 执行，FRBNY 是这一拒绝权的物理执行端。
- **美国盟友国政府（EU、UK、日本、加拿大等）**：2022 年冻结俄罗斯央行储备时，拒绝权是多边协调后统一执行的，不是美国单边动作——欧央行、英格兰银行同步冻结了在各自辖区托管的俄罗斯储备。这是与 SWIFT（也是多边协调）相同的模式。

**操作方**（自下而上扣住配合的一方）：

- **CHIPS 系统操作员（The Clearing House）**：私有机构，实际运营 CHIPS 系统（美元大额清算最核心的私有管道）。理论上有停止配合的能力，但实践中受美联储监管，从属于政治栈，不构成独立的操作方力量。
- **美联储本身**：在这个节点上，美联储身兼拒绝方（托管冻结）和操作方（系统实际运营）两种角色——这是 fi-usd 与 fi-swift 的结构差异之一：美元清算卡点上的拒绝权和运营权是同一主权单位（美国政府/联储）的延伸，而 SWIFT 的执行需要跨大西洋协调。

**结论**：拒绝权高度集中于美国国家（财政部+联储），商业层面没有独立的操作方力量可以反向施压。这个节点的控制结构比 fi-swift 更单极，但正因如此，每次使用拒绝权的政治摩擦也更小——美国不需要说服欧盟伙伴（2022 年冻俄储备的协调是例外，更多是政治背书，不是技术上的必要条件）。

### 两条流

**物理流（Physical Flow）**：在这个节点里没有传统意义上的"物质流动"，美元清算是纯数字流动。最接近的物理层是 CHIPS 和 Fedwire 的数据中心（美国本土）、与境外美元清算对接的代理行系统，以及 SWIFT 报文网络（传递指令而非清算本身）。**卡点**不在物理层，而在权限层——谁被允许发起清算、谁的指令会被执行。

**价值流（Value Flow）**：全球美元大额清算日均约 1.8–5 万亿美元流经 CHIPS/Fedwire。这个节点上"价值"和"清算指令"是同一回事——清算系统本身就是价值流动的管道，而非分离的价值捕获层。价格（交易成本）极低（接近零），价值捕获发生在基础设施层之上（外汇交易商、投行）。**卡点**在清算权限的授予和吊销，而不是在清算本身的收费。

两条流的中断点高度重叠：切断清算权限，物理流和价值流同时中断。这与氦气（物理和价值卡点分离）完全不同——fi-usd 是最典型的"权限即流动"节点。

### 最近一次被争夺的事件

**探针事件：2022 年 2 月底 G7 冻结俄罗斯央行约 3,000 亿美元储备**

2022 年 2 月 24 日俄罗斯入侵乌克兰，2 月 28 日至 3 月 1 日，美国、欧盟、英国、日本、加拿大、澳大利亚协调宣布冻结俄罗斯央行（CBR）在各辖区托管的外汇储备，规模约 3,000 亿美元（C3；确切数字因部分储备托管于中国等中立国而不确定）。这是 fi-usd 节点有史以来最大规模的主权层拒绝权行使。

**五个读取动作**：

**动作一：校准颗粒度**

这场争夺的节点不是"美元货币"本身，而是一个更具体的东西：**外国央行以为安全存放在西方托管机构里的美元计价储备资产的使用权**。

俄罗斯 CBR 在 2022 年 2 月以前持有约 6,400 亿美元等值外汇储备，其中约 2,800–3,200 亿美元托管在西方辖区（美联储纽约分行、欧央行、英格兰银行等）。冻结的对象是托管权（使用权），不是所有权（储备在法律上仍属于俄罗斯），也不是美元货币系统本身的运行。这个区分在后续法律争议中很关键。

**动作二：跟着反应链走**

谁动了，谁反应了？

- **G7 政府（美/欧/英/日/加/澳）**：协调宣布冻结，时间点是周末（2 月 26–27 日），在亚洲市场周一开市前完成政治协调——防止在消息传出前有人抢先平仓。
- **俄罗斯 CBR（Elvira Nabiullina）**：宣布资本管制，禁止本国居民向境外转移卢布；要求"不友好国家"以卢布支付天然气（这是反向使用俄罗斯自己手里的能源节点杠杆）。事后 Nabiullina 表示"未预料到这一步"（C3；广泛报道，未见原话一手记录）。
- **沙特阿拉伯/UAE**：2022 年 3 月媒体报道两国与中国讨论以人民币结算部分原油交易（C3；《华尔街日报》报道，双方未正式确认）。这是间接信号，说明中东产油国在重新评估美元储备安全性。
- **印度 RBI/中国人民银行**：加快黄金储备收购（C3；各国央行黄金购买量 2022–2023 年显著上升，世界黄金协会数据）。
- **全球非西方央行**：普遍开始评估自己在西方辖区托管资产的比例，部分开始减少在 FRBNY 的托管量（C3；通过美联储托管持有量数据可观察，但因果归因有争议）。
- **IMF**：技术上无法阻止 G7 的单边行动；美国推动暂停俄罗斯在 IMF 的某些权利，但 IMF 维持了对俄罗斯基本成员资格。IMF 的"中立性"在这一过程中被显性挑战——它的框架无法保护成员国储备资产。

**动作三：点名被当成地面的一方**

**IMF 和"国际货币体系"被当成了地面**——冻结行动发生在这个被设计为"中立基础设施"的框架之内，却使用了成员国的单边决定。

被当成地面的中立框架有三层：
1. 《布雷顿森林协定》设立的以美元为中心的国际货币体系（名义中立）
2. IMF 的成员国储备保护机制（理论上不应被用于制裁目的）
3. 美联储 FRBNY 作为托管机构（托管的法律逻辑是"受托人"，不是"制裁执行者"）

这三层框架被同时刺破。关键认识：**冻结行动本身并未违反美国法律**（美国法律赋予 OFAC 这一权力），但它违反了各国央行在使用美元储备时默认信赖的不成文前提——"主权储备资产在和平时期不会被托管方冻结"。这个前提是国际货币体系的一块基石，一旦被打破，就不能假装它还在。

**动作四：把节点放到时间里读**

- 1944 年布雷顿森林：美元和黄金挂钩，确立"美元等于中立储备资产"的前提
- 1971 年尼克松关闭黄金窗口：美元脱金，成为纯信用货币，但储备地位靠网络效应和"没有更好替代品"维持
- 2001–2021 年：OFAC 制裁不断扩大使用范围（伊朗、委内瑞拉、朝鲜、个人和企业），但主权央行储备从未被大规模冻结
- 2022 年 2 月：第一次对一个拥有核武器的大国、一个 G20 成员的央行储备执行冻结——量级和性质都是新的
- 2022 年之后：全球央行黄金储备购买加速（创纪录水平），部分非西方国家开始减少美元储备比例——这些动作证明冻结被全球央行解读为系统性风险信号，而非仅仅针对俄罗斯的例外

**动作五：把说法和数字当成动作**

- **"3,000 亿美元"这个数字**：这个数字本身是一个政治信号，用来强调行动规模（"史上最大规模制裁"的叙事）。但确切数字存在争议——俄罗斯部分储备在中国托管（中国没有参与冻结），另有部分在其他中立国。"约 3,000 亿"是 G7 协调后的公开叙事数字，不是精确审计值（C2）。
- **G7 声明中"史无前例"和"特殊情况"**：这两个措辞是政治防御动作——G7 在宣布时已知道这会损害美元的中立性主张，所以提前标记"这是例外"，以维持"一般情况下不会这么做"的叙事。但这个标记本身就证明他们知道有成本。
- **Nabiullina"未预料到"的说法**：如果俄罗斯 CBR 这个级别的机构没有预判这一风险，全球其他央行的风险计算就更粗糙——这加速了重新评估的速度和规模（不是俄罗斯自己的判断，而是其他央行看到这个说法后的再判断）。
- **卢布要求支付天然气（俄罗斯）**：这是俄罗斯把能源节点作为反杠杆的动作，信号意义大于实质（因为实际结算机制可以在卢布要求下绕行），但它确认了两条栈之间的作用在这次争夺中是双向的。

**五动作总结产生的结构认识**：

这次争夺揭示了 fi-usd 的一个核心结构特征：**美元清算卡点的最终来源是美国对西方金融基础设施的法域控制，而不是美元本身的物质稀缺**。3,000 亿美元的冻结可以在一个周末完成（技术上没有障碍），但它的代价是向全球所有央行发出了一个信号：这套系统的"中立性"是有条件的。这一信号不能被"撤回"——下一次声称储备是安全的，前提已经改变了。

这也是去美元化的真实机制：不是某个"替代品"出现了，而是"持有美元储备的安全假设"被修改了。速度慢，因为没有替代品；但方向被确定了，因为这个前提不能再被假装还在。

## 量化层

### Q1. 市场规模

和 fi-swift 同型的极端背离节点：**清算基础设施是公用事业（不以利润计），但它处理的价值是千万亿（quadrillion）美元/年量级。**

- **承载的清算量**：CHIPS 日均约 1.8 万亿美元（C3，task seed + 广泛报道，需 The Clearing House 官方核）→ 年化约 450 万亿美元（按约 250 个清算日）。Fedwire 日均更大（万亿级，C3）→ 年化接近或超过千万亿美元。两系统合计承载全球美元大额清算的绝大部分。
- **清算系统的"营收"**：CHIPS（The Clearing House，银行所有的公用事业）、Fedwire（美联储）都是成本回收型，不赚垄断租。**和 SWIFT 一样是"机构不赚钱、承载价值天量"的结构。**
- **真正的"市场规模"该怎么算**：fi-usd 的价值不沉淀为清算系统的营收，而沉淀为两样东西——① 美国的**铸币税 + 超额特权**（exorbitant privilege，美国能以更低成本借债、美元资产被全球持有）；② **制裁射程**（能单边切断任何美元用户的地缘权力）。前者有宏观估算（学界对超额特权的量化有争议，量级在美国 GDP 的零点几个百分点/年的融资成本优势，C2 需文献），后者无法用钱衡量。

【缺口：CHIPS/Fedwire 官方清算量——需 The Clearing House、美联储统计；超额特权的量化估算——需学术文献（Gourinchas & Rey 等）。本轮未取。】

### Q2. 集中度量化

- 美元大额清算基础设施：CR1（CHIPS）约 95% 跨行美元大额（C3 需 TCH 核）+ Fedwire 央行终局独家。
- 货币份额：美元 CR1 = 储备约 59%（IMF COFER 2023–24, C3）、外汇周转约 88% 一腿（BIS Triennial 2022, C3）、贸易计价约一半（C3）。第二位（欧元）储备约 20%、人民币约 2–4%（C3）——美元与第二名之间是数量级差距。
- price maker：**不适用**（清算系统是公用事业，不定价收租）。和 SWIFT 同——**集中度极高，但价值不沉淀为利润，沉淀为铸币税 + 地缘控制权。**
- 替代品份额：人民币全球支付约 4%（SWIFT RMB Tracker 转引，C2–C3），且 CIPS 多数流量仍借 SWIFT 传报文、人民币不可自由兑换。

【缺口：IMF COFER、BIS Triennial 原表 + SWIFT RMB Tracker 原始月报——需官方原始数据。本轮口径均为广泛引用，挂 C3。】

### Q3. 关键玩家财务概况

| 主体 | 年营收/规模 | 利润率 | 性质 | 来源 |
|---|---|---|---|---|
| 美联储（Fedwire）| 非营收主体（央行）| — | 央行 | 无（公用事业）|
| The Clearing House（CHIPS）| 成本回收型 | 非盈利目标 | 银行所有公用事业 | 【缺口：需 TCH 披露】|
| JPMorgan / Citi / BoNY Mellon（美元代理行）| 各为千亿美元级总营收，但美元代理清算分部无单列 | 银行整体净利率 | 美国大行 | 【缺口：需各行年报分部】|

资本纵深判断：**和 fi-swift 同——清算系统本身的资本纵深不重要，它不是靠资产负债表扛压力的主体。** 真正的"资本纵深"在三端：① 按按钮的**美国财政部/OFAC**（行政权，不靠钱）；② **被切方**的去美元化缓冲（俄罗斯的能源反筹码 + 事前建的本币走廊 vs 伊朗的薄缓冲）；③ **美债市场的深度**（这是美元中心性真正的"资产负债表"，也是美国必须维护的——若美债失去安全资产地位，整个 fi-usd 杠杆松动）。所以这个节点该问的不是"清算系统赚多少"，是"被切方有多少换货币缓冲"和"美债护城河还稳不稳"。

【缺口：美元代理行业务集中度与营收——需 JPMorgan/Citi/BoNY 年报分部数据。】

### Q4. 下游依赖度量化

- **下游成本敞口（极低）**：用美元清算的费用占交易成本极小。**切美元清算不是成本问题，是 access 问题。**
- **下游产能敞口（高到致命，无库存缓冲）**：和实体节点根本不同——被切美元清算没有"库存能撑几个月"这回事，是**即时断流**（这笔美元当天就过不去）。被切方能撑多久，取决于它**事前**建了多少换货币走廊。俄 2022 前已建 SPFS + 接 CIPS + 有能源反筹码，所以切美元清算后仍能维持对华/对印本币贸易；伊朗缓冲薄，受冲击深。
- **被切方缓冲来自事前准备，不是系统留余地**：和 SWIFT 同——美元清算的切断本身是接近 on/off 的，缓冲全在被切方自己提前建的替代腿。【缺口：伊朗/俄罗斯被切美元清算后贸易结算转移规模与时滞——需 BIS/IMF/IIF/Bruegel 专题分解。】

### Q5. 断供 / 管制经济冲击量级

- **2012/2018 伊朗**：美元清算切断 + SWIFT 断连 + 石油禁运组合，伊朗石油出口与外汇收入受重创——但难单独剥离"美元清算"一项的可归因 GDP 冲击。【缺口：单独美元清算切断对伊 GDP 的可归因冲击——需 IMF/智库分解。】
- **2022 俄罗斯**：三件套里**冻结央行约 3000 亿美元储备**（C3 需核）被广泛评为最咬人的一击，超过 SWIFT 断连本身。俄通过本币走廊把贸易结算迁走，避免了金融瘫痪，但储备冻结是实打实的资产损失。这是"美元中心性=持美元储备即落入美国射程"的最强实证。【缺口：冻俄储备的精确金额与对俄 GDP 冲击分解——需 IIF/Bruegel/IMF。】
- **结构推算（C2）**：美元清算切断的真实冲击量级=**取决于被切方坚持用美元的程度 + 事前换货币缓冲**。对坚持美元、无缓冲的目标（伊朗型）=接近金融窒息；对愿换货币、有反筹码的目标（俄罗斯型）=深度冲击但可缓冲。**必须给的数量级判断：美元清算是金融武器里单笔杀伤最硬的一件（直接本土管辖 + 射程全球 + 无库存缓冲），但其威慑名声同样会反噬——每次极端动用（尤其冻主权储备）都在加速去美元化这个长期成本。** 这是评估时最容易只看短期杀伤、漏算长期中心性流失的地方。

### Q6. 资本流向与利润归宿

价值链上**没有传统利润沉淀**——清算系统是公用事业，不赚垄断租。这个近独占节点的"价值"流到三处：

- **铸币税 + 超额特权**归**美国**：全球持有美元和美债，让美国能以更低成本融资、用本币对外负债。这是 fi-usd 区别于 fi-swift 的地方——SWIFT 的价值纯粹流成地缘控制权，fi-usd 还额外流成美国实打实的**融资成本优势**（量级 C2 需文献）。
- **chokepoint 面的价值**归**OFAC/美国行政权**：单边切断任何美元用户的制裁射程——这是地缘权力，不是钱。
- **panopticon 面的价值**归**能看美元清算流的美国情报机构**：全球美元资金流动情报。
- **被切方付的代价**=换货币的汇率/流动性损耗 + 被迫建替代腿的成本 + 失去美元通用性的机会损失。

first payer：一实体被切美元清算，first payer = **该实体/其美元代理行 → 其客户与进出口企业 → 终端（进口涨价、出口收汇受阻）**。清算系统自己不付代价（中立执行 OFAC 指定）。美国付的是**长期代价**：每武器化一次，美元赖以存在的普遍性被掏一点——但因为有美债护城河垫底，掏空速度比 SWIFT 慢。这是它真正的"资产负债表风险"，计在中心性的慢漂移上，不计在当期。

## 政治传动层

### A. 公开接口

- **美国侧（直接单边接口，核心）**：OFAC SDN 指定（依 IEEPA / 各项行政令）——把实体列入 SDN，所有美国人 + 想保美元代理资格的银行必须冻结/拒付。在库 SDN CSV 19,065 行（`raw/stack-atlas-political-mag-sources/downloads/ofac_sdn.csv`，C3–C4）。
- **二级制裁接口（射程覆盖非美主体）**：CISADA(2010) 代理行账户制裁、各版 NDAA、行政令——威胁外国银行的美元代理资格，迫其合规。这是 fi-usd 把射程从美国人扩到全球的关键法条。【缺口：CISADA/NDAA 二级制裁条款原文——需 U.S. Code 原文，本轮未取。】
- **50% 规则**：被 SDN 实体持股≥50% 的实体自动受同等限制（所有权外延，与 ps-sanctions 共用，已在库 eCFR/FR Entity List 笔记里有同源机制）。
- **清算层接口**：CHIPS/Fedwire 作为美元终局结算的技术执行层——OFAC 指定经清算层和代理行落地为实际拒付。
- **监视接口**：美元清算流 + 代理行 KYC/AML 报告义务（《爱国者法》强化）——panopticon 面的成文通道。

### B. 控制状态流转

针对被指定实体：从 `allow by default`（默认可清算美元）→ **`presumption of denial`（SDN 指定后美国人/美元清算行必须拒付）**。整网对绝大多数主体始终 `allow by default`，只对**被点名实体**翻成拒绝推定。翻转门槛与谁有权翻：**OFAC（美财政部）单边行政权即可指定**，不需要外部立法或盟友配合——这是和 fi-swift（需欧盟理事会一致同意 + 跨大西洋协调）的决定性区别。**fi-usd 的扳机是单手的。** 二级制裁部分给外国银行的是"自我执行的两难"：不是美国直接命令它，是它为保美元资格自己选择合规。

### C. 适用账本

- **许可账（核心）**：state_change_type=selective-seizure / presumption-of-denial（SDN 指定）；effective_date=各次指定生效日；decision_threshold=**OFAC 单边行政指定**（区别于 SWIFT 的欧盟一致同意）；字段=SDN 实体清单、OFAC 一般/特定许可（general/specific license）的豁免范围、50% 规则外延、生效日。
- **信息访问账（panopticon）**：美元清算流 + 代理行报告义务——access_scope、KYC/AML 监督机制、有效期。
- 无建设债账（清算系统非建设型节点）；替代品（CIPS/mBridge）建设另计在各自节点。

### D. first payer

OFAC 指定 → first payer = **被切实体/其美元代理行**（失去美元清算终局）→ 其客户/进出口企业（收付款受阻）→ 终端用户/公民（进口涨价、出口收汇难）。清算系统本身**不是 first payer**（中立执行）。和物理节点不同，这里**金融端先付**（银行/贸易商），再传导实体端——卡的是"结算终局"这条金融线。

### E. 时点

- 1970：CHIPS 上线；Fedwire 长期运行（美联储 RTGS）。
- 2010-07：CISADA 签署，二级制裁/代理行账户制裁系统化。
- 2012 / 2018：对伊朗美元清算切断（叠加 SWIFT、石油禁运）；2018 美退 JCPOA 后重启。
- 2022-02/03 起：对俄美元清算限制 + **冻结俄央行约 3000 亿美元储备**（C3）。
- 【缺口：各次指定的精确生效日、SDN 清单版本、OFAC 许可豁免条款——需 OFAC/Federal Register 原文。】

### F. 叙事合法化

- **美国侧（切断）**："反恐融资 / 防扩散（伊朗核）/ 制裁侵略者（俄罗斯）/ 维护国际规则秩序"——把切美元清算框成执行国际制裁的合法手段。动员：国安共识 + 道义动员（2022 对乌）。
- **美国侧（监视/panopticon）**："反恐 / 反洗钱 / 追踪非法资金"——9·11 后安全叙事合法化对美元清算流的情报访问。
- **被切方/替代品侧**："金融主权 / 去美元化 / 抗金融霸权 / 储备安全"——中（CIPS、人民币国际化）、俄（SPFS、本币结算）、金砖把建替代腿框成抵御美元武器化的主权自卫。这套叙事的真实柴火，正是美国每次极端动用（尤其冻俄主权储备）添的。
- **盟友的尴尬叙事**：2018 对伊后欧盟讲"欧洲战略自主 / 不愿被美国二级制裁绑架"（INSTEX）——武器化反噬连盟友的中心性认同都在侵蚀（FN 2019 结论段 verbatim 警告的正是这个 slow erosion）。

## 卡点分析

- **位置**：fi 栈清算结算层（美元清算终局），不在报文层（那是 fi-swift），不在物理层。真卡点在"美元这一种货币的清算终局 + 代理行美元资格"这一个位置。
- **持有者**：技术执行=The Clearing House(CHIPS)/美联储(Fedwire)/美元代理行巨头；**按钮在 OFAC/美财政部的单边本土行政权手里**。替代据点=CIPS(人民币，部分仍寄生 SWIFT)、双边本币、mBridge、稳定币(双刃)。
- **卡点来源**：网络效应（主）+ 法域护城河（美国直接本土管辖，是 fi-usd 比 fi-swift 硬的来源）+ **无替代安全资产的准物质护城河**（美债深度）。**无单点物理、无技术壁垒**——纯 real-force 卡点，但带一条物质尾巴。
- **政治进入后转移**：卡点正被地缘压力 + 自我武器化反噬**稀释而非转移**——不是从美元转到某个替代货币（没有替代安全资产接得住），而是被割裂成"西方走廊美元 + 对华对俄走廊本币/CIPS"的多货币态。中心性慢漂移流失，但无单一继承者。冻俄储备是加速这一漂移的标志性动作。
- **干预窗口**：对"建技术替代清算系统"=已开（operational，CIPS/mBridge 已建）；对"建替代储备货币"=几乎关闭（无替代安全资产，数十年级/不确定）；对"用美元清算施压"=开且**单手可按**（比 SWIFT 门槛低），但**每用一次窗口自己变窄**（反噬加速去美元化）。最大风险（对武器化方）=极端动用（动主权储备）会长期掏空美元中心性，且因为是单边可按、最常被用，反噬累积比 SWIFT 快。
- **最硬反例 + 过三关**：反例「去美元化在加速，美元储备份额从 71% 降到 59%，金砖在推本币、人民币在升，可见美元清算卡点正在瓦解、是纸老虎」。
  - 前提成不成立：美元储备份额确实从约 71%(1999) 降至约 59%(2023–24, IMF COFER)——前提**部分成立**（降是真的）。
  - 可不可比：但反例把"储备份额缓降"错推成"清算卡点瓦解"。三点不可比——① 储备份额 ≠ 清算射程：美元在外汇周转(88%)、贸易计价、清算终局上的主导没有同比例下降，单笔切断仍接近 on/off；② 替代品接不住：人民币全球支付仅约 4%、不可自由兑换、CIPS 多数仍寄生 SWIFT，没有第二个深广安全资产；③ 时间尺度：59% 的降是二十多年的慢漂移，不是瓦解。拿"长期缓降的储备份额"去证"当下清算卡点失效"，**不可比**。
  - 真发生过：储备多元化、黄金回流、本币走廊建设真发生过；但伊朗/俄罗斯被切美元清算后受深度冲击也真发生过，且至今没有任何主体能完全脱离美元清算。反例只取了对自己有利的趋势线。
  - 结论：反例**部分成立但把"慢侵蚀向量"误读成"当下失效"**——它正确地指出了 FN 2019 警告的 slow erosion 正在发生（这点对，本节点因果层与历史层已纳入），但推不出"卡点当下瓦解"。降级为精确结论：**美元清算是全图金融节点里单笔杀伤最硬、法域抓手最直接（美国单边本土管辖）的卡点；去美元化是真实的长期侵蚀向量，但受制于"无替代深度安全资产"这条物质约束，是数十年级慢漂移，不是当下失效。武器化用得越狠（尤其冻主权储备），侵蚀越快——卡点的现存力量与它的长期自我消耗同时为真。**

## 级联关系

- **上游来自**：① fi-swift 报文层（传话）——双向耦合，互为前提，组合拳（断报文+断清算+冻储备）才完整杀伤；② 美元的储备货币地位（real force 前提）；③ 美债市场深度（准物质护城河）。
- **下游影响**：几乎所有跨境美元计价实体贸易的结算终局——en 能源（原油美元计价）、ag 粮食、大宗商品、跨境美元债务还本付息、贸易融资。一个公用事业级的清算层，向下耦合到全球美元计价实体经济的兑现腿。
- **跨栈耦合**：与 fi-swift 强耦合（报文+清算组合拳）；接政治栈 ps-sanctions（OFAC 指定 + 二级制裁，许可/presumption-of-denial 耦合）；与 fi-cips（人民币替代清算）竞争耦合；与 fi-stablecoin（USDT/USDC 既延伸美元触达又是制裁规避灰色腿，双刃耦合）；与 ps-alliances 耦合（二级制裁需盟友默许但美国可单边，联盟掣肘弱于 SWIFT）。
- **跨域效应**："货币网络中心性作为 real force + 一条无替代安全资产的物质尾巴、且越武器化越加速侵蚀"的因果模型对全图叙事层有方法论示范（对应信仰里"锚在人对人认可上的力量可批量分流时贬值"——fi-usd 是带物质减速器的金融实例，比 fi-swift 黏）；去美元化/储备多元化的份额演化可走 Sigma 量化；制裁有效性的结构条件接 Cassa 技术-制度嵌入 + 已在库的 Hufbauer 制裁成功率口径（约 1/3，对友好国高于对敌对/威权国）。
