## 结构层

### 1. 功能定义

生物制剂（biologics）指用活细胞培养、而非化学合成产出的药：单克隆抗体（monoclonal antibody，一种能精准结合特定靶点的蛋白药，抗癌和自身免疫领域的主力）、重组蛋白（把目标蛋白基因转入宿主细胞让它替人生产，如胰岛素、干扰素）、以及细胞与基因治疗（把改造过的细胞或基因载体本身当药）。本节点说的是这类药的**原液制造能力**（drug substance manufacturing），核心是大规模哺乳动物细胞培养——一罐罐生物反应器里把细胞养到高密度、让它分泌目标蛋白，再纯化出来。

这个节点卡的是**大规模合规生物反应器产能 + 把细胞养稳养好的工艺能力**这一层：谁有足够大的、通过 FDA/EMA 认证的产能，又有把一条产线调到稳定量产的工艺诀窍。它不卡生物药的分子设计（那是研发层，靠专利和 know-how，属另一个功能位置），也不卡化学合成的小分子药（那是 ph-api / ph-generic 那一类）。

**绕不开的属性锚**：对越来越多把制造外包出去的大药企来说，绕不开的是少数几家合同研发生产组织（CDMO，Contract Development and Manufacturing Organization，替药企代工原液和成品的专门厂）手里的**大规模产能 + 工艺经验**。生物反应器可以买、可以建，但把一条产线从工艺开发调到稳定商业量产、通过监管现场检查，需要多年积累的工艺知识、工程团队和监管履历——这才是短期造不出替代品的地方。逻辑和半导体「设备可买、工艺不可转」同构：卡点不在硬件本身，在硬件之上那层不可转移的运营能力。

### 2. 物质形态与可运输性

生物药原液是蛋白分子的水溶液，几乎全部需要**冷链**（2–8℃ 冷藏，部分需 −20℃ 甚至 −70℃ 冷冻，如 mRNA 类和某些细胞治疗产品）。这和化学 API 的固态粉末不同——化学 API 常温装箱空运即可，生物药原液和成品对温度、震动、时效敏感，运输链本身更脆、更贵。

但真正的障碍和 ph-api 一样，不是物理运输，而是**监管许可路径的长度**。生物药的生产工艺被固定写入监管申报文件（美国的 BLA，Biologics License Application）——换一家工厂、换一条产线生产同一个抗体，属于「生产场地变更」，要重新做工艺转移、可比性研究（证明新产线产出的药和原来的药生物学等效）、稳定性数据、监管现场检查再批准。这个过程通常 18 个月到 3 年以上。所以生物药的产能不是可以随时调度的通用产能，而是**和特定产品、特定产线绑定的合规产能**。

一层比 ph-api 更硬的东西：生物药的「工艺即产品」（the process is the product）。同一段基因、同样的细胞株，放在不同反应器、不同培养条件下，产出蛋白的糖基化修饰等微观特征会变，可能影响药效和安全性。这使得生物药的产线迁移比化学 API 难得多，也是生物类似药（biosimilar，生物药的「仿制」版）比化学仿制药门槛高得多的根本原因。

### 3. 供给集中度

按 CDMO 代工产能看，**高度集中在少数几家**，但不是 EUV 那种单点独占，而是寡头。

**全球生物药 CDMO 市场（2024 年约 246 亿美元，C2，SkyQuest 转引，属市场研究口径，需一手降级复核）：**

按产能计的头部代工厂（C2，FiercePharma / KED 2024–25 转引）：
- **三星生物（Samsung Biologics，韩国）**：据报道为全球按产能计最大的生物药代工厂。韩国松岛（Songdo）单一园区总生物反应器容量据报道超过 60 万升，第五工厂投产后达约 78.4 万升（C2，同上口径，需年报核实）。
- **龙沙（Lonza，瑞士）**：位列第二梯队，2024 年以约 12 亿美元收购基因泰克（Genentech）在美国加州 Vacaville 的工厂，被视为西方产能扩张与竞争加剧的信号（C2，FiercePharma 转引）。
- **勃林格殷格翰（Boehringer Ingelheim，德国）**：第三大代工（C2，行业分析转引，具体产能待研究）。

除代工厂外，还有一批**原研药企的自有大规模产能**（in-house capacity），它们不对外代工或只部分开放：罗氏/基因泰克（Roche/Genentech，瑞士/美国）、安进（Amgen，美国）、艾伯维（AbbVie，美国）等抗体药巨头都有自建的大规模产线。所以「全球大规模生物反应器产能」这个总量，一部分在专业代工厂手里，一部分锁在原研药企内部。

**中国代工产能**：药明生物（WuXi Biologics，港股 2269.HK）是中国生物药代工主力，靠成本 + 速度 + 一体化服务（从细胞株构建到商业化生产的端到端 CRDMO 模式）拿到大量西方药企订单，是 BIOSECURE Act 的直接针对对象（详见「最近一次被争夺的事件」）。药明生物具体产能与全球份额【缺口：需要 WuXi Biologics FY2023/FY2024 年报】。

**谁是 access maker**：没有单一 access maker。急需大规模抗体原液产能时，三星生物、龙沙、勃林格殷格翰三家 + 原研药企的富余产能，构成实际可选集；药明生物此前是重要的低成本选项，正被政策从美国市场挤出。产能紧张周期里（据报道 2021–2022 年部分产能满负荷），谁排得上产能本身就是筹码。

**法域结构关键点**：
- 头部合规产能集中在**美国盟友法域**（韩国、瑞士、德国、日本）+ 美国本土。这和 ph-api「中国近独占大宗抗生素」的格局相反——生物制剂这一层，中国是**追赶者**（药明系靠成本切入），西方 + 韩日是**在位者**。这个方向差异是本节点区别于 ph-api 的核心，也是 BIOSECURE Act 能成立的结构前提：美国要切断的是一个还没坐稳、可被替代的中国供应方，而不是像稀土那样切断一个自己离不开的来源。
- 三星生物虽在韩国，但其客户高度绑定美欧药企，且韩国是美国盟友，政治上不构成对美依赖风险。
- 药明生物是港股上市的中国企业，受中国法域管辖，正是美国立法要排除的对象。

### 5. 上游依赖（子节点）

生物制剂制造自己绕不开三块上游，且这三块的集中度可能比代工产能本身更硬——**卡点可能在更上游的设备耗材层，而不在代工产能层**。这是本节点最需要在后续拆解中单列子节点的地方。

- **生物反应器与一次性耗材（单点风险高）**：现代生物药生产大量用一次性生物反应器（single-use bioreactor，用一次性塑料袋替代不锈钢罐，省清洗验证、换产快），上游被少数几家主导——**赛多利斯（Sartorius，德国）、思拓凡（Cytiva，原 GE Healthcare 生命科学部，现属丹纳赫 Danaher）、赛默飞（Thermo Fisher，美国）**。一次性袋、连接件、传感器等耗材供应在 2021–2022 年疫情期间出现过严重紧缺和长交期。这层的集中度【缺口：需 Sartorius / Danaher 年报分部数据 + 行业份额报告】。
- **层析介质 / 纯化耗材（单点风险高）**：抗体纯化高度依赖蛋白 A 层析介质（Protein A resin，一种能特异性抓住抗体的填料），全球供应集中在 Cytiva、Thermo Fisher、Tosoh（日本东曹）、Merck KGaA（德国默克）等少数几家。蛋白 A 介质是抗体下游纯化几乎绕不开的一环，价格昂贵、认证壁垒高，是比代工产能更靠上游、更隐蔽的潜在卡点【缺口：需层析介质市场份额报告】。
- **细胞培养基（moderate）**：大规模细胞培养需要成分确定的无血清培养基（chemically defined media），主要供应商 Thermo Fisher（Gibco 品牌）、Merck KGaA、Cytiva 等。集中度存在但比蛋白 A 介质稍分散。
- **细胞株与工艺 know-how（不可转移的软依赖）**：生产用的工程细胞株（多为 CHO，中国仓鼠卵巢细胞）和配套的高产、稳定表达工艺，是各代工厂/药企多年积累的核心资产，构成第 1 维说的「绕不开的属性锚」。这不是可买的物料，是绑在人和履历上的能力。

**小结**：生物制剂的真实卡点很可能不是「代工产能」，而是「上游设备耗材」——Sartorius / Cytiva(Danaher) / Thermo Fisher 三家主导一次性反应器、层析介质、培养基这几条耗材线，是比代工厂更上游、更集中的一层。买中国代工绕不过西方耗材，正如买中国 API 绕不过中国前体。这一层强烈建议在正式拆解中单列节点（暂名 ph-bioprocess-consumables）。

### 6. 下游依赖方

- **外包制造的大药企（依赖度高，可缓冲）**：越来越多药企把新分子的原液制造外包给 CDMO，尤其中小型 biotech 公司没有自建产能、100% 依赖代工。对单个产品而言，一旦选定代工厂并完成监管申报，短期换厂极难（见第 2 维），依赖强度高；但对整个行业而言，代工厂有多家，属可缓冲。
- **抗体药 / 自免疫药 / 抗癌药的全球患者（终端刚需）**：生物制剂里很多是救命药或长期用药（如肿瘤免疫治疗、类风湿关节炎生物制剂），断供直接影响临床，但因产品-产线绑定，断供是「单个产品供应中断」而非「整个市场断供」，冲击方式和 API 的大宗断供不同。
- **美国联邦采购体系 / VA / Medicare（BIOSECURE 的抓手）**：BIOSECURE Act 的机制不是禁止进口，而是**禁止联邦资金采购**用了「受关注生物技术公司」设备或服务的药品/服务。这让依赖联邦合同的药企必须在「用药明系代工」和「拿联邦订单」之间二选一——下游的政治敞口集中在这里。

**断供缓冲**：生物药供应链通常持有数月的原液或成品库存，产品-产线绑定使得「切换」而非「断供」是主要风险模式，政治响应有时间窗（BIOSECURE 的过渡安排本身就给了多年 grandfather 期，见政治传动层 E）。

### 7. 替代路径 + fallback 等级

替代要分层看：

**针对「某一家代工厂出问题」（含药明系被政策排除）：**
- 抗体成品原液：可尝试转到另一家合规代工厂（三星、龙沙、勃林格、富士等），但大规模合规产能本就阶段性紧张，且转产要重做工艺转移 + 可比性研究 + 监管审批，接得上但**慢（18 个月–3 年）、贵**。fallback 等级：`partial`（非抗生素式全断，是可迁移但高成本的迁移）。
- 现场执行能力常被高估：同一个抗体在不同产线上要重新验证，「搬机器」解决不了「工艺即产品」的可比性问题。

**针对「西方要在短期内建等量新产能替代中国代工」：**
- 建一座大规模合规生物药厂要约 3–5 年、几十亿美元投入，还要配齐工艺团队和监管履历，属**树状依赖**（大规模合规产能是主通道，短期没有等量旁路）。fallback 等级：`planned`（三星扩建、龙沙收购 Vacaville、富士扩产、Catalent 被 Novo 收购整合——西方产能正在扩，但形成等量替代需数年）。

**针对「上游耗材（蛋白 A 介质、一次性反应器）断供」：**
- 这一层若断，比代工产能断更难绕——供应商更少、认证绑定更严、更难替换。fallback 等级：`possible reroute`（待第 5 维单列节点后再评估，当前不足以判为真 fallback）。

**五问答法（以「药明系被 BIOSECURE 排除后，某美国药企的抗体产品转产」为例）：**
- 替代哪一层：合规原液制造产能（从药明系转到西方/韩日代工厂或自建）。
- 多久接上：工艺转移 + 可比性研究 + 监管场地变更批准，约 18 个月–3 年；2024 众院版曾设既有合同 grandfather 至约 2032（C2，成法版逐字过渡条款待 NDAA 851 条核），加上成法后 OMB 出 BCC 清单（1 年）+ FAR 修订（再 1 年）的行政落地期，合起来给了数年缓冲，正是承认这个迁移周期长。
- 卡在哪个环节：可比性研究（证明新产线产出等效）+ 监管现场检查 + 上游耗材（蛋白 A 介质、一次性反应器）供应本身也要排产。
- 谁有权限启动：药企自己（商业决定）+ 需要新代工厂有富余合规产能接单。
- 现场有没有执行能力：三星、龙沙等在扩产，但能否在过渡期内吸收全部从药明系转出的订单量，取决于扩产进度，`planned` 而非 `operational`。

真实 fallback 综合等级：`partial`（单厂/单产品可迁移但慢贵）到 `planned`（等量替代中国代工的西方新产能在建但未成）；上游耗材层 `possible reroute`。**总判：成本大幅增加、周期以年计，但不是不可替代——这是本节点和「blocked」型卡点的关键区别。**

### 8. 重建壁垒 + 前置期

生物制剂制造的壁垒**高于化学 API，但类型不同**：不是 EUV 那种物理极限，而是「工艺即产品」的不可转移性 + 监管认证长周期 + 资本密集 + 上游耗材依赖。

- **资本 + 周期**：一座大规模（数万升级）合规生物药原液厂，资本支出约 10 亿美元级、建设到投产约 3–5 年，通过监管认证再加时间【缺口：需具体项目资本支出，如三星第五工厂、龙沙 Vacaville 的公开投资额】。
- **工艺 know-how**：把细胞株、培养、纯化调到稳定高产是多年积累，工程和监管人才是硬约束。中国药明系正是靠积累了这套能力 + 成本速度，才在十几年里从追赶者变成头部选项。
- **监管履历**：新厂要建立通过 FDA/EMA 反复检查的合规记录，履历本身是壁垒，不能靠钱一次买断。
- **上游耗材同步**：即使建了产能，蛋白 A 介质、一次性反应器等耗材来源没解决，仍卡在更上游（见第 5 维）。

时间估算：西方要形成足以替代中国代工的本土/盟友产能，从政策/投资驱动到落地，量级为 3–7 年，且高度依赖上游耗材扩产同步。

### 9. 议价 / 控制机制

谁能拒绝谁、凭什么：
- **代工巨头**凭对**大规模合规产能的所有权**议价——产能紧张时排产权本身是筹码。卡点类型：capital（资本壁垒）+ service（监管合规与工艺服务依赖）。
- **原研药企**凭对**分子专利和工艺**的所有权，决定把订单给谁。
- **上游耗材商（Sartorius/Cytiva/Thermo）**凭对**关键耗材（蛋白 A 介质、一次性反应器）的所有权**，握有更靠上游的拒绝权——这是本节点最可能被低估的一层。卡点类型：capital + physical（耗材供应）。
- **国家（美国）**凭**主权/立法**把某国代工产能排除出本国供应链——这是 BIOSECURE Act 的核心：不针对单笔交易，而是**改写整个联邦采购市场的默认条件**（把用了「受关注公司」服务的药品从联邦可采购集合里划出去），属于领域核说的「为整个市场改写默认条件」那种准监管力量，控制力高出「拒绝单笔订单」一个层级。卡点类型：permission（立法许可）。

**卡点 mode（当前）**：整体 `open`（正常供给）。BIOSECURE 已成法（2025-12-18），对中国代工在美国联邦市场这条特定通道，法律框架已把 mode 设为 `selective`（定向排除被认定为 BCC 的中国供应方，保留其他所有来源）——但**尚未正式指向具体企业**：药明系截至 2026-07 未被正式列为 BCC，OMB 的 BCC 清单和 FAR 落地还在 1–2 年的行政程序里。也就是说这个卡点现在的状态是：法律已经成文，但尚未正式适用于药明系。这是**定向切断**，和 tc-mobile-chip 的定向切断同型，也和 ph-api「隐性成本主导、无显性管制」形成对照。

**方向对照（三个节点放一起看）：**
- **ph-api**：中国靠成本竞争**被动积累**主导地位，美国**无显性工具**、靠 BARDA/PLI 慢慢再岸化——中国是在位者，美国在追。
- **ph-biotech**：中国靠成本速度**追赶切入**，美国用**立法定向切断**（BIOSECURE）反向把中国挤出——西方是在位者，中国在追，美国主动用法律封住追赶者。
- **tc-mobile-chip**：美国用出口管制**定向切断**中国获取先进芯片——同为定向切断，但方向是切断对手的「获取」，BIOSECURE 是切断对手的「供给进入」。

同一件事（技术依赖变政治杠杆），在三个节点里方向、工具、在位/追赶关系各不相同，正是 Stack Atlas 要照出的结构差异。

### 10. 历史变迁（卡点怎么移动）

- **1980s–2000s**：生物药诞生于美欧（基因泰克、安进等），原液制造能力集中在原研药企自建产线，几乎全在美欧内部。
- **2000s–2010s**：CDMO 代工模式兴起，龙沙、勃林格等专业代工厂承接外包；生物药市场高速增长，产能需求外溢。
- **2011 年前后–2020s**：三星生物成立（2011）并靠韩国资本和快速扩产成为全球最大代工厂；药明生物（2017 港股上市）靠中国成本 + 一体化 CRDMO 模式承接大量西方早期研发和商业化订单，中国从无到有切入这一层。
- **2020–2022**：疫情推高生物药和疫苗产能需求，代工产能阶段性满负荷，上游一次性耗材紧缺暴露（Sartorius/Cytiva 交期拉长）。
- **2024–2026（现阶段）**：美国 BIOSECURE Act 立法动议直接针对药明系，试图把中国代工从美国联邦采购市场排除；同期西方产能整合扩张（龙沙收购 Vacaville、Novo Holdings 收购 Catalent、富士扩产）。卡点从「纯市场竞争」叠加上「主权定向排除」这一层。

卡点移动的方向：从**原研自有 → 专业代工寡头（含中国追赶者切入）→ 主权开始用立法重新划定「谁的产能能进哪个市场」**。下一步走向取决于 BIOSECURE 是否成法、西方扩产能否吸收转出订单。

### 11. 因果层

- **物质约束（中高）**：不是资源稀缺，而是「工艺即产品」+ 大规模合规产能 + 上游关键耗材（蛋白 A 介质、一次性反应器）的物理集中。比化学 API 硬（API 化学本身谁都能合成，靠规模经济；生物药工艺不可转移是更硬的物质约束），但比 EUV 软（EUV 物理上无第二家，生物药合规产能有多家）。
- **Real force（中）**：头部代工厂和原研药企的主导锚在**工艺积累 + 监管履历 + 资本纵深**，比 API 的「成本护城河」更黏（工艺不可转移），但仍可被资本和时间追上——药明系十几年从零切入就是证据。这不是稀土 know-how 或 CUDA 生态那种近乎不可复制的黏性。
- **个人/调用层（低–中）**：市场由分散的企业组成，无单一决策人。但**主权调用层在上升**——BIOSECURE Act 是国家意志直接介入、用立法定向排除一个供应方，这一层的能动性已在这个节点上被激活（与 ph-api「至今无正式武器化」不同：ph-biotech 的政治工具已经成法，2025-12-18）。成法后调用层还多出一处新的作用点：OMB/DoD 的清单认定权——立法把「切谁」的裁量从国会推给了行政清单，这本身是调用层能动性的一次转移。

### Q1. 市场规模

- **生物药整体市场**：庞大且快速增长，多份市场研究给出 2020s 中期约 4000 亿美元+ 的量级，并预测长期（2030s）向万亿美元级增长（长期预测可信度低，仅作数量级参考）【缺口：需 EvaluatePharma / IQVIA 生物药市场报告一手数字确认 4000 亿量级与年份】。

- 数量级确认：生物药终端市场 4000 亿美元级，其中外包给 CDMO 制造的部分约 200 多亿美元级，代工渗透率在上升。

### Q2. 集中度量化

- **CR3（三星+龙沙+勃林格代工产能份额）**：【缺口：需三家年报产能 + 行业总产能统计，才能算真实 CR3】。三星生物据报道已与全球前 20 大药企中的 17 家合作代工抗体药（C2，KED 转引），显示头部代工客户覆盖极广。
- **上游耗材集中度**（可能是更硬的卡点）：一次性反应器 / 蛋白 A 介质由 Sartorius、Cytiva(Danaher)、Thermo Fisher、Merck KGaA、Tosoh 等少数几家主导，CR 值【缺口：需耗材市场份额报告】。

### Q4. 下游依赖度量化

- **中小 biotech 对代工的依赖**：无自建产能的中小药企 100% 依赖 CDMO；大药企部分外包。整体外包渗透率【缺口：需行业外包率报告】。
- **药企对药明系的敞口**：部分美国药企的在研/在售产品用药明生物代工，BIOSECURE 一旦生效，这些产品面临「换厂或失去联邦市场」——具体有多少美国药企、多少在研管线依赖药明系【缺口：需 BIO 行业协会调查 / 药明生物客户结构披露】。据报道美国生物技术创新组织（BIO）曾就 BIOSECURE 对会员影响做过成员调查，显示相当比例会员与药明系有业务往来（C3，2026-07-08 交叉核对）。
- **断供/切换库存缓冲**：生物药供应链通常持有数月成品库存，产品-产线绑定使主要风险是「多年迁移周期」而非「即时断供」。

### Q5. 断供 / 管制的经济冲击量级

- **BIOSECURE 型定向排除的冲击**：主要不是「药品短缺」（因有西方替代产能），而是**供应链重组成本 + 迁移周期损失 + 药明系营收损失**。冲击量级【缺口：需券商/行业分析对 BIOSECURE 经济影响的测算报告】。
- **药明系市场反应（可作冲击的即时代理指标）**：据报道 2024 年 BIOSECURE 立法推进期间，药明生物、药明康德（WuXi AppTec）港股/A 股股价多次大幅下挫（单日跌幅曾达约 20% 级别）（C3，2026-07-08 交叉核对）【缺口：需 HKEX/交易所行情数据核实具体跌幅与日期】——股价是市场对「中国代工在美市场前景」的定价，是本事件冲击最直接的可量化代理。
- **上游耗材断供的冲击**：若上游耗材（蛋白 A 介质等）出问题，冲击面比代工产能更大，因为它跨所有代工厂【缺口：需专项分析】。

### Q6. 资本流向与利润归宿

生物制剂价值链的利润分布和 ph-api **相反**：
- **利润明显向供给侧和上游耗材侧沉淀**：上游耗材商（Sartorius、Cytiva/Danaher、Thermo）毛利率高、议价强；代工厂利润率也远好于大宗化学 API 厂；终端生物药本身单价极高（抗癌抗体药可达每疗程数万美元）。
- 这意味着：政治压力打到「中国代工（药明系）」这个供给方时，**打的是一个有利润、有资本纵深、有游说和诉讼能力的对象**——不像 ph-api 打中国 API 厂那样「打了也没多少利润可失」。所以 BIOSECURE 遇到的阻力更大（客户药企、药明系、部分行业组织都有动机反对），独立成法一度受阻（2024 单飞未成），最终靠附挂 FY2026 NDAA 才在 2025-12-18 成法——阻力真实存在，体现为「独立走不通、搭便车才过」，且成法后把「切谁」延后到行政清单，也是给继续游说留了缓冲。
- 同时，因为利润在供给侧，美国切断中国供给方（而非切断一个自己依赖的来源）在「成本-收益」上对美国相对划算：美国不失去关键供给（有西方替代），中国失去的是一块有利润的出口业务——这和 ph-api「切断中国 API 会伤到自己」正好相反，是 BIOSECURE 比 API 管制更容易被美国推动的结构原因。

## 政治传动层

### A. 公开接口

- **美国**：**BIOSECURE Act**（2025-12-18 成法，为 FY26 NDAA 第 851 条；前身 H.R.8333 / S.3558）——通过限制**联邦资金采购**用了「受关注生物技术公司（BCC）」设备/服务的实体，把中国代工从联邦相关市场排除。**成法版本不再直接点名企业**（2024 众院版曾点名 BGI/MGI/Complete Genomics/药明康德/药明生物），改为通过 DoD 1260H「中国军工企业」清单 + OMB 清单机制认定 BCC；药明系截至 2026-07 未被列入，药明康德据报道被提议列入下一次 1260H 更新（C3，2026-07-08 EC/律所简报交叉核对）【缺口：需 FY26 NDAA 第 851 条逐字全文 + 1260H 现行清单核实】。此外 BARDA 等联邦资金也是拉动本土生物制造产能的工具。
- **中国**：无针对生物代工出口的正式管制；药明系是市场化企业，中国的接口更多在「反制美国立法」的外交/舆论层面。
- **欧盟**：Critical Medicines Act 等供应链安全倡议涉及生物药，但未见针对中国代工的定向排除立法【缺口：需欧盟文件核实是否覆盖生物制剂】。

### B. 控制状态流转

- **当前状态**：`allow by default`（中国代工正常进入美国及全球市场）。
- **BIOSECURE 已成法（2025-12-18）**：对「联邦资金相关采购」这条特定通道，法律已把状态设为「用了 BCC 服务的实体推定不可获联邦合同/资助」，但保留过渡期和非联邦市场。**注意两点**：①这不是全面禁令，是针对联邦采购通道的定向翻转；②法律成立 ≠ 对具体企业立即生效——BCC 认定要等 OMB 清单（1 年内）+ FAR 修订（再 1 年），且成法版本靠 1260H/OMB 清单而非直接点名，所以「翻转门槛」从 2024 年的「国会立法」变成了现在的「进入 1260H/OMB 清单」这道行政认定门。
- **翻转路径**：2024-09-09 众议院 306-81 通过 H.R.8333 → 未搭上 FY2025 NDAA、当年未成法 → 2025-10 参议院把修订版并入 FY2026 NDAA → 2025-12-18 签署生效（第 851 条）。立法门槛终究是靠搭 NDAA 这趟「必过法案」的便车才跨过的——这本身印证了独立成法门槛高、进程慢的判断，但结论要更正为「最终靠附挂 NDAA 成法」，不是「未成法」。

### C. 适用账本

- **许可账**：BIOSECURE 成法后，「用了受关注公司服务」会成为联邦采购资格的否决字段——是一种资格准入账。
- **建设债账**：BARDA / 联邦对本土生物制造产能的资助合同。
- 当前主要是建设债账在动（扶持本土/盟友产能），许可账尚在立法中未激活。

### D. First payer

BIOSECURE 成法后代价传导顺序：
1. **药明生物 / 药明康德**（立刻：失去美国联邦相关市场，股价与营收承压，客户流失）。
2. **依赖药明系代工的美国药企**（中期：被迫在过渡期内完成工艺转移，承担迁移成本和周期风险，尤其中小 biotech）。
3. **西方/韩日代工厂（受益方而非付费方）**：三星、龙沙、富士等接收转出订单，是这条链上的净受益者。
4. **终端患者**（间接、有限：因有替代产能，主要风险是个别产品迁移期的供应波动，而非普遍短缺）。

与 ph-api 的对照：ph-api 断供的 first payer 是印度药厂→全球患者（因中国是不可替代来源）；ph-biotech 的 first payer 是中国供给方自己（因中国是可被替代的追赶者）。**谁先付代价，取决于谁不可替代——这是本节点和 API 最本质的结构差异。**

### E. 时点

- **BIOSECURE 成法时点：2025-12-18**（FY26 NDAA 第 851 条签署生效）。但对具体企业的生效时点后置：OMB 有 1 年发布 BCC 清单 → 180 天出实施指南 → FAR 委员会 1 年改采购条例；真正落到药明系头上的时点取决于它何时进 1260H/OMB 清单（截至 2026-07 未进）。
- 立法关键时点：2024-09-09 众议院 306-81 通过 H.R.8333 → 未搭上 FY2025 NDAA、当年未成法 → 2025-10 参议院并入 FY2026 NDAA → 2025-12-18 签署成法【缺口：需 FY26 NDAA 第 851 条 + OMB/1260H 清单原文核实】。
- 过渡安排：法案据报道设有多年 grandfather 期（有报道称到 2032 年左右），承认生物药迁移周期长（C3，2026-07-08 交叉核对）【缺口：需法案文本核实过渡期条款】。

### F. 叙事合法化

- **美国叙事**：「国家安全 + 生物数据主权」——把中国代工/基因公司接触美国患者基因数据、以及供应链依赖中国，框为国安和数据安全问题（动员力强，比 ph-api 的「公共卫生供应链安全」叙事更硬，因为挂靠了国安和数据主权，能调动国防和情报政治支持）。这解释了为什么 BIOSECURE 比 API 再岸化立法推进更有力——叙事挂靠国安，动员力更强。
- **中国/药明系叙事**：「无证据的政治打压」「破坏全球医药合作」「损害美国患者用药可及性和创新」——试图把行业客户和患者利益动员为反对力量。
- 与 ph-api 的对照：ph-api 的再岸化叙事是「公共卫生」，缺国防支持、动员弱；ph-biotech 的 BIOSECURE 叙事是「国安 + 数据主权」，动员强——这个叙事强度差异，是两个医药节点政治推进速度不同的直接原因。

## 卡点分析

**位置**：ph-biotech 节点，L1 生产基础设施层（生物药原液制造 + 上游关键耗材）
**持有者**：头部代工寡头（三星生物/龙沙/勃林格，法域在美国盟友）+ 原研药企自有产能 + 上游耗材寡头（Sartorius/Cytiva/Thermo）；中国药明系为被政策针对的追赶者
**卡点来源**：技术壁垒（工艺即产品、不可转移）+ 规模经济（大规模合规产能资本密集）+ 监管护城河（认证长周期、场地变更难）+ 上游耗材单点（蛋白 A 介质等）

**这个节点区别于 ph-api 的核心特征**：
- ph-api 是「中国被动积累主导 + 美国无工具、慢慢再岸化」；ph-biotech 是「西方/韩日在位 + 中国追赶切入 + 美国用立法定向切断追赶者」。**在位/追赶关系相反，政治工具相反（一个没工具，一个已成法 2025-12-18），叙事强度相反（公共卫生 vs 国安数据主权），利润归宿相反（供给方利润最薄 vs 供给方利润最厚），first payer 相反（依赖方付 vs 被切断的中国自己付）。**
- 正因为中国在这一层是可替代的追赶者、且供给方有利润，美国切断的「成本-收益」比切断 API 更划算，BIOSECURE 才成为「最清晰的定向切断」事件。

**政治进入后转移**：正在进行——BIOSECURE 已成法（2025-12-18）+ 西方产能整合扩张（龙沙收 Vacaville、Novo 收 Catalent、富士/三星扩产）双管齐下，把订单和产能从中国代工向盟友转移。进展现在受 BCC 清单认定进度（OMB/1260H）和扩产周期约束，数年尺度。
**干预窗口**：开且在关闭中。对中国药明系，窗口在关闭（法律已成 + 药明康德被提议列入下次 1260H + 客户提前分散供应链）；对西方，扩产窗口在打开。上游耗材层的干预窗口研究不足，待单列节点后评估。

**最硬反例 + 过三关：**

反例：「BIOSECURE 2024 年没成法（当年确实卡在参议院），说明这个卡点是虚张声势、中国代工不会被切断。」

过三关：
- **前提是否成立**：2024 年确实未成法，但这个前提已被 2025-12-18 成法推翻——2024 年的「没成法」只是过程中的一个快照，不是终局。前提不成立。
- **与原命题可比**：不可比。「当年未成法」被反例当成「不会成法」，但立法后来靠附挂 FY2026 NDAA 这趟必过法案成法了。这正好反过来印证：独立成法门槛高（2024 单飞失败），但一旦搭上 NDAA 便车就能跨过——门槛高不等于过不去。
- **真发生过**：不仅立法进程真实发生（2024 众院表决、股价反应），法案本身已成法（2025-12-18，第 851 条）——这是已发生的可查证事实，不是预测。
结论：这个卡点比两年前更硬，不是虚张声势——它已经从「立法威胁」变成「已经成文、但尚未指定具体适用对象的法律」。但要守住边界：成法 ≠ 已对药明系生效。真正的定向切断还卡在「药明系进不进 1260H/OMB 清单」这道行政门上（截至 2026-07 未进）。市场早在成法前就按「会被切断」提前迁移（药企分散供应链、股价被定价、西方扩产），成法把这个预期坐实——预期先行、法律追认，是本节点卡点起作用的完整路径。

## 级联关系

- **上游来自**：上游关键耗材（一次性生物反应器、蛋白 A 层析介质、细胞培养基——Sartorius/Cytiva(Danaher)/Thermo Fisher 主导，建议单列 ph-bioprocess-consumables 节点）；工业气体（发酵/培养需 CO₂、氧气，接 im-industrial-gas）；能源（大规模细胞培养和冷链能耗密集，接 en 栈）；冷链物流（原液成品冷链）。
- **下游影响**：终端生物药供应（抗癌/自免疫/罕见病用药）；生物类似药产能（biosimilar，其产能需求与专利悬崖挂钩）。
- **跨栈耦合**：ps-exportctrl / ps-sanctions（BIOSECURE 属立法定向排除，接政治栈的「立法许可」接口，耦合类型=许可 + 主权定向切断）；fi-usd（生物药代工大额跨境合同用美元结算）；与 ph-api 同属 ph 医药栈，但方向相反，二者对照是医药栈内部最有分析价值的一组。
- **跨域效应**：生物数据主权（华大基因等被点名涉及基因数据）接信息流/数据治理议题，与法玛（AI STS，数据与治理）关注面相邻；医药供应链韧性接公共卫生/社会韧性维度；Sigma（量化历史）可对生物药代工产能地理迁移做计量。

## 最近一次被争夺的事件

**2024 年美国 BIOSECURE Act（H.R.8333）→ 用立法把中国生物代工（药明系）定向排除出美国联邦相关市场**

这是 ph-biotech 节点最清晰、最新的被争夺时刻，也是本节点区别于 ph-api 的关键事件：不是防守性暴露依赖（像 2020 印度 API 禁令），而是**在位方（美国）用立法主动切断一个追赶方（中国代工）的供给进入**。以下按五个阅读动作复盘（立法进程细节为 C2 待核实，一手件缺口见文末）。

**1. 校准颗粒度。**
争夺的不是「全球生物药 CDMO 市场份额」这个大盘，而是**「中国代工（药明系）能否继续进入美国（尤其联邦资金相关）市场」**这一条特定通道。粒度锚在「美国联邦采购资格 + 生物数据主权」，不是全球产能总量——BIOSECURE 不禁止药明系在全球做生意，只切断它进入美国联邦相关市场的资格。校准到这个粒度，才不会把它误读成「全面对华生物脱钩」。

**2. 跟着反应链走。**
美国国会提出 BIOSECURE Act、2024 众院版点名药明康德/药明生物/华大基因等为 BCC → 药明生物/药明康德港股 A 股股价多次大幅下挫 → 依赖药明系代工的美国药企和行业组织（据报道 BIO 曾就影响做成员调查）表达担忧、部分企业开始分散供应链 → 药明系公开否认威胁国安、游说反对 → 众议院 2024-09-09 单独通过（306-81）→ 未搭上 FY2025 NDAA、当年未成法 → 西方代工方（三星、龙沙、富士）扩产/并购承接可能转出的订单 → 2025-10 参议院把修订版并入 FY2026 NDAA（关键：改点名为 1260H/OMB 清单认定，把「谁是 BCC」从立法争议转成后续行政认定）→ 2025-12-18 随 NDAA 签署成法（第 851 条）→ 药明系当下未被列 BCC，但药明康德被提议列入下次 1260H 更新，关键就在行政认定这一步。**每一个反应都暴露一个有利害、有手段的当事方**：国会（立法权）、药明系（被切断方，有游说和诉讼能力）、美国客户药企（迁移成本承担者，反对动机）、西方代工厂（受益方）、行业组织 BIO（在客户利益和政治压力间摇摆）、以及成法后新登场的 OMB/DoD（掌握 1260H/OMB 清单认定权，是决定清单何时适用于具体企业的一方）。当事人是从反应链看出来的，不是从分类推的。

**3. 点名被当成「地面」的一方。**
主流叙事是「美国 vs 中国」的博弈，容易把两类第三方当成中立地面：
- **美国客户药企（尤其中小 biotech）**：叙述里常被当成被动的「受影响方」，但它们其实有决定性手段——它们的**采购选择和游说立场**直接决定 BIOSECURE 的政治阻力大小。正因为相当比例美国药企依赖药明系、迁移成本高，它们的反对是法案 2024 年未能当年成法的重要原因之一。它们不是地面，是有能动性的博弈方。
- **西方/韩日代工厂**：被叙述为背景里的「替代产能」，但它们是这场争夺的**净受益者**，其扩产能力（能不能在过渡期吸收转出订单）直接决定 BIOSECURE 在现实中可行不可行——扩产跟不上，法案再硬也难落地。它们的产能进度是这条链的隐藏决定变量。

**4. 把节点放到时间里读。**
2011（三星生物成立、药明生物前身起步，中国开始切入代工）→ 2017（药明生物港股上市，中国代工规模化）→ 2020–2022（疫情推高产能需求，上游耗材紧缺暴露）→ 2024-09（众议院通过 BIOSECURE，主权首次用立法定向排除中国代工，但当年未成法）→ 2024–2025（西方产能整合：龙沙收 Vacaville、Novo 收 Catalent、富士扩产）→ 2025-12-18（法案搭 FY26 NDAA 便车成法，改为 1260H/OMB 清单认定机制）。时间轴照出：中国用约十几年从零切入到成为头部选项；美国的立法在成法前就靠「预期」触发订单迁移，成法把预期坐实，但把「切谁」的最终决定权从立法条文推给了后续的行政清单——**卡点从纯市场竞争，叠加上主权立法这一层，且预期先行、法律追认、认定权后置**。

**5. 把说法和数字当动作。**
- 「中国代工威胁美国生物数据安全和供应链安全」——这个说法本身是一个**动作**（国安 + 数据主权叙事，用来动员国防和情报政治支持、压过客户药企的经济反对）。要和物理事实对照：药明系是代工制造方，「接触患者基因数据」的程度需按业务类型核实（代工抗体原液 vs 基因测序服务，数据敞口不同），说法把不同业务的数据风险打包成一个国安威胁，是一种叙事手段。
- 「药明系股价大跌」——是市场对「中国代工在美前景」的**定价动作**，可作冲击的量化代理，但要用交易所行情核实具体幅度，别当已核数字。
- 「众议院 306-81 通过」——是已发生的立法动作，但「通过」≠「成法」，2024 年未搭上 NDAA、当年未落地，说法里的「通过」要和「是否成法」分清。

**争夺照出的结构：**
- ph-biotech 的在位方是西方/韩日代工寡头 + 原研药企 + 上游耗材寡头，中国是可替代的追赶者——这决定了美国切断的成本-收益比切断 API 划算（不失关键供给、对手失有利润的业务）。
- 政治工具是**立法定向排除**（改写联邦采购市场默认条件），门槛是全国会多数，比行政出口管制高、进程慢，但一旦挂靠国安/数据主权叙事，动员力强。
- 卡点在成法前就靠「预期」起作用：市场提前迁移、股价提前定价、西方提前扩产——立法威胁本身即政策效果，与 ph-api「隐性威胁产生实际投资」同型。
- 真实的更硬卡点可能不在代工产能层，而在上游耗材层（蛋白 A 介质、一次性反应器），BIOSECURE 没触及这一层——待单列节点评估。

**边界（守住「只记已发生、不赌将发生」）**：本事件记录已发生的动作——立法提出、2024 点名清单、众议院表决、股价反应、西方并购扩产、2025-12-18 成法（第 851 条）、认定机制改为 1260H/OMB 清单；不赌药明系最终是否被列入 BCC、份额如何变化、FAR 何时落地。这些属预测，排除。立法事实已用 EC/律所简报交叉核到 C3，NDAA 第 851 条逐字全文与 1260H 现行清单取到后升 C4。
